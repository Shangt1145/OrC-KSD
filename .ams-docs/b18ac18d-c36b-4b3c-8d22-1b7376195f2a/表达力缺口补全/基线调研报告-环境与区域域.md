## 一、对局 RNG 的持有与使用（G8）
- 持有：Match 私有字段 _random（Match.cs:35）；构造期 Seed = seed ?? Random.Shared.Next()（:115）→ _random = new Random(Seed)（:116）；public int Seed { get; }（:137）。
- 洗切实现：CardList.Shuffle(Random) Fisher–Yates 就地打乱、集合不持随机源（CardList.cs:137-146）；CardSet.Shuffle(Random) 同构（CardSet.cs:94-101）。
- 使用面：唯一消费点＝Match.ShuffleDeckAsync（Match.cs:217-235）：校验（玩家归属/终局）→ player.Deck.Shuffle(_random)（:233）→ EmitDeckShuffled（:234）；初始化调用×2＝:340-341（玩家索引升序）。
- 面向效果的随机接口：无（全仓 Random 消费仅 Match.cs/CardList.cs/CardSet.cs 三文件；无随机取样/随机选择/随机数值服务；内核 src/Orc/Core 无随机设施）。
