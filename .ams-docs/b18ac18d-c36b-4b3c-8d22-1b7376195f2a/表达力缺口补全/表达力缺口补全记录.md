## 二、逐缺口记录

### G12 卡牌元数据维度 ✅
- **补全机制**：TagData 组件（必填强类型槽位：国籍 Faction〔11 值〕、稀有度 Rarity〔4 值〕＋开放 tag 字典：子类别）；定义期声明 fail-fast→加载装配；构筑外＝对局级 ID 水位线（加载时分配、起手前快照、`ID＞水位线`）。
- **落点**：`src/Orc.Game/Cards/`（TagData / CardDefinition / CardBase / CardLibrary）、`Managers/PlayerManager`、`Match/Match`。
- **测试证据**：`CardTagDataTests` 18 枚——组合筛选（"日本精英空军"式 AND）、开放子类别（海军/T-34/谢尔曼）、构筑外判定（初始化内／生成牌模拟）、运行时增删、装配链、fail-fast 全失败面。

### G14 历史计数与比较 ✅
- **补全机制**："自写监听 handler"模式（订阅→状态自持于逻辑组件内部→触发主动触发器；不建通用计分板）；监听源：使用（card.played 载荷化）、洗切（deck.shuffled 信号＋ShuffleDeckAsync 公共面）、回合/死亡/位置（既有）、伤害（流程触发器）；即时比较＝读实时状态。
- **落点**：`GameUpdates.cs`（deck.shuffled；card.played 升级）、`Match.ShuffleDeckAsync`、效果侧模式。
- **测试证据**：`G14HistoryCountTests` 6 枚——使用计数（监听＋按卡累计＋结算读取）、累计伤害阈值触发（达标恰一次、域重置）、首次洗切（初始化路径可订阅＋首次标志自持）、即时比较（现算、零累积、零发射）。

### G9 延迟调度与回合相位效果 ✅
- **补全机制**：订阅自管（效果订阅 turn.* 相位、逻辑组件内部维护待办、到点执行自清理；不建调度器）；锚点约定："回合开始时"→`turn.start.after`、"回合结束时"→`turn.end`；**X3 回合修正**：结束不清零、点数跨敌方回合保留、"槽+1／开始设为槽数"两步。
- **落点**：`Managers/TurnManager`、`ResourceManager`（受控加值面）、`Players/Player`。
- **测试证据**：`TurnPhaseEffectTests` 7 枚——延迟资源／延迟动作／结束响应／资源语义修正＋受控面要件／显式注销／边界。

### G11 HQ 实体化 ✅
- **补全机制**：独立 HQ 实体（`Hq`：引擎薄容器子类＋组件容器＋词条/效果装载面；槽 0 占位；Player 只读转发）；数值走"通用数据改变管线"（"受伤 -1"改写／"致命前 +6 防"介入，可挂可卸）；目标以实体引用承载；终局判定迁至 HQ。
- **落点**：`Players/`（Hq / HqComponents / Player）、`Board/`、`Commanding/CommandManager`、`Match/`。
- **测试证据**：`HqEntityTests` 14 枚——实体装载（含终局迁移回归）、数值＋监听、管线改写、管线介入（含"5 血受 7 伤→+6→存活 4"两态对照、不递归、卸载复原）。

### G3 属性修饰 ✅
- **补全机制**：方案 A（卡侧修饰器组件）；修饰器＝基类＋模板子类（加／设值／回调／引用／钳制／条件）＋现场注入；链＝**全量重跑**（基准→链→有效值）；更新检测接口（生成/比较缓存）＋**集中触发**；管线三段合一；`card.stat.changed` 载荷化；门户（花费/单位组件）；单位防御力上限（加防同步／扣不减／修复＝恢复上限）。
- **落点**：`Cards/`（ModifierSystem / StatUpdateDetection / CardModifierComponent 等）、`Commanding/`、`GameUpdates.cs`。
- **测试证据**：`ModifierSystemTests` 9＋`StatUpdatePipelineTests` 7＋`StatPortalTests` 11＋`StatWiringTests` 9（合计 36）——加值/叠加/撤销、链确定性、缓存比较与集中触发、期限两型、设值型（含随动）、上限语义、死亡冻结/清理、伤害衔接。

### G4 持续/条件静态能力 ✅
