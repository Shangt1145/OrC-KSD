- **X4：handler moding ✅ 已对齐**——moding＝handler 的"修饰器"（delegate），**直接替换**运行逻辑；handler 运行时检查、取**最后一个**生效；**注册双形态**（装配期＋运行时增删）；**栈语义**（最后一者生效、注销回退上一个）；**纯替换**（不可调原逻辑）＋**约束：不允许 handler 内进行流程编排**（handler＝单一处理逻辑单元；编排发生在流程层）；用途：基类模板＋子类 moding、替代"前后插入 handler 实现屏蔽"；落点：引擎内核 handler 承载（具体定位待实现）。
