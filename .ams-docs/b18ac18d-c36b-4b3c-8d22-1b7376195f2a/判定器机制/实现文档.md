- Target: src/Orc（内核：判定器机制基座、Trigger 合法性验证改造）、src/Orc.Game（装配接入、合法性验证迁移、两示范）、tests/（验收场景）。

## Implementation Steps

### S1: 判定器机制骨架（形态/注册/引用/加载）

- Status: Done
- Target: src/Orc（内核）——判定器基类与契约、对局级注册表、引用面、加载接入；src/Orc.Game（装配接入）。
- Approach: 判定器基类 abstract（统一主方法 `object[]? Invoke(object[]? args)`〔同步〕；子类声明强类型 delegate＋覆写主方法做「拆包→强类型调用→组包」适配；调用侧经统一主方法，强类型面面向实现/测试侧）；对局级注册表（字符串名 ordinal；注册即配置、重复拒绝；未注册引用 fail-fast）；"对局加载时加载"＝随对局装配链（挂靠"初始化内创建＋注入"范式，卡加载前就绪）；命名规范由实现者提报（参照 KeywordIds/信号名先例）；加载时点与错误语义细节由实现者定型并申报；无状态（判定器不持有对局状态，输入经参数/上下文）。
- Acceptance:
  - [x] 基类与子类形态就位（统一主方法＋强类型 delegate 适配；同步）
  - [x] 对局级注册表就位（字符串名；注册即配置、重复拒绝）
  - [x] 未注册引用 fail-fast；handler 按名引用调用成功
  - [x] 对局加载时加载（挂靠装配链、卡加载前就绪）；无状态核验
- Rationale: 场 1 Q1/Q1a/Q2（注册面/失败语义/形态契约）；基线（内核域：无按名解析先例需新增、装配链范式）
- Terminology: [判定器](../../../CONTEXT.md)、[handler](../../../CONTEXT.md)

### S2: moding 与全局生效

- Status: Done
- Target: src/Orc（moding 注入面、统一解析点、条目句柄产物）。
- Approach: 允许注入 delegate 替换判定器主逻辑——**双形态**（统一签名 `Func<object[]?, object[]?>` 底层＋强类型封装便捷面）；栈语义（最后者胜、注销回退、快照一致、幂等宽容、句柄即权限、机制静默——语义与 X4 一致）；**全局生效**＝判定器调用内部设统一解析点（所有引用方每次调用解析同一栈）；判定器条目自带等价句柄产物（供 moding 寻址；延续 X4"不得存在无法被 moding 的注册项"精神）。
- Acceptance:
  - [x] 注入 delegate 替换生效；注销回退；栈语义（多次替换最后者胜、逐层回退）
  - [x] 全局生效（多引用点统一按栈顶解析）
  - [x] 双形态注入可用（统一签名＋强类型封装）
  - [x] 判定器条目可寻址（句柄产物）
- Rationale: 场 1 Q2a/Q4；X4 语义要素复用（基线内核域差距提示：全局生效属新增能力面）
- Terminology: [moding](../../../CONTEXT.md)、[判定器](../../../CONTEXT.md)

### S3: 合法性验证替换（集成）
