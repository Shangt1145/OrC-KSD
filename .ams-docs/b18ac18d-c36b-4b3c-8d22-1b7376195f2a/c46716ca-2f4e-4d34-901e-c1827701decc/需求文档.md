# C2 开发/发现完整链 — 需求阐明记录

> 委托：第 2 批 W5-1·C2（CodeImplementation；grill 层级＝文件级）。
> 职责范围：把已交付的卡牌选择器（C1：产出标识或卡引用、不含实例生成）与对局卡牌服务（S9：Create/Place 四去向、失败自动回收）串成端到端可表达的『开发/发现』链——取池（定义级名单）→ 选择器 N 选一 → 生成实例 → 落位（如手牌）；**测试内端到端示范为主、生产代码按需最小适配**。
> 进度：Q&A-1（示范交付形态与落点、生产件口径、验收驱动方式）✅；Q&A-2（卡池取样边界与退化口径、落位去向覆盖与失败负例）✅；Q&A-3（验收②选取语义链、效果链禁旁路与证明强度、交互断言面）✅；Q&A-4（取消必验与断言口径、空集边界三档、违规提交排除）✅；Q&A-5（数量维度边界、测试组织与《实现记录》交付约定）✅；Q&A-6（取样确定性与防退化断言口径、第二去向与驱动方式收口）✅；Q&A-7（验收标准收口·必验项同步）✅。

## 一、功能职责与流程约束（本委托需求基线）

- **链定义**：取池（卡池取样、定义级名单）→ 卡牌选择器 N 选一（桥接交互；载荷两形态：定义级名单〔生成语义〕／已有实例集〔选取语义〕）→ 产出（定义标识／卡引用）→ 生成实例（S9 创建；静态定义级）→ 落位（S9 统一放置服务；如置入手牌）。
- **交付形态**：示范以**测试内端到端组合**为准；生产代码**默认零新增**，仅在组合中发现 C1/S9 已交付面存在**接口阻碍**时做**最小加性适配**（不改既有语义、不引入第二真源、逐条申报——沿用 S9/S10 受控适配口径）。
- **驱动口径**：验收①必须**经真实效果链**（效果装配→装载→执行→执行上下文取用服务）驱动——"完整效果链"取**运行路径证明**口径；其余场景可按既有风格（对局构造＋桥接驱动，参照 C1 演示）承载。
- **不变量**：不修改 C1/S9 已交付语义；不新增"可复用生产件"（示范的复用形态＝测试内组合范式，供未来效果方参照/复制）；构建 0 警告；全量回归不破坏（基线 931/931：Orc.Tests 204／Orc.Lua.Tests 157／Orc.Game.Tests 570）。
- **文件新增**：测试文件可自由新增；生产文件新增仅限"经申报接受的最小加性适配"范畴（本单禁止删除文件）。

## 二、已解决的歧义（Q&A 逐轮记录）

### Q&A-1（2026-10-04）：示范形态 / 生产件口径 / 验收驱动方式

**子的问题原文（摘要）**：

- 主问题一（示范含义）："落示范"＝src 生产代码新增可复用示范件（配测试），还是"示范"仅在测试内呈现（生产"按需"＝仅最小加性适配、不新增生产件）？必须动 src／保持零改动的判据？
- 主问题二（若要求生产件）：复用等级＝"供后续卡牌效果可直接引用/装配的真实效果件"，还是"示范级组合（证明可表达、未来由效果方复制）"？落域（目标选择消费面／卡牌效果面／对局服务面）？允许新增文件吗？
- 主问题三（驱动方式）：验收①"全链测试"是否必须经真实效果链（效果装载/执行上下文）证明"效果链"，还是允许测试内直接构造对局＋目标桥接驱动（C1 演示风格）？"完整链"＝结构证明 or 运行路径证明？

**解答**：

**一、"落示范"的含义与判据**：

- 交付以**测试内端到端示范**为准（验收①②即测试口径）；**不要求新增生产示范件**。
- 生产"按需"判据：**默认 src 零新增可接受**；**必须动 src 的唯一情形**＝组合中发现 C1/S9 已交付面的**接口阻碍**（选择器产出与生成/放置的衔接缺口、执行上下文取用缺失、空集/取消路径断裂等）——处理方式＝**最小加性适配并申报**；不得借机重构或扩展语义。
- 拒绝备选："生产件（可复用效果/组合辅助）"——本仓库无内置真实卡池（卡数据由调用方提供），"真实效果件"无宿主；且不宜在验证阶段固化组合形态；示范以组合范式（测试内）承载即满足"可表达验证"目标。拒绝原因：宿主缺失＋过度固化风险。

**二、生产件口径（条件性；本单默认不新增）**：

- 本单不主动新增生产件；如实现者判断某组合辅助对验收或后续复用**确有必要**，走"申报—接受"通道（说明必要性/落域/复用等级），接受后方可新增。
- 若遇阻碍需最小加性适配：落域按阻碍实情（目标选择消费面／卡牌效果面／对局服务面）；不改既有语义、不引入第二真源。
- 假设口径备用（若未来评估生产辅助件）：复用等级只能是"**示范级组合**（证明可表达、未来由效果方复制该组合）"，不能是"可直接装配的真实效果件"；允许新增文件（禁止删除）。

**三、驱动方式（运行路径证明）**：

- 验收①（定义级三选一→生成→落位）**必须经真实效果链驱动**：装配测试卡定义＋效果（工厂/声明）→ 装载 → 执行（效果经执行上下文取用服务：选择器出题→桥接提交→生成→落位）。
- 验收②（已有实例集／选取语义）与③（边界：取消/空集等）**可**按既有风格（对局构造＋桥接驱动，参照 C1 演示测试）承载；经效果链一并覆盖更佳（不作硬性要求）。
- 拒绝备选："结构证明（纯测试组装 API 驱动）"作为验收①的唯一形态——不证明"效果侧取用面＋选择器＋生成/放置"的真实运行通路，对代表效果表达力验证（D13 口径）不足；结构证明留作辅助手段。
- 若效果链驱动中发现机制阻碍：按"最小加性适配并申报"处理（既有授权）。

**架构审视补充（本轮）**：

- 结果断言口径（全链）：选中产出→实例生成（定义标识正确）→落位（去向/数量/顺序）→失败自动回收可观察。
- 取池不足 N 张的退化行为与空集语义：**按 Q&A-2 精化口径**——运行时池不足（含 0）一律不抛、以链级终止/结局表达；构造期 fail-fast 保留但仅限调用方构造错误。
- 非功能：延续既有口径（构建 0 警告、全量回归、实现记录落盘）；无额外性能要求。

### Q&A-2（2026-10-04）：卡池取样边界与退化口径 / 落位去向覆盖与失败负例

**子的问题原文（摘要）**：

- 主问题一（卡池取样）：1.1 "卡池"范围＝本局卡牌库已注册定义全体（枚举读面＋随机服务取样），还是要求体现"筛选后的子池"？若后者必须，筛选承载方（效果侧自备 vs 通用筛选面）？1.2 取样是否必须经对局随机服务、且不放回？全链测试是否要求"固定种子＋确定性锚点"？1.3 取样不足 N 张（含 0 张）时链的期望行为（(a) 取样环终止不进入选择器／(b) 以 M<N 照常进选择器／(c) 其他）？"不抛断链"的强度（任何池状态不抛、一律结局表达 vs 允许 fail-fast 仅限"调用方构造错误"而运行时候选不足必须走失败结局）？请给出可直接断言的期望。
- 主问题二（落位去向）：2.1 验收①落位是否只以"置入手牌"为必验去向？四去向其余是否要求链式示范，或明确不在本单（S9 已覆盖）？2.2 若覆盖多去向：同一链"去向可配"还是每去向独立场景？"相邻空槽选取"环节是否需体现？2.3 "失败自动回收可观察"期望落点：是否需一条"落位被拒→已创建实例被回收且可观察"的全链负例？用哪个去向承载最贴切？

**解答**：

**一、卡池取样边界与退化口径**：

- **1.1 池范围**：卡池＝**本局卡牌库已注册定义的全体**（经既有枚举读面）；**不需要通用筛选面**——筛选（如按类别/阵营/谓词）由效果侧自备候选集承载（组合形态；示范可选体现、非验收项）；不新增筛选机制。依据：C1 名单载荷本就是"构造方给定的集合"；既有服务边界先例＝"服务只对给定序列取样；候选筛选与合法性由调用方负责"。
- **1.2 随机与确定性**：取样**必须经对局随机服务**（`PickN`；**不放回**为原语既定语义、保证名单互异；n＝min(N, 池数)）；全链测试**要求固定种子＋确定性**——同种子复现断言（两次运行取样名单一致），锚点（种子＋期望取样名单）写入《实现记录》（参照 B1 场景表口径）。
- **1.3 不足 N 张**：分段口径——
  - **M≥1（含 M<N）**：以**实际取到的 M 张**构造名单、照常进选择器（N 为期望张数上限、非硬性；断言：请求登场名单＝取样结果、链照常完成）。
  - **M=0**：取样环终止、**不构造选择器**（空名单会触发 C1 名单形态构造期错误——链不得把运行时状况落入构造期错误通道）、零副作用、不抛——以链级"无结果/终止"表达且可观察（断言：桥接零调用、无实例创建、无异常）。
  - **"不抛断链"强度（二分对齐）**：**运行时任何池状态（含 0）一律不抛、以结局/终止表达**；**构造期 fail-fast 保留、但仅限"调用方构造错误"**（如直接构造空名单＝编程错误，仍按 C1 语义拒绝）——运行路径不得触发该通道。三重约束对齐：`PickN` n＞候选数＝明确拒绝、`PickOne` 空候选集＝明确拒绝、C1 名单空集＝构造期错误——链的组装须"先判池→再取样→再构造"，**不做出上述非法调用**。
- 拒绝备选：(a) 全档"池不足即终止"——拒绝（M≥1 时丢弃可运行选择、与"可表达"目标相悖）；(b) 对 M=0 也构造空名单/直接调取样——拒绝（把运行时状况混入构造期错误/异常通道，与"不抛断链"冲突）。

**二、落位去向覆盖与失败负例**：

- **2.1 覆盖范围**：**必验＝手牌**（验收①）；**增补要求＝至少一条第二去向的链式场景**（阵线/卡组顶/洗入择一，**择低复杂度形态**）；**不要求**四去向穷举（S9 已覆盖各去向路径，链式不重复）。依据：证明链的"去向可配"（去向为链的显式调用点），成本低、直击接缝风险。
- **2.2 组装形态**：**每个去向独立场景、独立组装**；去向为链中的**显式调用点/参数**（不写死手牌）；**不做形式化"策略可替换"抽象**（本单是验证/示范件而非生产框架；形式化抽象会固化接口，与 Q&A-1"不新增生产件"一致）。**"相邻空槽选取"环节不要求体现**（S9 已覆盖解析与选取分离；本链用单空槽/调用方指定槽的退化形态即可，避免引入新的交互环节）。
- **2.3 失败负例**：**要求一条**——断言核心＝"**拒绝/失败结局可观察＋无未归属残留**"（S9 普适标准）。承载**推荐相邻处（无相邻空槽）**——可稳定构造（填占相关槽位使解析为空）、S9 语义＝`Rejected(NoAdjacentSlot)` 且**先于创建（零副作用）**。口径说明（纠偏）：S9 复合面为"**预防式为主＋兜底回收**"双层——类别预检/解析空等业务拒绝先于创建（无实例可回收）；"创建后回收"（销毁——无未归属残留；可观察面按 S9 既有回收语义）是放置期失败/异常的防御兜底（如可稳定构造则一并断言；不作硬性）。手牌去向无业务拒绝路径（烧牌＝成功语义、回收仅防御兜底），故负例不以手牌承载。
- 拒绝备选：四去向全链穷举——拒绝（与 S9 覆盖重复、范围膨胀）；"策略可替换"形式化——拒绝（过度设计/接口固化）。

**架构审视补充（本轮）**：

- 断言口径汇总（可直接断言）：取样（对局随机服务/不放回/确定性复现）；链行为（M=0 终止零副作用；M≥1 照常）；落位（去向显式、≥2 场景）；失败（拒绝可观察＋无未归属残留）。
- 池不足的判定位置＝链的组装代码（"调用方负责筛选与合法性"服务边界）；不修改 `PickN`/C1 既有语义。
- 非功能：无新增要求（延续 0 警告、全量回归、实现记录）。

### Q&A-3（2026-10-04）：验收②选取语义链 / 效果链证明强度与禁旁路 / 交互断言面

**子的问题原文（摘要）**：

- 主问题一（验收②选取语义）：1.1 候选实例集来自哪一区域（己方手牌／卡组内／战场单位）？归属是否限定？选择来源的判据（低复杂度、可稳定构造、体现"既有实例"身份）？1.2 选中后的动作——"选取语义"后续环节：把选中实例再落位到另一去向（如手牌→卡组顶/洗入），还是原地消费（无位置变化）？若要求位置变化，去向与来源是否成对指定？1.3 断言核心：同一实例（引用同一性、非新建、实例计数不变）＋位置/归属变化＋信号面（按 S9/G7 既有语义）？是否要求与定义级形成对照断言（同一次验证内两类载荷对照：定义级产出＝新实例、引用集产出＝原实例）？
- 主问题二（验收①证明强度）：2.1 "效果经执行上下文取用服务"是否硬约束——不得绕过（效果直接持有对局/服务引用、测试侧塞服务、效果自带实例/名单旁路）？可断言判据？2.2 效果链覆盖度：要求"装配→装载→执行"全过程证据，还是只要"执行期取用面成立"？触发形态是否指定（主动 vs 被动）或由实现择低复杂度？2.3 交互断言面：要求断言"出题请求描述"（呈现形态、名单/引用集一致性、槽位声明形态）＋"提交与产出读取"两端，还是只断言终局？

**解答**：

**一、验收②「选取语义」链定义**：

- **1.1 候选来源**：**推荐＝己方手牌的既有实例**。判据：低复杂度（起手装载/既有操作后实例天然在手、无需额外构造）；可稳定构造；能体现"既有实例"身份（有归属、有对局 ID、物理在区、非新建）。归属＝由构造方约定（沿用"归属中立"——框架不含归属，"己方"由构造方给定候选集界定）。来源备选评估：卡组内实例（受控面成熟度较低，非必要不选）；战场单位（受阵线/移动规则牵制、复杂度高，不用）。**空候选＝引用集既有失败语义（失败不进交互）**，不另立口径。
- **1.2 后续动作**：**要求位置变化**——把选中的既有实例**落位到另一去向**；来源与去向**成对指定**。**推荐组合＝手牌 → 卡组顶**（G7 回迁原子面 `ReturnToDeckTop` 已交付：跨集合受控、同一实例装回、不丢失不重复、**回迁静默**；最简、位置断言稳定＝卡组首位）；备选＝手牌 → 洗入（回迁＋洗切动作面组合；`deck.shuffled` 恰一次可断言）。**拒绝"原地消费"**（无位移——无法形成"实例同一性 × 位移"双重断言，验证意义弱）。
- **1.3 断言核心**：①**同一实例**（引用同一性；非新建——无新 ID 分配、无构筑外标记；实例计数不变）；②**位置/归属变化**（如手牌 −1、卡组[0]＝该实例）；③**信号面按既有交付语义**（回顶＝静默；洗入＝`deck.shuffled` 恰一次）。④**对照断言（要求）**：同一次验证内与定义级形成对照——定义级产出＝新实例（新 ID、构筑外标记可观察）、引用集产出＝原实例（同一引用、计数不变）。
- 拒绝备选：来源＝卡组/战场（理由内联）；动作＝原地消费（如上）；不做对照断言——拒绝（两形态的语义差异是验收②的证明要点，丢失则证明力不足）。

**二、验收①证明强度与禁旁路**：

- **2.1 "效果经执行上下文取用服务"＝硬约束**。明确禁止（下列做法即违规）：

## 三、验收标准

> 驱动方式口径：仅①必验效果链驱动；②、②a、③按测试内驱动（效果链覆盖为可选加分）。

- ①全链（定义级/三选一→生成→落位）：经真实效果链驱动（装配→装载→执行→取用→选择→生成→落位），断言通过。必验子项：
  - **确定性（同种子复现）**：两个同种子对局、同序操作 → 取样名单一致（操作序含洗切等同一随机流消费）；
  - **防退化（换种子变化）**：换种子 → 名单变化（须"池＞N"配置）；
  - **取样证据组**：名单互异（不放回）＋元素∈池＋请求登场名单与取样结果逐项一致（含条目数）；
  - **禁旁路行为锚点**：构筑外 ID（真经创建面）＋取样复现/换种子（真经随机服务）＋桥接驱动（真经选择）；
  - **交互两端**：出题请求描述（呈现类别＝卡牌阵列＋载荷一致性〔定义级＝与取样一致；引用集＝与构造方给定集合一致〕＋槽位形态）＋提交与产出读取（按槽位名读出，与生成/落位串联）；
  - **锚点入实现记录**：固定种子＋期望名单（确定性组）／对照种子＋不同名单（随机性组）。
- ②已有实例集载荷场景（选取语义）：**候选＝己方手牌既有实例；选中→落位到另一去向（推荐卡组顶〔静默回迁〕；来源/去向成对）**；断言＝同一实例（非新建、计数不变）＋位置/归属变化（手牌 −1、卡组[0]＝该实例）＋信号面按既有语义（回顶＝静默；洗入＝`deck.shuffled` 恰一次）＋**与定义级对照（新实例 vs 原实例）**；驱动方式不限（效果链更佳）；**对照组织：推荐"拆两条用例＋《实现记录》映射表"（亦可同一用例内两段）**。
- ②a 第二去向链式场景（手牌必验＋阵线/卡组顶/洗入择一，低复杂度形态）。
- ③边界与失败（统一断言口径＝不抛断链＋链终止＋零副作用＋结局可观察）：
  - **取消（必验；推荐定义级链）**：终局＝取消＋链侧零副作用（不生成/不落位/无信号）＋**取消后隔离**（同链下一次执行正常完成）；
  - **引用集空候选（必验）**：失败结局（不进交互）＋链终止＋零副作用（与 M=0 同构口径）；
  - 池不足（按 Q&A-2）：M=0 终止零副作用；M≥1 照常；**组装护栏可断言＝运行路径未触发构造期 fail-fast 通道（无构造期异常）**；
  - 失败负例（推荐相邻处无空槽）：拒绝结局可观察＋无未归属残留；
  - 系统失败（桥接异常/缺失）＝可选（推荐覆盖其一）。
- ④构建（-t:Rebuild）0 警告 0 错误。
- ⑤全量回归不破坏（基线 931/931：204/157/570）。
- ⑥《实现记录-C2.md》落盘（落你的文档区：功能点→落点→测试映射；含受控适配清单、确定性锚点、取用通道与禁旁路声明、测试证据表〔用例清单＋运行命令与结果摘要〕）。

## 四、接受的风险与延展点
