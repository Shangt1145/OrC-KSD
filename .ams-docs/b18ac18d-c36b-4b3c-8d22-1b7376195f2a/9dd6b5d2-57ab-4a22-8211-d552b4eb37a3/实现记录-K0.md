## 三、定型申报（共享单元形态）

1. **位置与命名**：`src/Orc.Game/HandLimitBurn.cs`（namespace `Orc.Game`，与 `GameUpdates.cs` 平级——跨域机制单元惯例）；类＝`public static class HandLimitBurn`（对齐 `CounterAttackRules`/`GameUpdates` 既有公开静态形态）。
2. **成员契约**：
   - `IsAtLimit(Player) → bool`：手牌计数 ≥ `Player.HandLimit`〔9〕（原两处判定表达式原样收编；常量与判定口径未动）。
   - `BurnAsync(LogicEngine, Player, CardBase, bool emitDrawn, CancellationToken) → Task`：烧牌动作，**emitDrawn 参数化语义**——`true`＝「算被抽到」（发 card.drawn 恰一次 → 销毁 → card.discarded 恰一次）；`false`＝「未经手牌」（销毁 → card.discarded 恰一次）。
   - `DestroyAndEmitDiscardedAsync(LogicEngine, Player, CardBase, CancellationToken) → Task`：销毁＋card.discarded 原语（**全库单一实现**；弃置与烧牌共享处置链：销毁〔含资源清理〕先、信号后）。
3. **参数化保留语义**：两路差异仅 `emitDrawn` 一处显式参数；其余（直烧不经手牌、hand.add 零次、不经弃置动作、信号顺序）共用同一路径——行为与统一前逐信号一致（对照用例序列断言锁定）。
4. **弃置路径接续方式**：`DiscardCardAsync` 保留「前提校验＋移除」，处置链（销毁＋discarded）转为复用共享原语（行为不变；由既有 G7 弃置测试锁定）。
5. **旧助手去向**：PlayerManager 私有助手 `DestroyAndEmitDiscardedAsync` **删除**（推荐形态——不作为独立实现保留；非转发壳、非重复实现）。
6. **单一实现范围盘查结果**：全库 `EmitCardDiscarded` 消费点共 3 处（DrawCard 烧牌〔经助手〕／DiscardCardAsync 弃置〔经助手〕／PlaceToHandAsync 满手〔内联〕）——现已全部收敛至共享单元；另盘查 `DestroyCard` 全部调用点，`MatchCardService.CreateAndPlaceCoreAsync` 的防御回收（L452）与业务失败回收（L458）为**「游戏层信号零发射」语义**（不发 discarded——非「销毁＋discarded」组合），不纳入复用（申报在案）。
7. **边界**：起手装载（`LoadOpeningHand`→`DrawIntoHand`）不接入共享单元（不受裁决、静默语义不变）；HandLimit＝9、无配置面改造（本单边界）。
