## 二、关键实现决策（供验收对照）

1. **原语面与契约**：最低能力集三项齐备（数值／PickOne／PickN）；命名/签名采用委托原型 `Next(int max)` / `PickOne<T>(IReadOnlyList<T>)` / `PickN<T>(IReadOnlyList<T>, int)`——泛型形态、对任意元素类型可用（服务不依赖元素语义）；服务只对给定序列取样（候选筛选与合法性由调用方负责）；「随机分配」＝调用方循环取样组合（服务不建分配专门机制）。
2. **确定性 PRNG（在线同步预留落点）**：SplitMix64 自实现（固定算法——消除 `System.Random` 的平台/版本不确定性）；种子显式化沿用 `Match.Seed`（可传入＋只读可查）；不新增"随机流消费状态/位置"查询面（需求明确不要求）。
3. **消费规则（单流、顺序确定——已文档化于代码注释）**：每次成功原语调用按确定性流程顺序消费样本；拒绝采样（阈值＝2^64 mod bound——消除除法偏差）可能补偿消费，拒绝序列同种子确定复现；参数被拒请求（如 max≤0）零消费；`PickN(_, n=0)` 零消费；无并发/异步乱序（P2 同步语义）。
4. **边界行为（全部由实现者定义＋测试覆盖）**：`Next`：max ≤ 0 ＝ `ArgumentOutOfRangeException`；max == 1 ＝恒 0（消费规则不变）。`PickOne`：null ＝ `ArgumentNullException`；空候选集 ＝ `InvalidOperationException`（明确拒绝）。`PickN`：null ＝ `ArgumentNullException`；n < 0 ＝ `ArgumentOutOfRangeException`；n > 候选数 ＝ `ArgumentOutOfRangeException`（不放回不可满足）；n == 0 ＝空列表（零消费）。`PickN` 返回顺序＝逐次选取序（随机序——文档化；同种子确定复现）。
5. **访问门禁（两层——对齐既有管理器门禁风格）**：对局内部链路（初始化链、准备态洗切）经服务本体消费＝合法（显式接口 `IRandomSource`，无对外门禁；状态约束由上层受控动作面 `ShuffleDeckAsync` 既有门禁负责）；对外取用面＝仅"进行"态可用（`Match.RandomService` 属性＋服务本体方法级门禁：准备态、终局后＝ `InvalidOperationException`；已持引用在终局后调用亦拒绝）。独立构造（公开构造——显式测试/工具用途）＝无门禁约束。
6. **接入面（形态与层级申报）**：**游戏层（Orc.Game）**；形态＝「卡 → 玩家 → 服务」读取路径（`MatchRandomService.ResolveFor(Card)`——与 `GameEnvironment.ResolveFor` 同构）＋装配期注入（`Match.Initialize` → `Player.ConfigureRandomService`）。效果运行期经该面取用服务；无隐藏全局单例（多对局隔离断言为证）。
7. **洗切接入（同一服务/单流）**：`ShuffleDeckAsync` 与效果取样共用同一服务实例/同一 PRNG 流（共流断言双形态覆盖）；"保持既有洗切行为"＝语义级——就地打乱（Fisher–Yates 性质、多重集不变）＋同随机源可复现；洗牌具体序列因 PRNG 更换而变化属预期（不要求与 `System.Random` 路径逐位相同；既有测试机械随改后全绿）。
8. **脱局降级**：`ResolveFor` 解析不到（卡未加载/独立构造/未注入）＝null——调用侧按「功能不可用、不抛错、不失败」处置（效果代码空值分支＋脱局执行测试覆盖）。
9. **P1/P2**：无随机消费时零副作用；全链路同步/顺序语义（调用返回即终态）。

### 无旁路核查（消费点清单——汇报正文口径）

**生产代码（`src/`）对局内随机消费点＝清零**（对局内统一经随机服务）；逐点列明唯一剩余 `System.Random` 触点：

| 位置 | 用途 | 性质 |
|---|---|---|
| `Match.cs` 构造：`Seed = seed ?? Random.Shared.Next();` | 未显式传入种子时的一次性自动生成 | **创建期一次性种子生成——不构成对局内消费**（列明；非对局内随机消费） |

- 对局内消费统一经 `MatchRandomService`：①洗切——`Match.ShuffleDeckAsync` → 集合 `Shuffle(IRandomSource)`（内部受控源面）；②效果取样——对外原语（`Next`/`PickOne`/`PickN`），经 `ResolveFor`／`Match.RandomService` 取用。
- **测试侧（`tests/`）**：对局内随机行为驱动均经 `MatchRandomService`（确定性源）——`System.Random` 使用＝清零（全仓搜索核验）。
