## 三、定型申报（集中节）

### 3.1 形态结论（B10：评估与落实）

- **评估结论＝不新建独立费用判定器／费用供给面**（R1 2.1 预期路径）：行动费「费用特例」承载点＝**（判定面）K3 leg 条目**（`move.leg.eligibility`／`attack.leg.eligibility` 即「费用条件豁免/改判」的可改写入径）＋**（数值面）既有费用修饰链**（G5 `GetEffectiveValue`——费用数值特例经修饰器表达，判定与扣费同源读取生效）。**不落位**判定器化（未动 `JudicatorNames`／`GameHooks`／`GameHooksJson`／注册段——无清单同步）。
- **落实＝写点侧最小内部收编**：统一取值入口（`Effective`）＋共享扣费动作单元（`Deduct`）——不改变读取节奏、不改变扣费语义。
- 「费用特例面」协同结论（演示洞察）：费用不足下「仅判定面豁免」真实执行必透支（扣费读有效值、无下限钳制——既有边界行为保持）——完整「免费/减费」特例需**判定面（leg 改写）＋数值面（修饰链）协同**表达。此为承载点归属的可执行证据支撑。

### 3.2 统一取值入口（`OperateCosts.Effective`）

1. **位置/可见性**：`src/Orc.Game/OperateCosts.cs`、`namespace Orc.Game`、`internal static class`（不新增对外公共接口——R1 授权口径）。
2. **单源形态**：`unit.Modifiers.GetEffectiveValue(CardStatFields.OperateCost)` **全库仅存一处**（本文件 L19）；leg 读取与两写点均经其取值（「写点不再内联取值表达式」）。
3. **读取节奏（硬边界保持）**：纯静态调用、无状态、无缓存/快照传递——判定读一次、扣费读一次；「判定时缓存费用值供扣费复用」未引入。

### 3.3 扣费动作单元（`OperateCosts.Deduct`）——两写点间归一（申报）

- 写点改法：`FinalizeMove/FinalizeAttack` 内 `var owner = unit.Owner!;`＋`owner.Points -= …` → **`OperateCosts.Deduct(unit);`**（扣减与取值下沉共享单元：`owner.Points -= Effective(unit)` 全库仅存一处）。
- 语义保持：扣除对象（`unit.Owner!`——NRE 语义同现状）、扣减结果（无下限钳制等边界变化）、`command` 取数与后续置位顺序逐条保持。
- 采纳理由：需求「两写点之间的扣费动作是否再归一（共享单元）＝实现自定（最小改动优先，若共享则申报）」——本单采纳共享（写点侧「扣费动作」全单源；申报在案）。

### 3.4 判定侧接入（`LegEligibilityJudicator`）

- L129：`owner.Points < unit.Modifiers.GetEffectiveValue(CardStatFields.OperateCost)` → **`owner.Points < OperateCosts.Effective(unit)`**（比较逻辑留 leg——取值进统一入口）。
- 枚举/类文档原文「G5 有效值读取口」语义不变（读取口＝`OperateCosts.Effective`）。

### 3.5 配置项定型（B13）

| 配置项（MatchOptions） | 类型/缺省 | 语义 |
|---|---|---|
| `OpeningHandSizeFirstPlayer` | int = 4（常量 `DefaultOpeningHandSizeFirstPlayer`） | 先手起手张数；0 合法＝空起手；负数创建期拒绝 |
| `OpeningHandSizeSecondPlayer` | int = 5（常量 `DefaultOpeningHandSizeSecondPlayer`） | 后手起手张数；同上 |
| `AllowFirstTurnDraw` | bool = false | 允许先手全局第 1 回合抽牌（false＝保持现行「先手第 1 回合不抽」唯一例外；true＝关闭该例外、照抽 1 张）；后手首回合与其余回合照抽的既有边界不受影响 |

- 命名定型：`OpeningHandSizeFirstPlayer/SecondPlayer`（沿用原 Match.cs 私有常量名升格）；`AllowFirstTurnDraw`（对齐裁定「置『允许』」语义轴，缺省 false 与「缺省构造＝4/5/false」口径一致）。
- 缺省值常量公开（`public const`——仿 `ResourceManager.DefaultMaxPointSlots` 先例；供引用与缺省断言）。
- 校验定型：**负数＝创建期 fail-fast**（`ArgumentOutOfRangeException`，同款 `nameof(options)`＋可行动消息「0 合法＝空起手」）；**0 合法**；**不新增卡组容量预检**（起手超卡组＝初始化抽取阶段既有失败模式保持）。

### 3.6 消费点接线（B13——单一来源、无第二真源）

1. **起手装载**（Match，Initialize 内装载段）：两处 `LoadOpeningHand` 实参改读 `_options.OpeningHandSizeFirstPlayer/SecondPlayer`（旧私有常量删除——全库旧引用＝0）。
2. **首回合抽牌**（TurnManager 回合开始处理段）：`ShouldDrawForTurn(turnNumber) => turnNumber != 1 || _allowFirstTurnDraw`；实例化（原 static 移除）。
3. **装配链传参**：`Match` 创建 TurnManager 时传 `_options.AllowFirstTurnDraw`（对局路径唯一构造方）。
4. 无其他「开局/首回合」消费点需同步（`GameEntryPoints` 入口目录表为签名转发面、不消费常量——零触碰保持；全库核查见 §五）。

### 3.7 独立构造路径与失败模式

- **独立构造路径**：`TurnManager` 构造新增尾参 `bool allowFirstTurnDraw = false`——缺省＝「第 1 回合不抽」（硬约束 1.3b；对局路径总显式传值、缺省路径供未来独立构造）；`new MatchOptions()` 全缺省＝4/5/false（1.3a）。**不传/缺省 MatchOptions 与独立构造路径缺省逐条与现状一致、零漂移**（测试证据：`Defaults_*` 两例）。
- **失败模式**：非法配置＝创建期 fail-fast（负数）；起手超卡组＝初始化抽取阶段既有失败模式（不拦截——保持现状）。

### 6.1 B10 专项（`OperateCostUnificationTests`，3 用例）

| # | 用例 | 断言要点 |
|---|---|---|
| 1 | `Move_Deduction_Matches_Judged_Effective_Value_Exactly_Once` | 修饰 +1（2→3）；点数 2 → PointShortage（**判定读有效值 3**；读基础值 2 会通过）；点数 3 → 临界可用；真实移动 → **点数 3−3＝0**（同值＋恰一次夹逼） |
