## 四、DIY 全链路（json → 游戏内卡牌）

五段管道（示例见 `samples/card-pack-demo/README.md`）：

1. **预检**：`CardDistributionValidator.Validate(cardDirs, libraryDirs)` → 双零放行（CI gate `HasNoErrors`）；
2. **装载**：`CardDataLoader.LoadDirectory`（卡）＋`PrefabManager.LoadDirectory`（效果库）——纯数据产出；
3. **注册**：`CardEffectRegistry.DeclarePrefab` ＋ `PrefabManager.RegisterPrefab`（**先于卡加载**）；
4. **初始化**：`Match.Initialize()`（效果随卡装载）；
5. **使用**：打出/触发（csx 经受控门面 `EffectRuntime` 执行，含批 4/6 的动态/定向能力）。

创作侧（可选上游）：`EffectCompilationDriver`——卡面文本/DSL → 编译 → 打包 `*.prefab.json`（批 5）。
