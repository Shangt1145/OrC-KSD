## 二、装配接线申报（第 5 轮 1a 口径：加性最小＋逐条列明）

1. **EffectRuntime 构造加性演进**（`Func<LogicEngine?>? engine = null`）＋ **Match.Initialize 装配点加性传参 `() => Engine`**。
   - 理由：受控挂载需经 `DynamicEffectFactory.Instantiate(engine, …)` 与 `engine.Prefabs`——引擎不可经卡/玩家公开面解析（`Card.Engine` 为 internal、玩家面无引擎读口）；不接线则受控面不可用。
   - 替代方案（被否）：从 target 卡解析引擎（无公开通道）；向内核加公开读面（跨层、超范围）。
2. **EffectRuntime 构造加性演进**（`Func<bool>? isActionAllowed = null`）＋ **装配点加性传参 `() => _lifecycle.IsActionAllowed`**。
   - 理由：需求 1 轮 2c「对局终局后 → 按『失效结果』处理、零副作用、不抛」——终局态不可观测则受控面无法给出正确失效语义（会错误执行卸载并发射信号）；读取面为既有 `MatchLifecycle.IsActionAllowed`。
   - 替代方案（被否）：不接线仅靠异常兜底（终局卸载会实际执行并发射，违背「终局门禁」先例）。

## 三、对外契约（命名定形——第 7 轮 1a「命名＝对外契约」）

- 方法（采用候选，*Async 风格）：`AttachPrefabAsync(Card, string prefabId, CancellationToken)`、`AttachSnapshotAsync(Card, string snapshotJson, CancellationToken)`、`CompileAttachAsync(Card, string dslJson, string? effectId = null, CancellationToken)`、`DetachEffectAsync(Card, EffectAttachCredential, CancellationToken)` / `DetachEffectAsync(Card, Effect, CancellationToken)`（**同名重载**）。
- 类型：`EffectAttachCredential`（挂载凭据）、`EffectAttachResult`（挂载结果·单一结构，四方法共用；Detach 场景 Credential 恒 null）、`EffectAttachStatus`（类别：Success／SourceMissing／InvalidData／CompileFailed／InstantiateFailed／MountFailed／NotFound／CrossCardOwnership／ServiceUnavailable——字面稳定、测试锁定）。

- 凭据不透明：无公开成员；csx 持有/回传/引用相等比较。全部新类型 public（csx 可引用——「csx 调门面」测试实证 csx 内可 await 调用）。

## 四、语义与实现要点

- **挂载**：统一装载链（Add 即装载）；成功判据＝实例化＋生效路径成功（被动=装载成功；主动=入列表）＋凭据有效；失败分类映射内核（实例化失败＝视图/处理器/csx 编译分类，装载失败＝OnMount/装载完成动作失败）。
- **失败回滚（完整·零残留）**：托管残留清理（光环注销→按来源撤修饰器→受益侧衔接，对齐内核装载失败清理口径）→ **静默容器移除**（零发射；「防未授权复活」——失败效果不留列表、不被幂等兜底静默复活）。重试＝重新 Attach。
- **卸载**：凭据/效果引用双向指认；成功＝实际移除命中恰发一次 `effect.removed`（含载荷 {Card, Effect}）；未命中/旧凭据失效＝NotFound；跨卡归属＝CrossCardOwnership（零副作用）；终局后＝NotFound（失效结果、不执行、不抛）。
- **编译面**：DslJson 解析→资产（默认目录懒加载/显式覆盖）→ 模板/op 存在性预检（缺失=SourceMissing）→ EffectCompiler（异常=CompileFailed）→ 缓存（**进程级**：键＝资产指纹＋effectId＋DSL 哈希）→ 统一挂载。身份：调用时指定；缺省=确定性自动（`effect.runtime.{fnv}`）。
- **资产指纹**：目录形态**每次请求重算**（文件路径＋内容哈希）——指纹不变复用解析、变化重载（「资产变更必反映」实测：改 op 模板→同 DSL 同身份重编译→行为变化）；内存形态模板以序列化内容、op 目录以实例身份标记参与指纹（op 目录无内容读面；安全方向：宁多编译不错误命中）。
- **门禁/降级**：无引擎上下文/非可操作相位/非本对局引用＝ServiceUnavailable；参数层 null/空白＝抛（语义层引用类无效一律结果化）。

## 六、N3 评估说明（沙箱/递归/放大）

- **风险机理**：①嵌套 csx＝动态挂载快照含 csx 时其 handler 经**既有求值器**编译执行——与直接书写 csx **同一沙箱/权限域**（程序集级白名单＋关键字过滤＋超时；同进程弱沙箱、非安全边界——不引入新权限面）；②递归＝「效果在运行时注册新效果」的既有属性（csx 挂链可自触发；同步链下循环表现为链增长，由宿主/既有超时机制兜底）；③放大＝动态挂载数量无门面级上限（csx 可循环 attach——总线订阅/内存增长）。
- **现状依据**：`CSharpScriptEvaluator` 既有定位＝尽力而为弱沙箱；沙箱白名单含 Orc/Orc.Game（csx 可用游戏层）。
- **本批处置**：受控方法 XML 注释**文档化**（受控入口定位/弱沙箱前提/主动施放不批/嵌套同沙箱）；**不动沙箱、不收窄 public 面**（收口留后续评估）；不做门面级递归/数量限制（需求裁定）。
- **实测证据（1 条）**：「csx调门面」测试即真实嵌套链——csx 效果 A 的 handler 内 `await runtime.CompileAttachAsync(...)` 挂载含 csx 的效果 B，B 的 csx 随后被事件触发并执行成功（csx 挂 csx 全链在既有沙箱内跑通）。

## 七、备注

- 「装载失败」实测构造：主触发器正常挂载、其它触发器无 hooks（总线拒绝挂载）⇒ 内核真实装载失败路径；门面表现＝MountFailed＋完整回滚（零残留、零发射）。

## 八、验收修复记录（2026-10-08，按验收反馈）

**缺陷 1：已销毁卡的引用类无效未结果化（已修复）**
- 修复：`RequireAttachAvailable` / `RequireDetachAvailable` 增加第 4 项判据——`!target.Life.IsAlive`（既有存活/生命周期读面）⇒ 结构化失败 **NotFound（未命中/已失效）**（"目标卡已销毁（已失效——不构成有效宿主）"；不挂载、不执行、零发射）。
  - 位置：归属校验之后（"他局卡"仍先归 ServiceUnavailable；"本局已销毁卡"归 NotFound）。
  - 映射说明：**已销毁卡 → 挂载面与卸载面均「未命中/已失效」**（卡级引用失效——销毁链不清 Owner、门面解析仍可达，故须独立判据）；对局已结束 → 挂载面「服务不可用」、卸载面「未命中/已失效」（环境级不可操作——与卡级失效区分）。死亡单位（IsDestroyed）不在本判据内（守需求"与内核 AddEffect 域一致"）。
- 补测：`失败路径_已销毁卡_挂载拒斥_零副作用`（DestroyCard 后 AttachSnapshot/AttachPrefab → NotFound＋零残留＋零发射）；既有 `托管_随卡销毁_…凭据卸载未命中` 继续通过（detach → NotFound）。

**缺陷 2：资产解析的权限类异常非结构化外抛（已修复）**
- 修复（两层）：
  ① `EffectAssetResolver.ResolveDirectory`：目录级读取失败（`IOException` / `UnauthorizedAccessException`）＝隔离为空资产（相关请求按「来源未命中」失败）；`ComputeDirectoryFingerprint`：单文件读取失败＝指纹哨兵、枚举失败＝枚举哨兵（均不外抛——安全方向：宁多编译不错误命中）。
  ② `CompileAttachAsync` 的 `EffectAssetResolver.Resolve` 调用点：结构化 try 兜底（非取消异常 → SourceMissing）——权限类/IO 安全异常一律结构化返回。
- 补测：`编译挂载_资产目录不可用_来源未命中`（目录不存在/路径指向文件）；`编译挂载_资产文件不可读_隔离_相关请求来源未命中`（FileShare.None 独占锁定 op 文件 ⇒ 指纹哨兵＋加载留痕隔离 ⇒ SourceMissing，不外抛）。权限类（UnauthorizedAccessException）与 IO 类共用同一异常过滤器路径；真实权限拒绝的模拟依赖 ACL 操作（环境相关），以可稳定复现的独占锁定路径锁定该隔离链行为。

修复后验证：构建 0 警告 0 错误；全测试套件 **1342/1342**（新增净 +3 条 = 26 条）；复跑一致。
