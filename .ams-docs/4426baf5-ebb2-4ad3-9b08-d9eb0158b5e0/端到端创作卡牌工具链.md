- **加载链**：调研文档覆盖（CardDataLoader→宿主注册→Match.Initialize→CardBase.LoadAsync→CardEffectLoader）。
- **时机链（初查）**：组件两段式（构造期/加载期）；效果装载（卡加载期实例化）→ 挂载（card.placed）→ 词条授予实例化；对局级装配（Match.Initialize / KeywordEffectAssembly）。

### 4.3 分发格式样例（继承）

- 卡牌 `*.card.json`：`{schemaVersion:1, id, name, components:[{component:"<类型名>", ...}]}`；六组件：typeCategory / factionCost / battleStats / tagData / keywords / effects。
- 预制体 `*.prefab.json`：`{schemaVersion:2, root:{id, version, mainTrigger:{...}, otherTriggers[], modings[], injects[]}}`。
- 内联效果：inline 项＝对象态（prefab JSON）或 JSON 字符串，两者读一致。
- 样本：outputs/kards-cards/ 1646 张官方卡（不含 effects）；KeywordPrefabs/*.prefab.json（含 csx 与 assemblyKey 两版）。

### 4.4 组装/装载/挂载链（本会话实读确认，2026-10-08）

- **打包**：`CardDataLoader.LoadDirectory/LoadFiles`（`*.card.json` 单文件隔离）→ `CardDataLoadResult{Definitions, Prefabs(内联), EffectDeclarations, Failures, Warnings}`（纯数据；宿主接线＝`PrefabManager.RegisterPrefab` ＋ `CardEffectRegistry.DeclarePrefab`）；内联预制体在载入期"先注册、以 id 并入声明"（装载链只处理引用）。
- **组装**：`CardBase.LoadAsync`＝〔ID 分配 → 组件两段式（加载期第一段＝内置注册序、第二段＝扩展/社区按数据体声明序）→ 效果装载 → `card.load` 广播〕；构造期组件（typeCategory/factionCost/battleStats）在卡实例构造时装配。
- **装载**：`CardEffectLoader.LoadAsync`（卡加载时点、先于 card.load）：声明解析（未知标识 fail-fast）→ 构造（执行异常隔离、工厂 null fail-fast）→ AddEffect（Add 即装载）→ 效果预制体实例化＋injects 落地（本版仅默认区段）→ 装载兜底 → 失败残留清理。
- **挂载**：`CardLoadout.MountEffect`（幂等；挂主触发器 → OnMount → 装载完成动作；失败回滚）；放置驱动 `CardLoadoutProcessor`（card.placed＝初始化＋逐效果幂等装载）；清理＝effect.removed / card.destroyed 收敛同一模板（发射恰一次 effect.removed）。
- **装载计划**：`EffectSnapshot.BuildLoadPlan()`＝【挂主触发器】→【注册事件】→【施加 moding】→【注入】有序步骤（数据与动作分离、可独立审查）。
- **效果快照版本**：`EffectSnapshot.SchemaVersion = 2`（S5 新增 injects；旧版读出＝结构化失败）；事件来源二选一（csx 内联 / assemblyKey）；触发器 `stableKey`＝定义级身份、`kind`＝主动/被动、`hooks`＝挂载点。
