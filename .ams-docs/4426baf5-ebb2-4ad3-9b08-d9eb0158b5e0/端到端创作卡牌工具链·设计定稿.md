## 一、目标与范围

按用户任务，完整梳理 DIY 路径并交付五个能力：
1. **标准分发格式/方法**（含卡牌与效果）
2. **效果加载方式与流程**（重点：加载时机声明）
3. **卡牌组装**
4. **卡牌整体序列化/反序列化**
5. **端到端全链路**（保证卡牌从 json 到游戏内卡牌）

范围界定：本批聚焦"**从分发数据（json）到游戏内卡牌**"的闭环；"卡面文本→json"的上游（效果编译管线生产驱动）不在本批（标注为后续扩展）。

## 二、现状基线（DIY 路径全景）

### 2.1 创作形态与分发数据

- 效果创作五形态（卡面文本解析／模板+DSL／预制体 JSON／csx 逃生舱／C# 类型）→ 统一落为分发数据：
  - **卡牌**：`*.card.json` v1（单卡一文件：schemaVersion/id/name/components 六组件）
  - **效果**：`*.prefab.json` v2（EffectSnapshot 三层嵌套自包含）或**卡内联**（effects.inline 对象态/字符串态）
- 内联机制：载入期"内联先注册、以 id 并入声明"——装载链只处理"引用"一条。

### 2.2 装载链 17 节点（*.card.json → 游戏内可打出卡牌）

### 2.3 关键机制校正（相对旧认知）

- **W3-A3 后"Add 即装载"**：被动效果在装载链/授予链 AddEffect 时即完成挂载（挂主触发器→OnMount→托管登记）；**"等待放置装载"语义已废除**，放置驱动（card.placed）为幂等兜底；"仅在场生效"由效果自持三策略承载（先例 `EffectRemountAndStrategyTests`）。
- 词条内嵌效果装载发生在**组件两段式第一段**（keywords 组件 loader→GrantCore）；卡声明效果在 `LoadEffectsAsync`——相邻但不同步骤，均先于 `card.load`。
- `KeywordEffectAssembly.Assemble` 实测行号 `Match.cs:695`（基线文档 :733 为旧版）。
- 效果装载计划（`EffectSnapshot.BuildLoadPlan`）＝【挂主触发器】→【注册事件】→【施加 moding】→【注入】。

## 三、设计决策（四项定稿）

### 决策 1：标准分发格式/方法

**格式（维持，不引入新格式）**：
- 卡牌＝`*.card.json` v1；效果＝`*.prefab.json` v2；卡内联两态（对象态为推荐写法，字符串态兼容读；**读宽写窄**——写出统一对象态）。
- 版本策略：schemaVersion 严格相等、不静默降级；写出固定当前版本（卡 1 / 预制体 2）。

**分发单位＝目录**：卡目录（顶层 `*.card.json`）＋效果库目录（如 `Cards/KeywordPrefabs/*.prefab.json`）；**不引入 manifest/卡包清单**（现状无依赖/版本协商需求，留作未来扩展）。

**方法（标准三段管道）**：
1. **装载（Load）**：`CardDataLoader.LoadDirectory`（卡）＋`PrefabManager.LoadDirectory`（效果库）——既有。
2. **校验（Validate）**〔本批新增实现〕：**分发预检器（dry-run）**——对分发数据做静态校验并输出结构化报告（Errors/Warnings）：读取/结构类（复用既有读入并汇总）、id 重复与冲突、**引用完整性**（卡声明的 prefab 引用在〔效果库 ∪ 卡内联〕内可解析；宿主代码注册引用标注为"不可静态判定"）、内联完整性（id 非空/不冲突）。不启动对局、不注册。
3. **注册（Register）**：宿主显式接线 `RegisterPrefab`＋`DeclarePrefab`（**维持"纯数据产出、注册由宿主完成"的既有设计原则**，不做自动注册封装）。

**不引入**：新格式版本、manifest、自动注册封装（避免破坏 S8 纯数据边界）。

### 决策 2：效果加载方式与流程（加载时机声明）

**"加载时机声明"定稿形态＝通道即声明（三时点模型）＋kind 装载开关 ＋ hooks 激活订阅**：

| 时点 | 名称 | 驱动 | 数据面"声明"载体 |
|------|------|------|------------------|
| T1 | 装配时点 | `Match.Initialize`（库装配/绑定核验/注册） | 库文件与绑定声明（`KeywordRegistry.DeclareEffectBindings`） |
| T2 | 装载时点 | 卡加载期 `CardBase.LoadAsync`（先于 `card.load`） | 卡 `effects` 组件（prefabs 引用 / inline） |
| T3 | 授予时点 | 词条授予期 `GrantCore` | 词条绑定链（词条效果库） |
| T0 | 运行期注入 | 装载链 `injects` 落地 / 动态实例化 | prefab `injects` 声明 |

- **装载时机由"效果放在哪个通道"声明**（位置即声明）：卡 effects＝T2；词条绑定＝T3；库＝供 T2/T3 引用。
- **装载与否＝`kind`**（passive=装载/挂载语境；active=不装载、施放时执行）；**激活/触发＝`hooks`＋`events`**（订阅更新、handler 绑定）。
- **不新增数据级"延迟激活/延迟挂载"字段**。理由：W3-A3 已统一"Add 即装载"（幂等、托管登记、卸载收敛）；"等待放置"曾经存在且被废除；"仅在场/条件生效"经效果自持三策略即可承载（延迟自挂载／内部状态门控／直挂靠触发时机）。重新引入会破坏统一装载语义与卸载收敛，风险显著大于收益。
- **流程规范（固化）**：各时点的驱动、顺序、失败语义按 §2.2 表执行；装载失败残留清理仅覆盖托管物（光环/修饰器），效果对象留列表属设计使然（影响重试语义——已记录）。

### 决策 3：卡牌组装

**组装链（固化现状为规范）**：
- 输入＝`CardDefinitionEntry`（id＋定义集）＋卡库/提供器＋效果注册面/预制体库；
- 构造期：构造器装配 typeCategory/factionCost/battleStats（同步、fail-fast）；
- 加载期第一段：内置 Load 相位按注册序（tagData→keywords→effects），fail-fast；
- 加载期第二段：扩展/社区按数据体声明序，隔离（未注册=隔离留痕）；
- 效果装载：`CardEffectLoader`（声明解析 fail-fast；构造/实例化隔离）；
- 广播 `card.load`——消费者查询不到未就绪状态。

**工具链层不新增"组装器 API"**：既有 `Match`＋`LoadAsync` 链即标准组装路径（先例 `OfficialCardDataSmokeTests`、`CommandTestKit`）；本模块交付＝**端到端测试覆盖**（分发数据[含写方向成环]→组装→打出→行为断言）。

### 决策 4：卡牌整体序列化/反序列化

**范围＝定义级双向**：`*.card.json` ⇄（CardDataBody/CardDefinition）**成环**（读→写→读）；写出入口＝`CardDefinitionEntry`。实例级（运行时状态导出）维持现状（`SnapshotJson` 只写不读，不在本批）。

**API 形态（采纳分析推荐 B＋A）**：
- `CardComponentRegistry` 注册项**新增 Writer 槽位**（可选参数、向后兼容；未提供 writer 的扩展组件＝写出隔离报告）；六组件静态 Write 作为 Reader 对称载体。
- `CardDataJson.Serialize`（对称 Deserialize；camelCase、读宽写窄、schemaVersion=1）。
- `CardAttributeMap` **新增反向映射**（Exact 反转 16 项；Valued 反转 Armor+value→`heavyArmorN`、Intelligence+value→`intelN`；老兵链前缀拼接 `BecomesVeteran:`/`VeteranOf:`）；正向 API 不动。
- 类别/单位类型反向词表（Command→order、Counter→countermeasure、单位类型→官方小写词）。
- `ComponentText` 写辅助（按需）。

**写出策略**：
- keywords：**Attributes 保真优先**（原始英文标识全量按序写回）；无 Attributes（代码构造卡）时**反向合成**；无法还原项＝**警告输出**（不静默丢失）。
- effects：**默认 prefabs 原样引用＋inline 全对象态**（提供策略参数可切换）；两区分组保序。
- 组件写序：按定义集顺序（保序对称）；文本级规范化（无注释/尾逗号、固定缩进），**语义级保真**。
- 目录级：`SaveDirectory`（卡：单卡一文件 `<id>.card.json`，对齐 LoadDirectory 口径）；效果侧落盘对称（`PrefabManager` 侧补 SaveDirectory/SaveFile——命名照卡侧口径〔批 2 grill 裁定，弃 WriteFile〕；效果文件 `<root.id>.prefab.json`）。
- 新增写入不留静默损失：Serialize 产出警告集（如无法还原关键词条）。

**测试要求**：逐组件 round-trip（参值型/老兵链/未映射属性/tags）→ 整卡 round-trip（dug_in、102_grenadier、内联效果样本）→ 目录 round-trip → **全量 1646 张（outputs/kards-cards）读→写→读语义等值**；既有测试零回归。
