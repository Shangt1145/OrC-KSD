## 四、核心能力清单（已验收）

1. **触发器系统**：主动/被动触发器、事件与 band 优先级（C# 枚举 + 二选一保护）、嵌套触发、Stop/Interrupt、异常隔离；
2. **事件流**：树形日志（ID/自动挂载/attach 含父子 ID/冒泡/扁平关键词）→ 树形 JSON 序列化（本地条目语义：条目归属写入流、树中恰一次）；
3. **总线**：更新字符串+载荷、Mount/UnmountOwner、参考优先级（升序）+注册序、更新入流、挂载/卸载留痕；
4. **组件与效果**：卡牌=薄容器（数据/逻辑组件）、Effect 基类（OnMount/OnUnmount）、放置装载/移除清理、注入（具名 band）+装载登记自动撤销（LIFO）；
5. **流程**：攻击（发起方）/伤害结算（承受方）分离、施放流程 SpellFlow（Counter→Resolve→Finalize，反制检查位）；
6. **输出**：事件流 JSON、快照 JSON（单实体从引用导出 + 全量登记）、三骨架（IEngineBridge / LogicEngine 公开面 / Subscribe 回调；含最小真实接线）；
7. **Lua**：从脚本源定义 handler、`Invoke(参数包)→Result`、通用动态编组、硬沙箱（17 名封锁）、动词白名单（orc.*）、六类结构化错误（防伪造分类）、环境隔离。
