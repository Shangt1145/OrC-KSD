# 需求 — 游戏环境（KARDS 模仿）

在 Orc 触发器引擎之上搭建游戏环境：整体模仿 KARDS 游戏逻辑。本批（第一批）＝**对局骨架**（数据结构＋回合轮转）。
**状态：需求 grill 已完成（2026-10-03）**——全部决策见下；细则确认：abcde 全部采纳。

## Scope
- Includes（本批）:
  1. **工程**：`src/Orc.Game`（引用 Orc）+ `tests/Orc.Game.Tests`；追加 OrcEngine.sln；无新外部依赖。
  2. **集合类**：`CardList`（卡牌 id 序列，可重复、有序）/ `CardSet`（卡牌实例集合）——`Shuffle`（对局级随机源）/ `Insert` / `Draw`（取首张并移除）/ 名单→引用集 `Instantiate`（经卡牌库）。
  3. **卡牌基础数据组件**：花费（部署费）/ 行动点数（行动费）/ 攻击力 / 防御力（＝HP）——引擎"数据组件"（强类型类）形态，挂卡牌；本批仅承载字段。
  4. **卡牌库**：id → 定义（代码注册）；名单实例化经由它（JSON 载入后续）。
  5. **战场**：三线（己方支援线 / 前线 / 敌方支援线＝`CardSet`）；容量 4/5/4（配置字段；校验后置）。
  6. **玩家**：资源（指挥点数＋指挥点槽）＋ 卡组（`CardList`）＋ 手牌（`CardSet`）＋ HQ（20 血，数据；占支援线一格）。
  7. **对局 `Match`**：引擎（LogicEngine）、双玩家、回合数、当前行动方、状态、战场、随机源；**初始化**＝生成并初始化各管理器（回合/玩家/战场/资源/卡牌库）。
  8. **回合体系**：5 个更新 hook 按序 Emit——`turn.start.before` / `turn.start` / `turn.start.after` / `turn.end.before` / `turn.end`；回合开始处理＝槽+1（至自然上限 12，可配置）→ 点数＝槽值 → 抽 1（先手第 1 回合不抽）；回合结束不保留剩余点数。
  9. **通用更新**：`card.played` / `card.drawn` / `card.stat.changed`（**数值更新无载荷**）——常量＋发射 API（打牌调用点后续批次）；抽牌基础版（起手：先手 4 / 后手 5；回合抽：发 `card.drawn`）。
  10. **验收**：五项锚点＋骨架场景（双人对局·两回合循环）。
- Excludes（后续批次）: 战斗/移动/前线完整规则；卡牌效果体系；胜负判定；调度（重新调度）；容量校验；卡组构造校验；数据 JSON 载入。
