## 四、关键约定速览（交接必读）

1. **触发器**：一个触发器一个 ContextView；band＝C# 枚举＋二选一保护；事件签名 `Task(view, ctx, ct)`；三形态触发入口（统一/具名重载/字典透传）；
2. **合法性验证**：`Validate`（virtual，默认恒合法）→ InvokeAsync 固定先调；不合法＝仅本次取消；合法后错误捕获兜底（Outcome 三态）；
3. **更新体系**：字符串常量＋载荷；底层/外部触发器分层（轻量标注、靠自觉）；排序＝升序（小值先）；`card.played` ≠ `card.placed`；
4. **目标选择**：Targeter 两阶段桥接（收集＋交互＋应答器）；粗筛（UI 列表→允许子集；未返回项前端置黑）＋细筛（单引用回调）；槽位 Single/Multi；
5. **游戏规则**：仅部署扣费；移动仅推进（支援→前线）；KARDS 矩阵（坦克双动/相邻/任意/烟幕/守护）；反击豁免判定表；HQ≤0 立即终局；词条＝逻辑组件（数值由效果模块维护）；单位化＝部署/加入共用触发器；
6. **流程纪律**：需求→grill（double-grill 两阶段）→定稿→委托（CodeImplementation＋useGrill）→验收（抽查＋全量回归）；红线：不触碰其他工作包的源文件、不 git 提交、不用 Source Generator、net8.0＋C# 12。
