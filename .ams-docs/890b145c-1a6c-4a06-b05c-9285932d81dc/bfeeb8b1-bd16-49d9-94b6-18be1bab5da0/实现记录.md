## 六、专项说明：`Guard_State…` 场景重建（最大重构条目）

**为何必须重建**：HQ 居中后，支援线任一可部署位的邻格最多一侧（槽 1/槽 3 另一侧为 HQ 占位；槽 0/槽 4 仅一邻格）——「两个守护者夹持一个单位」在支援线**几何上不可表达**，且"支援线单位移动"（仅推进）与"守护者被夹持"无法叠加（Q&A-2(b)：无法逐字复现的前提按新布局等价关系重建）。

**原意图 → 新构造映射**（覆盖意图逐项保持）：

| 原意图面 | 新构造 | 覆盖保持 |
|---|---|---|
| Join 触点（入场触发维护）：X 入场 False；G1/G2 入场 True | A 前线 X@槽 2 先入（False）＋G1@槽 1／G2@槽 3 入场（True） | ✓ |
| 多守护源（移走其一仍保留） | B 双巨兽（B 支援线）各一次真实攻击：击杀 G1 后 X 仍被守护（G2 在） | ✓（"移走"→"击杀"；前线单位不可移动〔移动源须∈支援线〕） |
| 死亡触点：G2 死 → X 失去被守护 | 再击杀 G2 → X 失去被守护 | ✓ |
| 移动触点＋HQ 联动：G1 走、G2 死 → HQ 不获 | 独立移动段：Y@槽 0＋守护者 H@槽 1（HQ 左邻）——H 移动走 → Y／HQ 失去被守护（Y 与 HQ 同段验证"移动触发维护"） | ✓ |
