## 一、模式设计点清单

### 1. 效果制品形态（构造/装配方式）

- **制品形态**：C# 类型的效果（复用批 1 基类 `KeywordSignalEffect` 的 `PassiveEffect` 子类 `BlitzDeployEffect`）——效果体系正式对象；延续批 1/2。
- **装配方式**：词条组件**构造期**经 `EmbedEffect` 注入——授予链自动装载、移除/死亡注销/回滚自动卸载；不另起私有挂载体。
- **制品集**（`KeywordEffects.cs` 批 3 区域；复用基类、无新增基类）：`BlitzDeployEffect`（闪击·部署置位——监听 `GameUpdates.UnitDeployed`）。

### 2. 生灭五路径表达

| 路径 | 承载 | 说明 |
|---|---|---|
| 装载 | 词条授予链（`GrantCore`）→ 组件 `EmbeddedEffects` 逐一 `AddEffect` | 订阅建立于效果 `OnMount` |
| 卸载 | 词条移除链（`RevokeCore`）→ 内嵌效果逆序 `RemoveEffect` | 订阅撤销于效果 `OnUnmount`（幂等） |
| 死亡注销 | `RevokeOnDeath` → 效果卸载 | 行为撤销；登记/参值保留 |
| 回滚 | `RollbackGrant` → `RemoveEffectSilently` | 通道级复用＝**申报引用**（批 0 已验「装载失败→整体回滚零残留」） |
| 复装 | 移除后再次授予（新效果实例）→ 标准装载链 | 专项覆盖（含同实例独立卸载/复装） |

### 3. 信号订阅挂点（订阅建立/撤销）

- **建立**＝效果 `OnMount`（`KeywordSignalEffect` 基类：宿主卡 → `KeywordRules.TryGetKeywordManager` → `LoadContextProvider` → `context.Engine.Subscribe`）；
- **撤销**＝效果 `OnUnmount`（`Dispose`，幂等）；
- 独立构造（脱离对局）＝上下文不可达＝不订阅（功能不可用、加载不失败）。
- 「效果订阅先于部署信号已建立」基线成立（词条装载先于 `card.load`/部署；批 1/2 同模式已验证；本批由 mid 观测点置位已发生实测证实）。

1. **置位时点前移**（扣费后 → `unit.deployed` 发射时；接受依据既定）：仍先于可指挥读取（置位在打出链内完成、链返回后玩家方可发起指挥）；未来如引入部署收尾信号可再归位。mid 观测点适配恰 1 处（断言＋伴随注释/方法名）。
