## 一、机制层设计点清单

### 1. 词条效果库（数据壳制品落点）

- **目录**：`src/Orc.Game/Cards/KeywordPrefabs/`——`*.prefab.json`×3（制品集）；随程序集输出
  （`Orc.Game.csproj`：`<None Update="Cards/KeywordPrefabs/**/*" CopyToOutputDirectory="PreserveNewest" />`——
  沿 EffectParsing 资产拷贝先例）；默认目录＝`AppContext.BaseDirectory/Cards/KeywordPrefabs`
  （`KeywordPrefabLibrary.DefaultDirectory`——沿 `EffectTemplateLoader.DefaultDirectory` 先例）。
- **形态**：**复用既有预制体体系**（不另造平行格式/通道）——`EffectSnapshot`（schemaVersion 2）：
  触发器/hooks 结构面＋行为引用（`assemblyKey` → C# 委托）；命名沿用既有「预制体」体系。
- **制品集**：`keyword.blitz.deploy-set`（hooks: `unit.deployed`，stableKey=闪击·部署置位）／
  `keyword.mobilize.accrual`（hooks: `turn.start`，stableKey=动员·回合累积）／
  `keyword.mobilize.loss`（hooks: `card.damaged`，stableKey=动员·受伤失去）。
- **装载通道**：既有 `PrefabManager.LoadDirectory`（单文件失败＝隔离记录、不阻断其余——报告承载）。

### 2. 词条级绑定面

- **落点**：注册面（`KeywordRegistry` 加性）——`KeywordEffectBinding(PrefabId, EffectName)` 记录＋
  `DeclareEffectBindings`（声明面）／`GetEffectBindings`（装载期查询）／`EnumerateEffectBindings`（装配期核验查询）。
- **生产内建绑定**：注册面静态构造声明（闪击→1 项；动员→2 项；声明序＝装载序）；键常量登记处＝`KeywordEffectAssembly`；
  注销（`Unregister`）随词条一并清理绑定。
- **校验**：词条须已注册（注册先于绑定）；非空白/不重复/非空集；重复声明拒绝（注册即配置）。

### 3. 装载期实例化点

- **落点**：`KeywordManager.GrantCore` 装载链 ②（`component.Mount` 之后、内嵌效果遍历之前）——
  `AttachKeywordEffectPrefabs`：`context.Engine` 可用时经 `DynamicEffectFactory.Instantiate` 逐项实例化
  （实例化名＝绑定 `EffectName`——卡容器效果检索面契约），以 `KeywordComponent.AttachDataEffect`
  （加性内部面）接入内嵌效果通道——随词条生灭（装载/卸载/死亡注销/回滚/复装同一条遍历链）。
- **失败语义**：`context` 为 null（独立构造）＝不实例化/跳过（功能不可用、加载不失败）；
  库键缺失 / 实例化失败（handler-missing/signature/装配异常等）＝fail-fast（异常上抛——授予链整体回滚、零残留）。

### 4. 行为引用生产注册面

- **落点**：`KeywordEffectAssembly.Assemble(engine, libraryDirectory?)`——**单一装配入口**（单一时序点承担两者）：
  ①行为引用注册（键 → 委托×3）；②词条效果库装载（`KeywordPrefabLibrary.LoadInto`——预制体注册；单文件失败＝
  隔离记录＋引擎总流留痕「词条效果库」）；③绑定核验（全部绑定 → 库键可解析；缺失＝装配期 fail-fast）。
- **挂点**：`Match.Initialize`（管理器群装配收尾、洗切/加载之前）。**不变量**：正常对局初始化后，任何词条装载时
  行为引用与库键均已就绪/可解析。**选择依据**：该时点绑定清单（注册面静态内容）与库内容（默认目录）均可获得——
  「不可行」判据不成立；两段（行为引用/库装载）皆先于任何词条装载（洗切→加载→起手），核验点在两者之后。
- **幂等/多对局**：每对局＝新引擎实例、各自装配（重复注册＝拒绝——「注册即配置」）；幂等以生命周期结构达成
  （Initialize 恰一次、重复被拒绝）；多对局天然隔离（引擎级 PrefabManager 实例）。
- **非功能性**：装配＝对局一次性的目录扫描＋注册（常量级）；装载期实例化＝按授予次数（常量级）。

### 5. 试点行为引用目标（单源）

- `BlitzDeployEffect`／`MobilizeAccrualEffect`／`MobilizeLossEffect` 改造为**行为引用目标**类
  （私有构造＋静态 handler：`HandleDeploySetAsync`／`HandleAccrualAsync`／`HandleLossAsync`；
  签名 `Func<CardEventView, Context, CancellationToken, Task>`；条件/过滤/守卫保留在行为内部——数据壳仅承载
  触发器/hooks＋行为引用结构面）；不再继承 `KeywordSignalEffect`（原效果实例订阅路径退役）。
- 壳（`BlitzKeywordComponent`／`MobilizeKeywordComponent`）不再构造 C# 效果（构造签名保留——公共契约面零删除）。
