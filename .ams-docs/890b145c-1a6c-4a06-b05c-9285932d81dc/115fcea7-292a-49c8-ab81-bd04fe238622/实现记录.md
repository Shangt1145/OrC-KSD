## 一、模式设计点清单

### 1. 效果制品形态（构造/装配方式）

- **制品形态**：C# 类型的效果（`PassiveEffect` 子类）——效果体系正式对象（进入既有效果装载/生命周期链）；延续批 1 形态。
- **装配方式**：词条组件**构造期**经 `EmbedEffect`（内嵌效果通道）注入——由 `KeywordManager` 装载链在授予时自动装载、
  移除/死亡注销/回滚时自动卸载；不另起私有挂载体、不短路装配。
- **制品集**（`src/Orc.Game/Cards/KeywordEffects.cs` 批 2 区域扩充）：
  - `KeywordDamageRewriteEffect`（新基类——伤害改写族统一承载：「解析对局上下文 → 装载准备检查 → 向
    『造成攻击伤害』触发器注册改写 handler」/「卸载撤销＋清位」；`OnLoading`（false＝不注册）／`OnLoaded`／
    `OnUnloading` 派生钩子）；
  - `AmbushRewriteEffect`（伏击·伤害改写）、`ArmorReductionEffect`（重甲·减伤）、`ImmuneZeroingEffect`（免疫·归零）。

### 2. 生灭五路径表达

| 路径 | 承载 | 说明 |
|---|---|---|
| 装载 | 词条授予链（`GrantCore`）→ 组件 `EmbeddedEffects` 逐一 `AddEffect` | 效果随词条授予自动装载（注册建立于效果 `OnMount`） |
| 卸载 | 词条移除链（`RevokeCore`）→ 内嵌效果逆序 `RemoveEffect` | 效果随词条移除自动卸载（注册撤销于效果 `OnUnmount`） |
| 死亡注销 | `RevokeOnDeath` → OnRevoke 序列＋运行逻辑注销＋内嵌效果卸载 | 行为撤销；登记/参值保留 |
| 回滚 | `RollbackGrant` → `RemoveEffectSilently` | 通道级复用（批 0 已验「装载失败→整体回滚零残留」）＝**申报引用**，不逐效果重做失败注入（无定制装载步骤） |
| 复装 | 移除后再次授予（组件重建→新效果实例）→ 标准装载链 | 复装后二轮卸载仍自动撤销（专项测试覆盖） |

### 3. 注册挂点（注册建立/撤销）

- **建立**＝效果 `OnMount`（装载链「挂主触发器 → OnMount」的 OnMount 步）：上下文解析 → `OnLoading` 通道检查 →
  `context.AttackDamageTrigger.Register(HandlerName, handler)`；
- **撤销**＝效果 `OnUnmount`：`Unregister`（幂等）＋上下文/通道引用清位；派生类通道引用清位经 `OnUnloading`（伏击）。
- **上下文解析路径**＝宿主卡 → 词条管理面（`KeywordRules.TryGetKeywordManager`）→ 词条装载上下文提供器
  （`KeywordManager.LoadContextProvider`——与词条组件运行逻辑同一上下文来源）→
  「造成攻击伤害」触发器注册口（`AttackDamageTrigger`）。独立构造（脱离对局）＝上下文不可达＝不注册（功能不可用、加载不失败）。
- 注册名保持：「伏击改写」「重甲减伤」「免疫归零」（注册面名称不变——日志/追踪连续）。

### 4. 防御语义（伏击——等价硬验收项）

- 无装载上下文→不注册；两个判定器通道（`CounterEligibility`／`AmbushCondition`）任一缺失→不注册
  （`OnLoading` 返回 false）；均不抛错；**不回退直调（单源约束）保持**。
- 通道引用保存于 `OnLoading`、清位于 `OnUnloading`（与注册状态一致；重复卸载幂等）。

### 5. 参值运行期读取（重甲）

- 减伤量**每次伤害结算时**经词条读取面读取（`KeywordRules.GetKeywordValue`——非装载时快照）；参值改写后随动；
  参值 null／0＝无减伤（「重甲 0」语义等效）。
- 参值钳制（[0,3]）保持于壳（构造 `Clamp` ＋ `OverrideValue` 覆写）；`AppliesToCommandDamage` 公开面保留
  （默认 false、可设置性不变、本批不接线）；`ArmorRules.IgnoresArmor` 读点保留不动（效果内照旧读取）。

### 6. 双宿主（免疫——非对称性逐条保持）

- 单位侧＝上下文注册路径（要求上下文；无上下文＝不注册）；HQ 侧＝HQ 宿主即挂「归零改写器」
  （`Hq.AddDamageRewriter`——**不依赖装载上下文**；不得因「上下文不可达＝不处理」跳过 HQ 侧）。
- 来源标记＝**效果实例**（原组件实例改签——见 §三.1「内部改签清单」）。

### 7. 壳化边界与壳内残留清单（核实成立）

- 伏击／重甲／免疫三枚组件收薄为壳：不再覆写 `Mount`/`Unmount`、不再注册/注销、不做时序决策；
  仅保留非行为面——①构造期 `EmbedEffect` 装配（模式的装配点）；②重甲：参值面（读改写）＋钳制＋公开属性。
- **壳内残留清单**：伏击＝无行为性残留；重甲＝参值（读改写面）/钳制 [0,3]/`AppliesToCommandDamage`（公开面保留）；
  免疫＝无行为性残留（与需求预期一致）。
- 不动面确认：读点（`ArmorRules.IgnoresArmor` 等）、防护判定、`AppliesToCommandDamage` 公开面、Targeter 体系零改动。

### 8. 注释同步

- 组件类注释与文件头注释同步（反映壳形态——`KeywordComponents.cs`／`KeywordComponents2.cs`）；
- 效果制品集注释（批 2 制品与注册/注册承载方式——`KeywordEffects.cs` 文件头「批 2 词条效果化」段）；
- 服务/系统注释小改（`KeywordServices.cs` 文件头＋`ArmorRules` 类注释；`KeywordSystem.cs`「伏击组件」→「伏击效果」×3、
  `AttackDamageTrigger` 描述 →「改写注册口」）——均为注释（无行为面）。

## 五、连接件评估（AC⑤；Q&A-3 口径）

- **评估结论：零扩展。** 本批未新增/修改任何机制面 API（未用加性扩展即完成模式；公共面签名/机制语义零变更）。
- **既有通路清单（逐点）**：
  1. 词条装载上下文提供器路径：`KeywordRules.TryGetKeywordManager(Host)?.LoadContextProvider?.Invoke()`
     ——与词条组件运行逻辑同一上下文来源（批 1 模式，已验）。
  2. `KeywordLoadContext` 既有通道：`AttackDamageTrigger`（注册口——2C 既有）＋ `CounterEligibility`/`AmbushCondition`
     （K2 加性既有）——无新增字段。
  3. 触发器注册面：`Trigger<TView>.Register/Unregister`（S4 加性既有 public 面——注册名/默认优先级保持）。
  4. 公有读取面：`KeywordRules.GetKeywordValue`（重甲参值）；`ArmorRules.IgnoresArmor`（读点）；
     `Hq.AddDamageRewriter`/`RemoveDamageRewriter`（HQ 挂载 API）。
- **零扩展依据（逐点职责等价）**：
  - 伏击：注册/撤销（Register/Unregister）与判定链（CounterEligibility/AmbushCondition）全部经既有通路——
    与原组件所用 API 完全一致（同一注册口、同一判定器通道），仅承载主体由组件改签为效果。
  - 重甲：参值读取经既有 `KeywordRules.GetKeywordValue`（`manager.GetValue` → 组件 `Value`——同一数据源、运行期读取）；
    减伤登记 `resolution.AddDamageReduction`、无视重甲读点 `ArmorRules.IgnoresArmor` 均为既有面。
  - 免疫：单位侧同伏击模式；HQ 侧经既有 `Hq.AddDamageRewriter/RemoveDamageRewriter`（与原组件相同）。
- 「csx 门面/工件封装」：本批不作为要求、未实施（未来「制品数据化」方向记录；Q&A-3(3)）。
