# Requirements — 老兵与隐蔽（模板效果补全）

为 Orc 引擎的"老兵""隐蔽"两个词条机制补全模板效果及所需配套，使卡池中老兵/隐蔽类卡面文本可经效果解析器表达、可运行。

> 状态：Grill 第 4 轮（规格确认中，2026-10-06）。第 1 轮：交付＝解析表达层＋机制底座（b）。第 2 轮：升级＝就地形态切换；隐蔽设计初稿。第 3 轮：升级组件替换细节；隐蔽改为"保留原定义＋判定器豁免＋隐蔽标记"。

## Scope
- Includes:
  - **老兵机制**：组件替换式就地升级（清空损伤/修饰；数据组件＋词条组件直接替换为老兵版本）、"升为老兵"触发器（由卡牌老兵触发效果自托管调用）、"升为老兵"事件、老兵读取面。
  - **隐蔽机制**：单位数据中声明隐蔽状态；"无法被卡牌效果影响"（效果影响范围判定器剔除、隐蔽判定器管辖）；揭示（先移除隐蔽标记→调揭示逻辑）；主动揭示动作；"可以指向隐蔽单位"例外（判定器改写）；"揭示"事件。
  - **解析表达层**：词法＋模板效果＋op＋语义映射（"升为老兵""揭示""老兵单位""隐蔽单位"等）。
  - 官方数据映射：`BecomesVeteran:` / `VeteranOf:` / `covert` 转正式承载。
- Excludes: 明牌/情报执行面；呈现层（卡背——仅保证可监听触发器）；"魔免"本体（仅架构预留）；G19/G21 其余。

## Constraints
- 构建 0 警告；既有测试全绿；P1/P2。〔沿用批次口径〕
- 资料口径：可用者对齐、不可考者申报、不自行发明。〔默认执行，异议请提出〕
- 术语入 CONTEXT：老兵（升级/触发器）、隐蔽（状态/揭示）、隐蔽判定器等。

## Requirement Items

### R1: 老兵机制（组件替换式升级）
- Status: Draft（第 4 轮确认）
- Behavior（规格）:
  - S1 升级＝就地组件替换：清空损伤与临时修饰；**数据组件（数值）与词条组件直接换成新的**（老兵版本内容）；单位实例保留（ID/位置不变）；不触发死亡/离场。
  - S2 **"升为老兵"是触发器**；由卡牌的老兵触发效果（自托管主/被动）触发。
  - S3 升级完成**经触发器**对外广播"升为老兵"事件（监听面："升为老兵时，X"／"友方（敌方）单位升为老兵时，Y"）。
  - S4 读取面："老兵单位/若是老兵"＝读取单位当前组件内容（升级后＝老兵版本数据／词条，含 `VeteranOf` 类标识）。〔N2 确认〕
  - S5 解析层：词法（"升为老兵""老兵单位"）、模板效果（升为老兵类监听）、op（升为老兵）。
- Acceptance:
  - [ ] "在场上的第三回合开始时，升为老兵"＋"升为老兵时，对敌方总部造成3点伤害"链路可跑。
  - [ ] 升级后数值/词条＝老兵版本；实例不重建；不触发死亡。

### R2: 隐蔽机制（状态＋判定器豁免＋揭示）
- Status: Draft（第 4 轮确认）
- Behavior（规格）:
  - S6 隐蔽＝**单位数据中声明的状态**（加载时 `covert` 映射）；无实体切换/占位。
  - S7 豁免：隐蔽单位**无法被卡牌效果影响**（效果影响范围判定器剔除——含光环类，如"相邻陆军"不作用于隐蔽单位）；[N1 边界确认]；"可以指向隐蔽单位"类例外经判定器改写实现（本轮实现）；"魔免＝无法被指令指向"仅架构预留（隐蔽为更高级别）。
  - S8 揭示＝**先移除隐蔽标记 → 调揭示逻辑**（执行"揭示：X"）；触发条件＝被攻击／主动攻击／主动揭示动作（直接触发揭示触发器）；完成发"揭示"事件（含"友方隐蔽单位被揭示时"监听）。
  - S9 读取面："隐蔽单位"筛选由判定器承载（lambda 全局过滤）；"处于隐蔽回合数"由单位额外逻辑组件自行注册 handler 监听回合结束（效果层自管）。
  - S10 解析层：词法（"揭示""隐蔽单位"）、模板效果（揭示类监听）、op（揭示）。
- Acceptance:
  - [ ] "部署：揭示1个隐蔽单位"、主动攻击/被攻击揭示链路可跑。
  - [ ] 指令/效果不可作用于隐蔽单位；例外卡（可指向）可改写生效。
