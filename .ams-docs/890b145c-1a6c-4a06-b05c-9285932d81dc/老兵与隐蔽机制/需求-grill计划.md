### R1 老兵复述 → 用户裁定
- a) **清空**；数据组件与词条组件**直接换成新的**（老兵版本内容）。
- b) **"升为老兵"是触发器**；由**卡牌的老兵触发效果**来触发（"老兵触发效果自己托管自己的主/被动效果"——卡自身效果结构自托管）。

### R2 隐蔽复述 → 用户裁定（设计修正：放弃"隐蔽通用单位"方案）
- 不用隐蔽通用单位；**全部保留原定义**（原实例/数值/词条照常）。
- 豁免＝从**卡牌效果影响范围的判定器**中剔除（隐蔽单位同时纳入"隐蔽判定器"的范围）。
- 在**单位数据里声明隐蔽状态**。
- 揭示＝**先移除隐蔽标记 → 再调揭示逻辑**（不切换实体）。
- 魔免＝「无法被指令指向」；**隐蔽更高一级＝无法被卡牌效果影响**（如"相邻陆军"类无法影响隐蔽单位）。
- b) 主动揭示动作：**做**（直接触发揭示触发器）。
- c) "隐蔽单位"筛选＝**判定器负责**（内部 lambda 全局过滤）、不专门造机制；"处于隐蔽回合数"＝**单位额外逻辑组件自行注册 handler** 监听回合结束（效果层自管）。
- d) 呈现层同意（保证有 UI 可监听的触发器即可）。
- e) 例外卡（"可以指向隐蔽单位"）：**实现**。
