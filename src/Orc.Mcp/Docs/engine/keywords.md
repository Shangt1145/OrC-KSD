# 词条（Keyword）

词条是卡牌的固有属性：**定义期声明、加载时装载**。词条标识是全局受控词汇（`KeywordRegistry`）。

## 声明方式（卡数据体）

```json
{ "component": "keywords", "keywords": ["blitz", "smoke"] }
```

有参词条按模板效果填槽（参值经 `keywords` 组件携带）。词条效果的行为由**词条效果库**（`KeywordPrefabs/*.prefab.json`）承载：词条注册面声明"词条 → 效果预制体 id"的绑定。

## 内置词条（19 枚，内建插件进程级注册）

内建插件（`orc.builtin.core`）在进程级注册面登记内建词条与 6 个内置卡组件。
**完整清单不要手抄**——用 `diag.hooks` 或 `diag.report` 读取当前运行时注册面；沙盒模式可让 agent 自行枚举。

## 沙盒里注册自定义词条

- 进程级：词条注册走 `KeywordRegistry`（注册即配置；同名重复注册＝拒绝，覆盖须显式用 `RegisterOrReplace`）。
- 卡包级：卡包目录内的 `keywords.json` 声明"词条 → 效果绑定"，由卡包词条加载器在包装载/重载时登记（**卸载不注销**——注销须冷重启）。
- **跨包同名直接拒绝**（不得劫持既有词汇）。

> 进程级副作用提示：沙盒内的词条注册**不随沙盒局结束回滚**（`sandbox.state` 的 `processStateNotes` 会留痕）。长迭代建议定期重启服务进程。

## 与卡牌/效果的关系

- 词条**行为**以「效果」承载（词条效果化）：组件是壳（标识/参值/授予-移除），行为在效果预制体里。
- 词条的读取口是**判定器**与服务面的组合：效果里判"是否有某词条"应经既有读取面（如 `KeywordRules`/判定器），不要自行解析组件字典。
