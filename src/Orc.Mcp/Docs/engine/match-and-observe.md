# 对局状态与观察面

## 对局状态

- `state`：`Preparing`（准备）→ `InProgress`（进行）→ `Ended`（结束）。**准备态与终局后，输入类入口一律拒绝**。
- `phase`：换牌（mulligan）/ 进行等相位。沙盒建局使用 `SkipMulligan = true`、起手 0 张，故建局后直接处于进行态。
- `turn`、`currentPlayerIndex`、`winnerIndex`、`endReason` 由 `observe.view` 给出。

## 观察面（沙盒：全知）

| 工具 | 内容 | 消费性 |
|---|---|---|
| `observe.view` | 摘要：状态/相位/回合/双方手牌与卡组计数/指挥点/HQ 血量/手牌明细 | 可重复读 |
| `observe.snapshot` | 全量实体快照：每个实体的 `entityId`、名称、存活、**组件字段**（反射导出） | 可重复读 |
| `observe.segments` | 事件流段（一次动作产生的因果条目树） | 引擎侧**取走即移除**；服务层保留最近 N 段缓存供重复读 |
| `diag.audit_chain` | 声明期触发器关系图（谁挂在哪个 hook、下游依赖） | 可重复读 |
| `diag.hooks` | 信号/判定器/触发器分层清单（事件名与判定器名的**权威来源**） | 可重复读 |

## 事件（信号）

- 事件名是**开放集合**、无白名单；权威清单见 `diag.hooks`（`GameUpdates` 31 条 + 内核 4 条 + 载荷键常量）。
- 载荷键也是受控常量（如 `Card`/`Player`），大小写敏感。
- 投递事件用 `sandbox.emit`：返回 `subscriberCount`；为 0 时带 `no-subscriber` 警告——**投递只能命中已存在的订阅者**，外部无法新增订阅者。

## 段与因果

- 一次"动作"（动作作用域）结束时，引擎把本轮产生的信号聚合成一个**事件流段**（含本段条目与因果子树）。
- 典型段条目包含信号名、级别、来源与载荷摘要；用它判断"某个效果到底跑没跑、跑了哪些信号"。
- 段是**拉取式**的：`observe.segments` 拉一次取走一次；服务层缓存保证还能回看最近 N 段。

## 对象引用

- 实体的稳定标识＝`Entity.Id`（**N 格式 GUID 字符串**，如 `observe.*` 输出里的 `ref`/`entityId`）。
- 无 `Id` 的对象（如玩家）由其引用键（`players[].ref`）表达；**同一对局内稳定，重建对局后变化**——不要跨对局复用。
- 目标选择候选另有**会话内序号**（见 targeting 文档）：候选由引擎给定，外部不得自造。
