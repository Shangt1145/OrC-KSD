# 卡牌数据体持久化与加载 — 决策摘要

本域记录"卡牌数据体持久化与加载"任务的关键决策摘要。术语权威定义见项目根 `CONTEXT.md`；
需求与实现定稿见同目录 `requirements.md`、`implementation.md`（grill 过程见两份 grill 计划）。

## Decisions

- **数据体形态**（2026-10-05）：元数据（`id` / `name`）＋ `components` 组件定义集；明文 UTF-8、单卡一文件（`*.card.json`）、目录扫描；**相同项对齐官方语义**（`type` 为列表、`set` 不入体、`kredits`→部署费、`operationCost`→行动费）；Orc 额外项（`name` / `tags` / `inline` 效果的 `injects`）另加。
- **组件模型**（2026-10-05）：组件＝**定义**（实现"可反序列化组件"接口、自校验 fail-fast）＋ **loader**（装配到卡）；**静态注册面**注册序＝第一段顺序；**两段式**（第一段＝内置按注册序、第二段＝扩展/社区按数据体声明序）；构造期组件（`factionCost` / `battleStats`）在卡构造时装配；`CardDefinition` 的组件集为**唯一真源**，既有 12 参数构造与全部读面保留（内部派生）。
- **`RebuildFromPersistence` 退场**（2026-10-05）：其"持久化重建"职责由组件 loader 模型取代，扩展点删除；等价能力＝扩展组件 loader。
- **词条分流**（2026-10-05）：数据体写**官方英文标识**，经代码常量映射表转 `KeywordIds`；参值后缀（`heavyArmor1` / `intel2`）显式拆解；未实现项（`guard` / `shock` / …）进 `UnmappedAttributes` **只读留痕**（不 fail-fast、不写日志）。
- **效果接线**（2026-10-05）：数据体 `effects` 组件仅作**声明**（`prefabs` 引用 id 或 `inline` 内联文本）；内联＝**载入期分配/校验 id → 注册预制体 → 并入声明**（装载链因此只有"引用"一条）；引用时要求**预制体注册面先于卡加载就绪**。
- **注入落地**（2026-10-05）：`EffectPrefab.injects`（`{ target, band, event, priority }`）→ 装载链**框架侧**经 `Effect.InjectByFramework` 注入**宿主具名触发器**（宿主卡按名解析；本版仅支持默认区段）；`EffectSnapshot.SchemaVersion` **1 → 2**（旧版＝结构化失败）。
- **部署逻辑收敛**（2026-10-05）：废弃 A4 路径（`DeploymentLogicData` / `Registry` / `LoadContext` / `Rules` 与加载链步骤整体删除）；`UnitCard.DeployKeywordTrigger`（默认区段）取代之——部署链①段与"重放部署"共用同一触发器（**不发射链级信号**）；部署类效果经效果 ＋ `injects` 表达。
- **范围与验收**（2026-10-05）：不做导出方向、不做热重载、展示/本地化字段（`title`/`text`/`image`/`set`）不入体；验收＝构建 0 警告 ＋ `Orc.Tests` 298 / `Orc.Game.Tests` 707 / `Orc.Script.Tests` 9 全绿；官方导入脚本 `scripts/import_kards_cards.py` 产出 1646 张（`outputs/kards-cards/`；官方语料无效果字段）。
- **运行时组装保留**（2026-10-05）：`DynamicEffectFactory.Instantiate` → `AddEffect` / `MountPassiveEffects` 的手工路径与代码效果工厂路径均保留、语义不变。

## Decisions（写方向补全 · 2026-10-08）

- **写方向（导出）立项**（批 1 grill 确认；修订 2026-10-05「范围与验收」中『不做导出方向』）：卡牌数据体写出＝**定义级双向**（`*.card.json` 读→写→读成环，供创作工具链）；运行时状态导出（快照）不属写方向。
- **组件写出器（Component writer）**（批 1 grill 确认）：组件 loader 的对称面——把组件定义写回数据体组件对象的**字段部分**（`component` 类型名由序列化器按注册面**单点注入**）；注册面**可选槽位**（缺省合法；写出时＝隔离警告＋跳过）；含**警告通道**（不可还原项必须上报、不静默）。
- **写出隔离口径**（批 1 grill 确认）：整体性非法＝fail-fast 抛出；组件级（未注册／无 writer／写入异常／无反向项）＝警告集＋跳过/降级、不阻断（对称读侧）。
- **keywords 写出判据**（批 1 grill 确认）：`Attributes` 非空＝**唯一真源**（全量保真写回、不比对、不警告）；为空＝**反向合成**（老兵端口吸收「老兵」标记；不可还原项＝无反向映射／参值非法／Exact 带值／端口空白 → 警告，不静默）。
- **写出空值规范**（批 1 grill 确认）：组件在场时其集合字段一律显式写出（空＝`[]`）；组件不在场不写组件（保结构）。
- **写方向警告判据**（批 1 grill 确认）："生成物读回时必然与源不等值或被拒"＝警告＋照写（不静默、不降级伪造）；读回成功者不警告（语义可疑不属写方向职责）。
- **落盘契约**（批 1 grill 确认）：目录自动创建；单卡失败＝隔离报告（非法 id 拒绝、批内重复首见写、同 id 重存覆盖）；目录准备失败＝整体抛出；结果＝成功/失败/警告分列。
- **写方向验收口径**（批 1 grill 确认）：全量往返按"读面＋组件集逐字段等值"（保真路径列表逐项一致）＋"四空"硬指标（Serialize 警告／Save 失败／再读 Failures＋Warnings）；全量测试用临时目录、outputs 缺失跳过，样本用例内嵌自含。
- **写出文本契约与诊断**（批 1 grill 确认）：默认多行缩进 2 空格（开关可选）／LF／尾换行／UTF-8 无 BOM／固定键序；J1==J2 幂等为字节级硬性；警告＝卡 id＋组件名＋项原文＋原因类别（中文关键词区分）。
- **无载体面与字段集冻结**（批 1 grill 确认）：数据体字段集冻结、不新增字段/组件类型；无载体字段（IsGuard）＝警告＋照写、不发明 v1 载体；卡级完整性（缺必填槽位）不属写方向警告面。



## Decisions（写方向补全·批 1 · 2026-10-08）

- **写出入口**：卡牌序列化写方向入口＝`CardDataBody`（数据镜像）与 `CardDefinitionEntry`（id＋定义）两形态；`CardDefinition` 无 id（外部携带）；六组件字段集冻结——不新增数据体字段/组件类型。
- **写方向警告判据**：命门＝"生成物读回时必然断裂或与源不等值"；整体性非法＝抛出，组件/项级＝警告集（可达、可定位、不静默）；无 v1 载体的定义字段（如 `IsGuard`）＝警告＋照写不落盘。
- **keywords 双路径**：Attributes 保真优先（全量按序原样写回、零警告）；Attributes 空＝反向合成（无反向映射/参值不可表达（值≤0）/裸「老兵」标记＝警告；`VeteranOf` 端口吸收「老兵」标记）。
- **空值规范**：组件在场＝必写、集合字段空＝`[]`；组件不在场＝不写组件；写序＝定义集顺序（保序对称）。

- **文本契约与幂等**：2 空格缩进多行＋LF＋尾换行＋UTF-8 无 BOM＋固定键序；"写→读→写"字节级幂等（J1==J2）为 round-trip 硬指标；全量 1646 张"四空"（Serialize 警告/Save 失败/再读 Failures/Warnings）硬验收。

## Decisions（分发预检器·批 3 grill · 2026-10-08）

- **分发预检器（Dry-run validator）**（批 3 委托 grill 确认）：对分发数据（卡目录＋效果库目录；多目录合并）做**纯只读静态校验**、输出结构化报告（Errors/Warnings 分列＋汇总）；不注册进引擎、不建对局（库侧经 `PrefabJson` 静态读取，不经 `PrefabManager` 实例）。
- **输入形态与边界**（批 3 委托 grill · 第 1 轮确认）：卡/库目录均支持多个；单边输入合法；全空＝参数异常；显式目录不存在＝报告 Error（不静默）；空目录＝零 Error。
- **重复/冲突与引用级别**（批 3 委托 grill · 第 1 轮确认）：跨目录同卡 id、跨库同 prefab id、跨来源（库×内联等）同 prefab id＝Error（运行期注册必然冲突）；同一目录重复传入＝校验器去重（不假重复）；引用未解析＝Warning（宿主代码注册可能提供、静态不可排除）；Error 仅用于可确证问题（目录不存在/重复/读面 Failures 映射）；报告确定性纳入验收。
