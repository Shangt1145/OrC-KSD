# Requirements — 游戏层对局端到端流程文档

为 Godot 前端开发者产出一份贯通「游戏层（Orc.Game）对局端到端流程」的文档，把各类游戏机制流程与可介入/可观察的 hook 位置对齐到同一条时序上，降低前端开发阻力。

## Scope

- Includes:
  - 单文档（引擎仓 `d:/OrC-KSD/docs/`，新建独立文档，与既有报告并列/交叉链接）。
  - 多流程端到端描述（对局时序为主轴，逐步骤）＋ hook 在流程中的位置。
  - 效果体系总述一节（DSL / 模板效果 / 效果预制体 / 装载链 / injects 落地）。
  - 调试工具一节（事件流日志、触发器序列化/快照；含内核面标注）。
  - 口径＝**实况 + 显式缺口标注**。
- Excludes:
  - 前端侧 UI 实现细节/桥接代码实现（只给"对接要点"，不给实现代码）。
  - 一切源代码（C#/csx）与模板 JSON 内容（只引 id/文件名）。
  - 信号目录全文、输入点签名表全文（改为链接既有文档）。
  - 注：**分文件之间允许内容重复**（为保自包含），但信号名/载荷键等权威值仍只引代码常量。

## Constraints

- 术语遵循根 `CONTEXT.md`：正文用「接入点/观察面/扩展点」；开头说明与内核窄义词 "hook" 的关系。
- 不制造第二真源：信号名/载荷键/判定器名以代码常量为唯一权威，文档引用而非改写。
- 以**符号名（类型.方法）**为准；行号仅作参考基线；标注基线日期 2026-10-07。
- 文档内不直接放源代码。

## Requirement Items

### R1: 交付形态与落点
- Status: Confirmed
- Behavior: 引擎仓 `d:/OrC-KSD/docs/` 新建独立端到端流程文档（多文件）；与既有文档交叉链接。
- Acceptance:
  - [ ] 文档位于 `d:/OrC-KSD/docs/`，为新建文件。
  - [ ] 含指向既有文档的链接，且不与其重复。

### R2: 流程覆盖清单（全收）
- Status: Confirmed
- Behavior: 覆盖 ①–⑲：①初始化 ②换牌 ③回合 ④资源结算 ⑤卡牌管理 ⑥单位打出+部署 ⑦指令打出 ⑧反制 ⑨指挥/移动 ⑩交战 ⑪伤害 ⑫死亡 ⑬重触发 ⑭目标选择(异步倒置) ⑮终局收尾 ⑯修饰器/光环 ⑰关键词 ⑱初始化补充(卡牌加载/效果初始化/判定器初始化与预定义moding) ⑲调试工具。
- Acceptance:
  - [ ] 上述每项有独立小节。
  - [ ] 每项含"分步骤（步骤→代码位置→语义）"。

### R3: 缺口标注（口径乙）
- Status: Confirmed
- Behavior: 未实现/后置机制在对应流程处显式标注"当前不支持 / 后置"，与 `GameHooks.PendingTriggers` 一致。
- Acceptance:
  - [ ] 文档含缺口标注，且与 `GameHooks.cs` 待补层一致。

### R4: hook 的口径与粒度
- Status: Confirmed
- Behavior: 按「接入点/观察面/扩展点」三类；**逐步骤标注 + 末尾总索引表**；不贴代码。
- Acceptance:
  - [ ] 每个流程步骤标明可介入/可观察 hook。
  - [ ] 末尾有"hook → 流程/步骤 → 类别 → 接入方式"总表。

### R5: 效果预制体引用（乙）
- Status: Confirmed
- Behavior: 以 `*.tpl.json`（模板效果）为主，逐步骤标 id + 末尾总表；追加「效果体系总述」一节；`*.prefab.json` 概念级提及。
- Acceptance:
  - [ ] 含"流程步骤 ↔ 模板效果 id ↔ inject 目标触发器"总表。
  - [ ] 含效果体系总述节（含装载链与 injects 落地）。

### R6: 每流程小节模板（乙）
- Status: Confirmed
- Behavior: 每流程小节固定含：触发/前置｜分步骤表（步骤｜代码位置｜语义｜发射信号｜hook）｜关联效果预制体｜前端对接要点｜能力现状。mermaid 仅给主干链（初始化、回合、打出/部署、交战、死亡、终局）。
- Acceptance:
  - [ ] 各流程小节结构一致。
  - [ ] 主干链 6 条含 mermaid 时序图。

### R7: 前端对接要点
- Status: Confirmed
- Behavior: 每流程含"前端对接要点"：该观察哪个信号 / 需实现哪个桥接 / 常见坑。
- Acceptance:
  - [ ] 每流程小节含该栏，且信号名与 `GameUpdates` 常量一致。

### R8: 真源与时效
- Status: Confirmed
- Behavior: 以符号名为准；行号仅参考；标注基线日期 2026-10-07。
- Acceptance:
  - [ ] 开头声明"以符号名为准、行号会漂移"+ 基线日期。

### R10: 渐进式阅读（agent/人友好索引）
- Status: Confirmed
- Behavior: 主索引文件须支持**渐进式阅读**——读者（尤其 AI agent）只能先读主文件，据"任务→最相关文件"路由表**只读 1–2 个最相关分文件**；按需再依分文件内的"内容边界/相关文件"索引追加，**而不是一次性全读**。
- Acceptance:
  - [ ] 主文件含「任务→最相关文件」路由表（每条给 1–2 个文件，非全部）。
  - [ ] 每个分文件开头声明自身**内容边界**（含/不含）与**相关文件索引**（指向下一跳）。
  - [ ] 允许分文件间内容重复以保自包含（重复限于流程背景；信号名/载荷键等仍以代码常量为权威，不另立第二目录）。
