## Scope

- Target：对局全流程——**建局→起手（静默）→mulligan→回合循环→行动→战斗→胜负/认输→终局**，使游戏可完整运行一场。
- 范围裁决（折中 c）：**纳入** mulligan、认输/投降；**显式不做** 天气、疲劳、烧牌、开局特殊卡（startInHand/autoUse）、老兵升级。
- 规则参数：以 OrC 现行 4/5/4 ＋现指挥点曲线为准，**不对拍** kards-diy（其 6/5）。
- Excludes：效果表达力；UI/AI/网络。

## Implementation Steps

### S1: 对局相位模型 `MatchPhase`
- Status: Done
- Target：`Match/Match.cs`、`Match/MatchState.cs`、`Match/MatchLifecycle.cs`、`Match/MatchPhase.cs`(新)
- Approach：
  - **`MatchState` 末尾加性追加 `Mulligan`**（既有值 `Preparing=0`／`InProgress=1`／`Ended=2` 不变——H2 裁决）。
  - **`MatchPhase { Mulligan, Play, Ended }` 为派生投影**（公开读面 `Match.Phase`；单一真源＝`MatchState`，不独立存储——避免双真源）；准备态读取＝抛错。
  - `Initialize` 末尾序列调整为：…→起手装载（静默）→ **置 `Mulligan`**（不再直接执行先手第 1 回合）；先手回合延后至双方确认（见 S2）。
  - **装配开关**：`MatchOptions.SkipMulligan`（缺省 `false`＝按 A1 序列；`true`＝既有序列：直接执行先手第 1 回合＋置"进行"）。
  - 重复 `Initialize`／准备态推进＝照旧抛错。
- ✅ **受控变更（已授权 A1=a）**：2A 冻结的「初始化序列＝…→**先手回合开始序列**（3 条更新入总流）→置进行」正式变更为"置 `Mulligan`、先手回合延后到双方确认后执行"。逐条差异登记见文末。
- Acceptance:
  - [x] `Initialize` 后 `Phase == Mulligan`；动作入口在非 `Play` 相位被拒。
  - [x] 旧→新序列差异登记；受影响测试受控随改（总数不减——经装配开关＋新用例，见实施记录）。
- Terminology: [对局](../game-environment/CONTEXT.md)、[准备/进行](../game-environment/CONTEXT.md)

### S2: mulligan 重调度（**特制槽位**）
- Status: Done
- Target：新增 `Managers/MulliganManager.cs`、`Match/Match.cs`、`Targeting/*`（加性）
- Approach（**M1=b ＋ M2=a 裁决**）：
  - **特制槽位**：新增 `Targeting/MulliganSelectSlot.cs`（`HandSelectSlot` 的特化）；`TargetSlotKind`／`TargetSlotPresentation` 末尾加性追加 `MulliganSelect`——前端据此**识别"开局换牌"并播放专属动画**（区别于常规手牌选择）。候选＝该方手牌引用快照、域判定强制（"仍在手牌"）、数量 `0..手牌数`（`min=0`＝不换牌、合法）、槽位参数＝该玩家。
  - **唯一对外入口**：`Match.BeginMulliganAsync(player, ct)`——发起特制槽位交互；确认＝"退回卡组 → 重洗（发 `deck.shuffled`）→ 抽等量（静默，不发 `card.drawn`）"并**自动确认该方**；**取消＝零副作用**（不换、不确认）；空手牌＝零交互直接确认（避免死锁）。
  - `Match.MulliganDone(player, ct)`＝**不换牌直接确认**（第二入口）。
  - **双方确认** → 置 `Play` 并执行先手第 1 回合（`turn.start.before`/`turn.start`/`turn.start.after` 三连，恰一次）。
  - 静默口径对齐 2A「起手静默」：换牌不产生 `card.drawn`／`card.hand.add`；洗切恰一条 `deck.shuffled`；交互本身不产生 `GameUpdates` 信号（仅留痕）。
  - 相位门禁：mulligan 期间出牌/指挥/结束回合/认输一律拒绝。
- Acceptance:
  - [x] 仅 Mulligan 相位可换/可确认；非法＝明确拒绝且零副作用（已确认/非相位/终局＝类别化拒绝）。
  - [x] 双方确认后相位→`Play` 且先手第 1 回合序列恰一次。
  - [x] 换牌重洗恰一条 `deck.shuffled`，无 `card.drawn`。
- Rationale：kards-diy `mulliganReplace`/`mulliganDone`（§2.3）＋ M1=b（专属动画需专用槽位标识）＋ M2=a（统一 `Begin*` 预行为形态）。
