# 卡牌引擎（触发器系统）—— 决策摘要

本领域文件记录触发器系统相关的关键决策摘要；完整术语定义见项目根 CONTEXT.md。

## Decisions

- **视图权限闸门语义**（2026-10-03 · S1 委托 grill 确认）：ContextView 属性访问采用运行期逐次拦截——[Read] 写入、未声明访问在访问当刻抛 PermissionDeniedException；[Optional] 缺省读取返回 default；拦截由框架统一提供，视图作者"声明即工作"；绑定期必填校验（EnsureRequired）与访问期拦截并存。


- **ctx 载体与共享边界**（2026-10-03 · S1 委托 grill 确认）：Context 创建时允许对入料字典拷贝一次（对齐设计文档 §4.2），此后保持单一 Data 载体；视图绑定与属性读写全程直连载体、不得拷贝；"共享而非拷贝"验收聚焦同一 Context 内（跨执行改写互相可见）。


- **S1 触发器壳契约**（2026-10-03 · S1 委托 grill 确认）：执行入口显式接收 Context；执行委托为视图单参（Task、无返回值、无取消令牌）；触发器无状态；异常不隔离、原样传播（隔离策略留 S2）。


- **S1 视图会话契约**（2026-10-03 · S1 委托 grill 确认）：视图经 Binder 公共入口创建（同入口原则；显式传视图类型 + Context）；每次执行会话新建实例；Seal 幂等、异常路径不跳过、不放松权限矩阵；单视图约束以泛型构造固定（编译期）。


- **S1 可演进边界**（2026-10-03 · S1 委托 grill 确认）：视图作者契约＝最小偏离的可代理形态（使用面不变；切 Source Generator 时仅写法微调收敛）；冻结面＝IContextView.Bind/Seal、异常与特性类名、Context 构造/读 API、Binder 创建入口；委托参数集为 S2 受控变更点。


- **S1 引用类型契约**（2026-10-03 · S1 委托 grill 确认）：Ref 仅库内可构造（外部经持有者获取）；失效防线＝属性 getter + Value 双层（无批量预检；IRef 类抽象留后续）；Entity 不封闭、Destroy 只杀不管卸载（卸载通知留 S3）；Kill/Destroy 幂等。


- **S1 绑定与写入契约**（2026-10-03 · S1 委托 grill 确认）：必填缺失（缺键或值为 null）绑定前抛 KeyNotFoundException；[Mutate] 可增改新键；@ContextView 必须标注（未标注拒绝）；异常断言以类型为准、不锁消息。


- **S1 交付口径**（2026-10-03 · S1 委托 grill 确认）：文件清单=预期性质（少量新增、不删除、汇报列实际清单）；交付物不含文档类文件（说明归汇报）；不引入 InternalsVisibleTo；缓存不要求行为级测试。


- **S1 作者契约终局**（2026-10-03 · S1 委托 grill 确认）：作者只写"类 + [ContextView] + 特性属性"（不声明 IContextView——框架侧契约、框架产物运行时实现，计入偏离记录）；触发器壳不带名称/标识（严格最小）。


- **S1 属性声明合法性**（2026-10-03 · S1 委托 grill 确认）：主特性互斥——[Read]+[Mutate] 同标＝绑定期拒绝（参数类异常）；无有效主特性的属性不参与必填、访问期一律拒绝；执行入口与创建入口的 null 参数均防御拒绝。


- **S2 触发入口与转接契约**（2026-10-03 · S2 委托 grill 第 1 轮确认）：触发入口三形态（同一 InvokeAsync 重载族，收敛于统一入口）——①统一入口（框架提供；接收『引擎引用＋数据字典＋可选取消令牌』，以数据创建 ctx、返回事件流、不隐式转接）②具名重载（作者侧书写，经手写转接汇入①）③字典透传（①的直接使用、零加工，"入料拷贝一次"沿用）。转接＝作者视图类上的手写静态方法（框架不建强制契约、不隐式调用）；引用以同一 Ref 实例入（共享、可被 [Mutate] 改写）、值以快照入（双向独立、不禁止 ctx 内改写）。


- **S2 band 方案与注册契约**（2026-10-03 · S2 委托 grill 第 2 轮确认）：band＝C# 枚举（可指定值；触发器装配期声明方案：默认枚举或专门枚举，运行期只读）；二选一保护——默认枚举（仅 default=0，可省 band 注册）／专门枚举（必须显式成员；省略 band 报错、拒绝默认枚举成员；允许 0 值成员）；注册＝枚举成员引用＋优先级（默认 0），构造期初始集合＋运行期追加并存（S4 注入基座）；越界/负值/溢出＝装配/注册期明确拒绝；同值成员为别名（同一区段）。触发器 Kind 默认主动（S2 仅标识、运行期可读）；名称可选；事件名允许重复（仅定位用，不查重）。


- **S2 触发器公共面与 S1 迁移**（2026-10-03 · S2 委托 grill 第 3 轮确认）：触发器保持单泛型 Trigger<TView>；band 方案经构造面显式声明（不得由注册隐式推断）；注册＝双重载（无 band／带 band），二选一保护＝注册期运行校验拒绝（错误须可行动）；band 参数容纳任意枚举成员（Enum/泛型约束方向）。S1 旧构造（单委托）不保留兼容层、由新形态取代；S1 测试迁移适配、保持验收语义覆盖（共享/绑定失败/防御），基线＝迁移后全套测试全绿。


- **S2 嵌套链与 Stop/Interrupt 语义**（2026-10-03 · S2 委托 grill 第 4 轮确认）：每次执行（含嵌套）各自独立 ctx；"共享"仅限同一触发器内（跨触发器数据仅显式传递、不继承）；嵌套关系由框架自动感知（执行栈）；检查点＝事件边界（in-flight 事件必跑完；已中断链上不再启动新执行）；Stop 仅本级；Interrupt 沿链向上传播（所在层及祖先层停其剩余事件，含子层），最外层正常返回事件流、不外抛，可查根 ctx 状态；中断写入事件流。


- **S2 事件流挂载/冒泡/条目规范**（2026-10-03 · S2 委托 grill 第 5 轮确认）：挂载＝执行会话级自动（多子流挂同一父流；执行结束后持久保留、不封口）；冒泡＝逐级至根、kind 全量、视为同一条目、写入时序、无裁剪；attach 写父流（最小集含父/子流 ID）；level 固定四档、timestamp=UTC、keywords 扁平（允许 key:value）、data 可空；公共读面＝ID/父引用/条目枚举/子流枚举；写 API＝log 与 update 公共面存在且可测；框架自动写最小集＝attach/异常隔离/Stop 与 Interrupt；验收⑥＝经公共写 API 写入含关键词的 log 条目。


- **S2 引擎引用与 LogicEngine 最小壳**（2026-10-03 · S2 委托 grill 第 6 轮确认）：引擎引用＝LogicEngine 实例（统一入口/Translate 首参同一概念；链上期望恒定、不强制；仅影响顶层挂载目标，链中挂载恒随触发者流）；框架不自动注入引擎进 ctx（作者自由；嵌套触发推荐闭包捕获或经 ctx 数据，两者皆合法）；允许多实例、无单例；顶层挂载自动至传入引擎总流；LogicEngine 严格止于总流＋顶层挂载（总线等留 S3）；链标识不需要（ChainId/Depth 不落地，链由事件流树表达）。


- **S2 异常隔离与取消语义**（2026-10-03 · S2 委托 grill 第 7 轮确认）：隔离捕获＝除取消类外全部异常；绑定失败与 Translate 异常＝执行前失败、原样传播（不隔离、不写隔离记录；Seal 不跳过）；取消类（is OCE 含派生）穿透各层不隔离、直至最外层（拿不到 EventStream；已写入条目保留）；隔离记录硬性＝kind(log)/level(Error)/source/message/keywords 含异常类型名（data 自由）；隔离不回滚、记录失败不反噬；框架不主动检查 ct（透传义务成立；验收以主动 throw OCE 为准）。


- **S2 方法级边界与工程口径**（2026-10-03 · S2 委托 grill 第 8 轮确认）：顶层流父引用＝总流对象（总流为根；读面同时暴露流对象与 ID）；空转执行＝产空流、挂载（含 attach）、不执行事件、不绑定视图（验收以执行序列缺失为准）；"不启动新执行"分两层（后续事件不被触达；in-flight 内调用被调用但空转）；一次执行＝一个视图实例、结束 Seal 一次（异常不跳过）；S1 工程红线全部延续；S1 测试文件可同文件重组（保留、语义不变）；验收③基准确认。


- **S2 Trigger 开放性与终极口径**（2026-10-03 · S2 委托 grill 第 9 轮确认）：Trigger 开放继承（S4"继承＝额外注入"基座；属受控变更）；继承者契约＝不绕公共执行入口/注册面、不引入新可变状态面、泛型约束不破坏；对外执行面唯一（统一入口；RunAsync 不保留对外形态）；source 统一为"触发器名/事件名"（未命名退化；attach 同构）；验收证据沿用 S1 口径；实现择定项＝最小化＋汇报、冲突暂停反馈。


- **S4 效果装载与职责边界**（2026-10-03 · S4 委托 grill 第 1 轮确认）：装载＝放置更新（card.placed）驱动：挂主触发器→OnMount（注入）；卸载＝OnUnmount（清理）→总线卸载；主触发器 hooks 覆盖放置/移除类（至少移除类）；职责分立＝框架（注册/注销模板、挂载/卸载、接线、顺序与幂等）／主触发器（效果运行时代表）／作者（OnMount/OnUnmount）；主动效果不挂总线、不装载（施放时调用）；完整口径见 S4 需求阐明记录（8aa8c7aa）。


- **S4 清理/撤销与流程验收**（2026-10-03 · S4 委托 grill 第 2 轮确认）：清理＝实际撤销注入（注册表移除，非短路）＋总线卸载＋登记/引用清除；多效果隔离列为专项验收；RemoveEffect＝列表移除＋可重装＋已放置后 Add 即时装载（不得静默死效果）；流程验收＝伤害结算先于回血（强制）、分离观测＝独立触发/子流结构＋次序断言、施放＝"施放→伤害结算"用例覆盖；装载/清理留痕支撑验收。


- **S4 容器与生命周期入口语义**（2026-10-03 · S4 委托 grill 第 3 轮确认）：容器键＝类型（重复 Add 同类型拒绝、多类型共存、命名多实例后置）；GetData 缺失抛明确异常（不返回 null）；数据类任意、引用共享（外部可改字段）；范围＝AddData/GetData+AddEffect/Effects+RemoveEffect；载荷：effect.removed 含卡牌+效果、card.destroyed 含卡牌；销毁规范入口＝一步式辅助（杀+发更新）、两步合法；移除幂等（重复/不存在不抛错）、双路径均有覆盖（RemoveEffect 与 effect.removed）；多卡牌隔离列入验收。


- **S4 Effect 钩子契约**（2026-10-03 · S4 委托 grill 第 4 轮确认）：主动效果不执行钩子（纯列表进出）；撤销＝框架按装载期登记自动（作者 OnUnmount 只写专属清理）；作者上下文＝宿主卡牌（含数据）+注入目标获取路径（形态自由）；钩子可多次成对（移除→复装即再次 OnMount）；重复 Add 同一实例拒绝；验收④＝调用与否/次序/失败隔离/上下文可获得。


- **S4 验收基线核对**（2026-10-03 · S4 委托 grill 第 5 轮确认）：增补＝重复 Add 同一效果实例拒绝、移除不存在幂等明确、多效果顺序确定性并入；降级＝攻击 band 全序可降级、放置后 Add 非核心、两步/护盾减伤用例可选；对称性/留痕不单列（隐含）；数值/数据类/标识/留痕粒度＝实现自由（汇报说明）。


- **S5 事件流 JSON 导出语义**（2026-10-03 · S5 委托 grill 第 1 轮确认）：树形 JSON 节点 entries＝本地条目（语义 B——每条目恰在其写入流节点出现一次、不重复；内存读面含冒泡不变）；导出范围＝以传入流为根的子树（总流导出＝整棵树）；本地/冒泡区分＝新增只读能力优先（加性、汇报）；形式细节＝实现择定+汇报，验收锁结构＋字段值内容；格式最终定稿留用户。


- **S5 快照 JSON 语义**（2026-10-03 · S5 委托 grill 第 2 轮确认）：单实体输入＝引用/卡牌对象皆支持；标识＝实体标识符必输出（首选新增加性 Entity.Id，备选 Name+重名限制记录）；失效目标＝降级输出不抛（null 参数仍参数异常）；components＝类型简单名（同名限制记录）+公共可读属性+复杂值确定性处理且不递归（防环）；全量＝引擎卡牌登记（加性、创建即注册、销毁即移除、多实例独立）+逐卡复用单实体结构（空集合法）。


- **S5 三骨架验收语义**（2026-10-03 · S5 委托 grill 第 3 轮确认）：底线＝最小接线真实贯通（桥＝宿主编译期实现、引擎在更新广播时真实调用；Subscribe 挂引擎、订阅单位＝更新、多订阅者+取消注册+回调异常不破坏主流程）＋公开面梳理注释（XML，不强制新增入口）＋轻量冒烟断言（1~3 条，非完备行为）；桥未装配可跳过、桥异常不破坏主流程；完备行为留后续。


- **S5 场景 1 反制/中断验收语义**（2026-10-03 · S5 委托 grill 第 4 轮确认）：反制＝效果形态经既有装载/注入接线（施放链具名检查位；禁 hack 路径、不做完备机制）；观测面＝(i)伤害不发生＋(ii)中断留痕（事件流）＋(iii)失败可查询；两路径端到端断言（最终状态＋事件流关键结构）；"中断"＝反制引起的 Interrupt（不强制 Stop/独立演示）；语汇实现自由。


- **S5 反制位点与装配语义**（2026-10-03 · S5 委托 grill 第 5 轮确认）：位点归属＝引擎层共享（施放流程/SpellFlow 或等效，与 AttackFlow 同构；反制者不需知道具体法术）；检查位由框架统一提供；装配＝完整链首选/最小等效装配允许（公共机制）；关联引用（引擎级载体）经装载提供可接受、具体施放信息经执行上下文（非预绑）；多反制依既有"中断即停"语义。


- **S5 测试集整合交付口径**（2026-10-03 · S5 委托 grill 第 6 轮确认）：交付＝场景 1 新增＋JSON 断言（树形含归属不重复＋快照单实体/全量/失效降级＋空情形轻量）＋全量回归＋场景 3 核对结论（缺口才补）；文档类产出不追加、汇总进汇报；组织/数量/命名/施放流程命名＝实现自由（须自证对应验收点）。


- **验证输入面与调用语义**（2026-10-03 · 验证委托 grill 第 1 轮确认）：信息面＝验证者须能到达目标对象本体（存活前提下可解引用、读取类型与数据）；签名不得仅用「标识+存活」面，定型候选＝强类型引用列表（Ref<Entity> 或等效，实现定型+汇报）。触发时收集＝data 第一层值中的引用类对象（不递归容器、按引用相等去重、保持插入序、无引用=空列表）；外部预检由调用方自行组织、无框架收集工具；内外同一判定源、无缓存短路。验证自身异常＝契约兜底路径（捕获+记录+失败标记+安全结束；不按"不合法"、不直接外抛；取消类穿透）。验证契约补充：只读无副作用、保持轻量；输入面以引用为限（资源类检查归调用侧）。
