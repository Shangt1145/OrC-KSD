# Targeter 指示器（目标选择）

Orc.Game 对局内目标选择框架（前端桥接的选择交互）的术语表。2026-10-03 建立。

## Language

**Targeter（指示器）**:
一次目标选择的请求对象（携带筛选器与槽位）；唯一发起入口为其 Targeting 方法；可串行复用（每次独立结果）。

**Targeting**:
发起并等待一次目标选择的异步过程；经 Manager 排队、经桥接等待前端；终局恰好一次（Complete 或 Cancel）。

**TargeterManager**:
对局内的全局 FIFO 串行队列（防冲突）；对局管理器群"第六员"（经 Match 公开面读取；支持独立构造供测试；随 Initialize 加性生成、桥接经 Match 构造可选参数注入）；与桥接一对一绑定；桥接缺失＝失败结局（不抛）；多 Manager 互不干扰。

**前端桥接（Targeting Bridge）**:
后端与前端的交互通道：Begin（请求描述：允许子集/槽位/请求标识）→ 玩家操作 → Complete(refs)/Cancel()。方法级契约：候选收集每次 targeting 恰一次；请求标识由后端生成、随请求描述提供、终局回传校验归属；Complete 提交面统一按槽位组织（扁平＝缺省槽位承载）；Cancel 带标识无其他参数；留痕可观测且纳入断言。（2026-10-03）

**允许集（Allowed Set）**:
两级筛选后的可选引用集合——粗筛（**批量式**：列表→允许子集）＋细筛（**逐项谓词**：单引用回调）；两级均可缺省（全通过）；后端只产出"允许什么"，前端负责未返回项与淘汰项的置黑显示。

**Targeting 结局**:
成功（携带产出引用，只读）/ 取消（前端主动放弃）/ 失败（系统原因；**原因类别化**——至少覆盖：无可用候选、候选收集失败、桥接交互异常、筛选回调异常、其他兜底）；以统一结果对象表达、不抛异常。


**候选提交（Candidate Intake）**:
前端在**出队执行时**经桥接「候选收集」入口提交的"当前可交互引用完整列表"（粗筛输入；执行时收集保证新鲜度）；null 防御性剔除；收集/筛选失败＝失败不抛（统一失败模式）。


**选择槽位（Slot）**:
Targeter 的选择结构声明（最小集：SingleSelect、MultiSelect(min,max)；**可缺省**——缺省＝单一选择）。min=0 允许空选完成、max≥1、关系构造期校验；无/单槽位＝**扁平产出**（视图属性写入），多槽位＝**非扁平**（结构化，ctx 强类型写入）；后端对 Complete **校验数量与成员（⊆允许集）**，违规＝拒绝（不构成终局）＋留痕＋继续等待。**多槽位**：一次交互完成全部槽位、按槽位组织提交（槽位名业务方声明）、每槽位独立约束、跨槽位重复默认允许。**收尾规则**：名非空、互不重复（构造期拒绝）、无数量上限；单槽位名可省略（归缺省）；缺省承载稳定可引用；声明构造期固定。（第9轮）


**结果写入（Result Write-Back）**:
targeting 产出的写入＝**显式**（业务方执行；框架不自动写；类型化辅助入口可用）；键名自由、重复即覆盖；**产出为引擎引用类型**（前端提交截面可弱类型，后端规范化）。调用位置：ctxv 内（主路径）/ handler 内（允许；写入后后续事件可读取）。（2026-10-03）


**用法模式（Usage）**:
独立（targeting→产出作参数，链路证明）/ 请求对象传参（接收方发起）/ 结果传参（消费方使用）；两种用法（a/b）分别须测试证明，可与位置范式合并覆盖。（2026-10-03）


**引用与规范化（Reference & Normalization）**:
产出元素＝引擎引用类型（库内构造、可失效校验；类型面〔如 Ref<T>/IRefInfo〕实现定型并汇报）；前端提交元素应承载引用实例（object? 仅容器型别）；规范化在粗筛前完成、粗筛/细筛回调只见规范化后引用；无法规范化元素＝剔除单项、最终空→无可用候选失败；失效引用＝可规范化保留（有效性归筛选）；终局校验附加"仍有效"（失效＝内容不合规）；产出防护沿用引擎防线。（2026-10-03 第8轮）


**留痕（Trace）**:
失败与违规路径的可观测记录；渠道＝对局用引擎既有渠道、独立构造注入优先/未注入降级可观测记录；覆盖所有失败与违规；断言范围含收集失败/交互异常/内容不合规/标识不匹配/未装配。（2026-10-03）


**流程隔离（Isolation）**:
每请求状态独立（收集/筛选/交互中间状态不跨请求泄漏）；复用与后续请求不受前一次失败/取消/违规影响；实现自定；隔离性纳入测试。（2026-10-03）


**非引用候选（Non-Reference Candidate）**:
不经前端收集、非引擎引用的一类选择候选（效果选项、卡牌定义名单）；由槽位声明/请求构造携带、随 Begin 请求描述交付；不经收集/规范化/筛选链；终局校验＝「∈声明集」。
_Avoid_: 弱类型候选

**扩展槽位类型（Extended Slots）**:
槽位类型族新增（库内派生）：选项槽位（OptionSelect，非引用、单选）、手牌选择槽位（HandSelect，己方手牌引用＋域校验「仍在手牌」＋专属呈现）、卡牌选择器槽位（CardPicker，形态构造期声明二择一：定义级名单〔产出标识、消费方生成实例〕／引用集〔产出引用〕；中央多卡呈现→选择→确认）。

**候选通道与槽位类别（Candidate Channel & Slot Classes）**:
槽位三类——①既有普通引用类（前端收集＋筛选取允许集）②新引用类（构造方允许集、不经筛选链）③非引用类（声明/载荷集合）；候选来源与类别一一对应；组合＝框架一般能力（无禁配、名互不重复）；含既有引用类的混合请求收集恰一次（仅服务既有引用类）；校验真源＝后端。

**产出读取面扩展（Outcome Read-Out）**:
引用产出沿用 Ref 读面（Single/List/GetSelection）；非引用产出按槽位名读取（与引用读面并列、类别可辨）；混合槽位按名组织、不依赖顺序；不允许弱类型快照。


**选项条目（Option Entry）**:
选项槽位的声明单元：标识（非空、集内唯一、分派与断言键——"分支"即消费方按标识分派的行为约定、非独立字段）＋文本（非空、仅呈现用、不要求唯一）；文本随请求描述交付、不进入产出（产出仅选中标识）；重复标识＝构造期拒绝。

**提交面按类别承载（Typed Submission）**:
统一提交入口按槽位类别承载选择元素（引用类＝引用；非引用类＝标识）；一次提交覆盖全部槽位（含混合）；校验逐槽位按类别、违规＝显式拒绝（同"内容不合规"）。


**域判定面（Dynamic Domain Check）**:
引用类槽位的通用请求级绑定（可选；手牌选择槽位强制要求）：动态成员判定（构造方提供、每次请求独立绑定、请求结束即弃；槽位声明不要求/不携带）；与允许集叠加（快照范围 ∧ 动态成员性）；缺失＝请求构造期拒绝；调用点＝终局校验单点（交付照快照、不过滤）；判定异常＝失败结局。

**归属中立（Ownership-Neutral）**:
Targeter 框架不含玩家/归属概念——槽位不携带归属标识；"己方"等归属语义由构造方约定（允许集隐含界定）；跨归属场景（如对手手牌）亦由构造方提供、框架保持中立。


**自动形态（Automatic Forms）**:
不经 Targeter 槽位、无需玩家交互的目标应用形态（群体/相邻/随机）；由效果侧自组目标集＋直接应用（既有查询面＋动作面组合）；与交互形态（槽位请求）相对。



**双路承载（自动/交互）**：
自动形态（群体/相邻/随机）＝效果自组目标集＋直接应用（不经 Targeter）；交互形态（抉择/手牌选择/卡牌选择等）＝Targeter 槽位族扩展。（2026-10-04 第 2 批）

**选项槽位（OptionSelect）**：
槽位族扩展类型（抉择承载）：非引用候选——选项＝标识＋文本的声明条目（构造期固定、标识唯一、集非空）；单选恰 1；产出＝选中标识（按槽位名读取）；"分支"＝消费方按标识分派的行为约定（非条目字段）。（2026-10-04 第 2 批）

**手牌选择槽位（HandSelect）**：
槽位族扩展类型：候选＝手牌卡引用（允许集由请求构造方给定、请求期快照）；强制"域判定面"（仍在手牌）；专属呈现标注（区别于场上点选）；数量 min..max 可配。（2026-10-04 第 2 批）

**卡牌选择器槽位（CardPicker）**：
槽位族扩展类型：候选＝卡集合、构造期二择一载荷形态——名单（定义级；产出标识、生成归消费方）/引用集（产出卡引用）；呈现＝屏中卡牌阵列。（2026-10-04 第 2 批）

**域判定面（Domain Predicate）**：
请求期绑定、终局校验逐提交项同步调用的动态成员性判定（手牌类强制、引用类通用可选）；与允许集叠加；缺失＝请求构造期拒绝、异常＝失败结局。（2026-10-04）

**呈现形态标注（Presentation Mark）**：
随 Begin 请求描述交付前端的槽位类别呈现提示（选项列表/手牌选择/卡牌阵列）；呈现提示、非策略指令。（2026-10-04）

**统一提交面（按类别承载）**：
终局提交统一入口按槽位类别承载元素（引用/标识）；一次提交覆盖全部槽位、逐槽位按类别校验；违规＝拒绝＋留痕。（2026-10-04）

**非引用产出读面**：
按槽位名读取标识的产出读面（与引用读面并列、类别可辨；不允许弱类型快照）。（2026-10-04）

**三类候选来源**：
前端收集（既有引用类）/声明·载荷携带（非引用类）/后端构造方携带（新引用类）。（2026-10-04）

**混合槽位**：
一次请求可含任意类别组合（无禁配）；收集恰一次仅服务既有引用类；筛选链仅作用既有引用类；失败＝请求级。（2026-10-04）
