# 效果解析层（EffectParsing）

卡面中文文本 →（词法／AST／语义映射／编译）→ 带 csx 效果的解析子系统（`src/Orc.Game/EffectParsing`）；本文件记录其术语与硬决策摘要（与项目根 CONTEXT.md 的解析层术语互补）。

## Language

**『揭示』三形态**：
『揭示』字面在解析层的三种角色合围：①句中动作（→ reveal 原语）；②事件前缀（"揭示：…"→ 监听效果）；③监听短语（"…被揭示时"→ 监听效果＋归属守卫）。
_Avoid_: 把三形态混为"揭示一词多义"

**事件型前缀白名单**：
"动作词＋冒号"被识别为事件前缀的受控清单（当前仅『揭示』）；白名单外保持既有语义路径（如"获得："嵌套效果），不做通用"动作词+冒号"扩展。
_Avoid_: 动作词+冒号通例

**"直接可跑"口径**：
＝解析双口径中"语义完整"档位的口径名（无占位条件、无 `needsCsx`/`csx` 留痕）；**非**端到端运行义务（端到端由机制侧测试另行承接）。
_Avoid_: 把"直接可跑"读成运行化义务

**条件族·在场回合数与回合归属**：
本批新增的两类"真实条件"承载——"在场上的第 N 回合"（在场回合数比较）与"若是友方/敌方回合"（回合归属判定）；均须真实求值、不得降级为占位条件。
_Avoid_: 占位条件（那是降级形态）

**『冲击』留痕豁免**：
『获得奋战和冲击』样本中『冲击』维持"未实现词条"留痕口径（不补词族、显式标注）；『奋战』入 keyword 词族。
_Avoid_: 静默忽略


## Decisions（词条效果化·批 0 补充 · 2026-10-06）

- **参值通道边界**（批 0 grill 确认）：本批＝效果表达侧**静态携带**参值（DSL 值字段 → 模板值占位符渲染 → 运行时承接）；"词条壳参值→效果填槽"（运行时动态）与解析器侧词条行接入不在本批。
- **参值校验层级**（批 0 grill 确认）：通道层不设值域校验（非负/上限）；值域归词条组件侧钳制（如重甲/情报 [0,3]）；经新通道行为＝与既有直接路径一致（放行、组件兜底）。
- **语言面增量边界**（批 0 grill·Q&A-2 确认）：官方 op 增量仅『授予 op 参值形态』；『撤销/参值改写/内容型授予』只做运行时口（不做官方 op）。
- **内容型授予口径**（批 0 grill·Q&A-3 确认）：沿用既有内容类型（映射既有签名）；csx 脚本可达性不属本批（缺口申报）；验收＝运行时口存在＋C# 行为级（授予/消费/卸载/幂等）。
- **参值代表词条**（批 0 grill·Q&A-4 确认）：重甲N＝必需（行为链实证：减伤读数）；情报N＝可选轻量（授予/读回，执行面待办）。
- **机制冻结（冻结面）**（批 0 grill·Q&A-5 确认）：指**行为与契约冻结**（机制的行为、公共签名、语义与既有断言不得变更）；**纯新增（方法/文件/测试）不受限**；申报分界看"是否改变既有行为/契约"。
- **词条域可达口径**（批 0 grill·Q&A-6 确认）：门面词条域（授予〔含参值〕/撤销/参值改写/内容型授予）可达域＝**具备词条面者（CardBase＋Hq 同族统一）**；旧口同步统一；不可达＝返回 false 降级（参数 null＝fail-fast 分列）。



## Decisions（词条效果化·批 0 补充 · 2026-10-06）

- **参值通道**＝效果表达侧**静态携带**词条参值的通道：DSL 值字段（可空整数）→ op 模板值占位符（整数字面量）→ csx 授予调用携带参值 → 运行时承接；"未提供"与"显式 0"为两种形态；值域校验归词条组件、通道层不校验。
  _Avoid_: 运行时填槽（属批 1/2）、解析器词条行联动（属批 4）
- **效果运行时口（词条操作）**＝EffectRuntime 对既有词条管理能力的受控暴露（撤销／参值改写／内容型授予）；可达域＝"具备词条面"（CardBase／Hq 同族，经统一读口判定）；行为语义沿用既有（幂等、终态拒绝、参值改写前提＝词条存在）；暴露层不吞错、不降级（服务不可达除外——沿用门面降级口径）。
  _Avoid_: 重造语义、吞错降级、CardBase 限定式判定
- **批 0 语言面边界**：官方 op 增量仅"授予 op 参值形态"；撤销/参值改写/内容型授予只做运行时口、不做官方 op。
  _Avoid_: 无消费方的 op 预建
- **冻结面（老兵/隐蔽）**＝老兵与隐蔽批次已交付机制的行为与契约冻结：禁改行为/公共签名/语义，纯新增不受限，既有语义注释原样保留（EffectRuntime 内 UpgradeAsync／RevealAsync 面同样原样保留）。
  _Avoid_: 把冻结读成"文件禁写"


## Decisions（序列③·词条行联动 · 2026-10-07）

- **词条行→声明产出**＝词条行（整行仅词法命中词条/数值/标点；维度 keyword/unitType/attribute）不再静默丢弃、产出**声明**（维度/标识/参值/注册状态）；**未注册词条如实标注**；不成词法整行与混行保持既有解析路径；一行多词条**逐条分列**；参值＝**紧邻后随数字**（形态提取，不做交叉校验）。
  _Avoid_: 静默丢弃、半行声明、"数字在前"参值


- **声明产出与兼容口径（序列③ · Q&A-2 · 2026-10-07）**：声明经**公共解析入口**可达（与效果/未解析并列）；非词条行解析面逐位不变、词条行不产生效果单元（原语义保留）；**声明不计入效果/覆盖率计**（报告新增声明维度、对照申报）；空白行豁免；异常/未命中归既有未解析记录面。
  _Avoid_: 把声明计入覆盖率、独立异常面、未注册另列



## Decisions（词条效果化·批 4·序列③ · 2026-10-07）

- **词条行声明产出**（批 4·序列③ grill）：词条行（整行仅词条/数值）不再静默丢弃——产出『声明』列表（按维度分类：词条/兵种/属性）；参值＝紧邻后随数字（无参值＝null）；词条未注册＝声明内状态位标注、不另列。产出经公共解析入口与效果/未解析并列可读（接口形态由实现者设计并申报；命名不得与卡定义层 KeywordDeclaration 混淆）。
  _Avoid_: 静默丢弃、把声明计入效果/覆盖率计、独立异常记录面
- **未知/异常口径**（批 4·序列③ grill）：不成词法行＝不产出声明、保持既有解析路径（不视为违规）；参值异常（多数字/非数字）与无声明成分行（孤立数字等）＝归既有未解析记录面（原文＋原因，不静默）；空白行豁免。
- **兼容与报告口径**（批 4·序列③ grill）：正常词条行对既有解析面（效果/未解析/切分单元数）零行为变化（原『丢弃』断言语义保留＋新增声明断言；等效性论证＝对拍面清单＋"保留/新增"书面化留存）；报告新增"声明产出"维度统计、静默统计自然下降——口径变化对照申报。
- **本单不接消费方**（批 4·序列③ grill）：声明→卡构建/组件/行为接线不做（非内置效果自动生成留后续）；验收以"公共入口可读声明产出"为准。


- **词法完备性与面变化归类（序列③ · Q&A-3 · 2026-10-07）**：新补词法取值一律**中文**（与注册面标识对齐；『冲击』＝「冲击」）；『亡计』『动员』因字面被 triggers 占用**豁免**；旧英文值与『游击』保持＋申报；『获得 X』**自然收益放行**＋对照申报；参值异常/孤立数字的未解析记录＝**新增面（目标性）**（"逐位不变"仅限判定不成立行＋判定成立行的效果面）；纯标点行与空白行同豁免。
  _Avoid_: 人为压制自然收益、把新增记录记入"逐位不变"、英文取值混入新补


- **『获得』多词条授予口径（序列③ · Q&A-4 · 2026-10-07）**：宾语区多词条（已识别）**逐词条 grant 并列**（限 gain 动作）；未识别残留**保留 needsCsx 留痕机制**；混合形态＝部分授予＋部分留痕；V4 回补断言基准＝2 个 grant、无留痕（目标性变更面）。
  _Avoid_: 单授予携带多词条、移除残留留痕、把目标性变化归等效性项


- **数字快照注释去数字化（序列③ · Q&A-5 · 2026-10-07）**："N 项/N 枚"式快照注释改为**一般化表述＋锚定权威登记面**（防反复失修）；注释同步申报格式＝"文件:行｜旧文→新文｜理由"；范围内过时注释一并同步、范围外记录申报不动手。
  _Avoid_: 数字快照注释、静默改注释、越范围动机制产品代码


- **报告与交付口径（序列③ · Q&A-6 · 2026-10-07）**：新增"词条行（声明产出）"专项样本节（逐例断言＋报告独立节）；统计口径更新（声明维度＋三项对照）＋交付说明对照表；"留痕豁免"档位保留空档；工程口径沿用（四套件／全解决方案 0 警告／冻结后 --no-incremental 复跑＋计数）；申报沿用批 1-5 结构＋接口设计申报。
  _Avoid_: 仅统计不建样本、移除豁免档位机制、对照单形态


## Decisions（词条效果化·批 4·序列③ 补充 · 2026-10-07）

- **批 4·序列③ 词法口径**：filters 词族补入 10 枚（被压制/被抑制/钳击/预报/免疫/重甲/情报/无法被压制/无法被抑制/冲击）；取值＝中文词条字面（『冲击』＝「冲击」）；『亡计』『动员』豁免（字面已被 triggers 占用）；旧 5 枚英文值保持（差异申报）；补入后"获得 X"转真映射＝自然收益（对照申报）。
- **批 4·序列③ 回补口径**：「获得 X 和 Y」（均已识别词条）＝逐词条 grant 并列（限 gain）；未识别残留 needsCsx 机制保留、不调整。
- **批 4·序列③ 注释/申报口径**：注释去数字化、锚定权威登记面；触及面内过时注释一并同步＋单列申报（格式＝文件:行｜旧→新｜理由）；范围外记录申报、不动手。
- **批 4·序列③ 交付口径**：报告新增"声明产出"专项样本节＋声明维度统计＋三项对照（声明／未解析变化／静默下降）；"留痕豁免"档位机制保留（空档）；交付沿用批 1-5 申报结构（接口设计以"设计点"列入）；P1/P2 一句自证。


- **词条行参值/声明细则（序列③ · Q&A-7 · 2026-10-07）**：参值＝Num 形态族（含 numerals 中文字）**整数化**；符号/小数不构成参值；判定成立行**成分级**处理（首参值归前邻词条；孤立/多余数字→异常记录）；声明序＝行序＋行内序、**保留重复**；注册状态仅 keyword 维度；最小必需集＝维度＋标识＋参值＋注册状态。
  _Avoid_: 原文参值、声明去重、逐形态特例识别


- **序列③兜底口径（Q&A-8 · 2026-10-07）**：DslJson 缺漏（Field）＝**缺陷修复**（申报单列、不计变更面；已核对为唯一缺漏）；声明标识/注册判定以**字面**为基准（filters 取值不参与）；『获得』混合形态保持"**先授予后留痕**"；声明产出**纯函数性**（无副作用/同输入同产出）；口径不可达成＝停手申报、等价差异＝继续＋申报。
  _Avoid_: 把缺陷修复计作变更面、以 filters 取值判注册、最接近口径静默继续


## Decisions（词条效果化·批 4·序列③ 补充 2 · 2026-10-07）

- **声明细则口径**（方法级）：参值＝Num 形态族（含中文数字词）整数化、无符号非负（符号/小数＝异常、不特例化）；判定先决＋**成分级**处理（异常落点＝数字成分；合法"词条-参值对"仍产出）；声明序＝行序＋行内序、保留重复（去重属上层）；注册状态仅 keyword 维度；最小必需集＝维度＋标识＋参值＋注册状态（来源定位建议携带、非必需）。
- **声明产出纯函数性**：无副作用、同输入同产出（一句自证＋测试覆盖）。
- **DslJson 修复归类**：OpDto.Field 往返＝纯缺陷修复（补齐对称字段、不改既有形状/语义；交付申报单列"缺陷修复"、不污染变更面对照）。
- **冲突处置分级**：已确认口径不可达成＝停手申报；等价可达成的实现细节差异＝继续＋申报。


## Language（批 5·效果离线编译驱动 增补）

**语义完整档位**：
效果级产出档位：该效果**无占位条件、无 needsCsx／csx 留痕**（递归含内嵌效果）＝语义完整；仅编译成功并已产出的效果参与该档位（失败效果不标、不计）。
_Avoid_: 把模板自带 csx 计入留痕、把「失败但无留痕」算作完整

**留痕三类**：
驱动报告中**分列**的三类「不静默丢弃」记录：未解析记录（文本级）／needsCsx｜csx 留痕（效果级）／占位条件（效果级）；类别字面稳定、逐条带定位锚点。
_Avoid_: 合并为笼统「警告」清单、把留痕记为失败

**词条行声明区**：
驱动报告中与成功／失败／留痕并列的**独立信息区**（维度／标识／参值／注册状态＋定位锚点）——既不属留痕亦非失败，不影响语义完整档位与效果计数。
_Avoid_: 第四类留痕、把声明计入覆盖率

## Decisions（批 5·效果离线编译驱动 · 2026-10-08）

- **产出粒度与身份**：一文本 N 效果 → N 产出（N=0＝空成功）；身份＝基名＋声明序派生（N=1 → 基名，N≥2 → `{基名}.{n}`）；批量身份基名＝输入文件基名（`*.txt` 与 `*.dsl.json` 均去尽格式后缀——`a.txt`／`a.dsl.json` 同名＝应被发现的重复）。
- **留痕不失败**：三类留痕与声明均不改变「成功」判定；失败类别字面稳定（InvalidData／SourceMissing／CompileFailed／InvalidIdentity／DuplicateIdentity／IoFailed）。
- **不吞不降级**：失败条目原因必须完整包含既有层（解析器／编译器）例外消息原文；留痕与失败分属不同区与类别。
