# 审查链（逻辑序列化与关系导出）

卡牌引擎（Orc）在**声明期**导出逻辑关系图的领域术语：以触发器为节点、handler 为链，配合可文本化的预制体与效果快照。
与运行期因果记录（**事件流**）互补——本域只讲"逻辑长什么样、怎么被引用"。

## Language

**审查链**：
从引擎静态声明面导出的逻辑关系图（触发器为节点、handler 为链）；输出 = JSON 真源 + 派生文本视图。仅声明期，不含运行期实际调用。
_Avoid_: 事件流、日志、追踪

**静态声明图**：
审查链的模型——节点＝触发器，边＝handler 及其**声明的**下游触发器；与运行期实际调用序列不同。
_Avoid_: 调用图、实际链路

**编排管理器**：
内核侧集中登记 handler ↔ 触发器 ↔ hook 关系、并提供反向依赖与可达链导出的管理器；覆盖全域。
_Avoid_: 注册表、调度器

**挂载面**：
逻辑中"什么时候该调用"的一面——由 Hook 声明 + 挂载优先级 + 所有者 + 总线订阅构成。
_Avoid_: 编排层

**反向依赖**：
"我该被什么调用"——某 hook / 触发器被哪些触发器与 handler 订阅的查询面。
_Avoid_: 上层调用、上游

**TriggerId**：
触发器**种类/定义**的稳定标识（如"打出触发器"），由引擎/代码定义、跨对局稳定；具体实例以 (TriggerId, 宿主) 定位。
_Avoid_: 触发器实例 ID、展示名

**HookId**：
hook 的稳定标识，与 hook 名字双向互转；hook 空间开放，首次登记即对局内固化。
_Avoid_: 更新字符串、事件名

**事件标识**：
触发器内一条 handler 注册项（事件）的稳定标识，供审查链与快照引用。
_Avoid_: HandlerID、回调 ID

**预制体**：
可复用的逻辑声明单元，分三层：**效果预制体** → 引用 → **触发器预制体** + **事件预制体**；实例化时从文本重建携带完整逻辑的动态对象。
_Avoid_: 模板、配置、蓝图

**事件预制体**：
具名、可参数化的 handler 逻辑声明（来源：程序集或 csx）。
_Avoid_: handler 预制体、回调模板

**触发器预制体**：
触发器定义的声明（Kind / band 方案 / hooks / 事件集合）。
_Avoid_: 触发器模板

**效果预制体**：
效果定义的声明（主触发器 + 需挂载 HookID + 其它预制体 + moding 声明）。
_Avoid_: 效果模板

**预制体管理器**：
解析与注册预制体、从程序集（显式注册）与本地明文目录（csx）获取委托并统一管理、支持 moding 的管理器。
_Avoid_: 脚本宿主、插件系统

**动态效果**：
由预制体实例化（csx 文本重建）得到的效果；与既有 C# 效果**并存**，进既有卡牌效果装载链。
_Avoid_: 脚本效果、运行时效果

**动态 handler（csx）**：
由 csx 脚本源定义、经 satellite 工程编译取得的可调用对象；与既有的"动态 handler（Orc.Lua）"按**来源**区分。
_Avoid_: Lua handler

**效果快照（EffectSnapshot）**：
效果预制体的自包含序列化形态（`schemaVersion` + 嵌套三层预制体）；反序列化产出**装载计划**。schema 版本不符＝结构化失败（不静默降级）。
_Avoid_: 效果存档、效果转录

**装载计划（EffectLoadPlan）**：
由效果快照派生的**有序**装配步骤（挂主触发器 / 注册事件 / 施加 moding）；数据（快照）与动作（计划）分离、可独立审查。
_Avoid_: 装配脚本、初始化序列

**csx 来源 / 程序集来源**：
事件预制体逻辑的两种承载：`csx`＝内联文本（动态、社区、明文）；`程序集`＝显式注册键（内置）。二选一。
_Avoid_: 脚本源、DLL 源

**脚本求值器（IScriptEvaluator）**：
内核定义、satellite（`Orc.Script`）实现的 csx 求值契约；返回**擦除形态委托**，由调用侧按视图类型绑定。未装配＝动态处理器不可用。
_Avoid_: 编译器、脚本引擎

**弱沙箱**：
csx 的安全姿态：同进程 + 引用白名单 + 导入白名单 + 关键字过滤 + 超时；**尽力而为**、非安全边界。强隔离须进程级。
_Avoid_: 沙箱、安全沙箱

**动态被动效果 / 动态主动效果**：
由效果快照重建的效果：被动＝继承框架生命周期清理、把动态触发器一并挂载；主动＝纯动作型（无 hook 段），施放经 `CastAsync`。
_Avoid_: 脚本效果、运行时效果

**本地明文目录**：
预制体分发的唯一形态：本地目录下的 `*.prefab.json` 明文文件（无在线仓库/工坊）。
_Avoid_: 预制体仓库、工坊

## Sample Dialogue

> 开发者：审查链怎么看出"打出触发器"会引发什么？
> 领域专家：那是**静态声明图**——以 TriggerId 为节点，找到它的**事件**边，再看每个 handler **声明的下游触发器**；链上不出现运行期真正调用的顺序，那是**事件流**的事。
> 开发者：那效果快照里的"主触发器 + 挂载 HookID"呢？
> 领域专家：那是**效果预制体**的**挂载面**；HookId 由引擎提供、跨对局稳定，是快照的引用锚点。
> 开发者：社区写的 csx 逻辑放哪？
> 领域专家：在**事件预制体**里，经**预制体管理器**从本地明文目录装载；实例化出的就是**动态效果**。


## Decisions（词条效果化·批 1 · 2026-10-07）

- **效果定义形态口径（批 1）**：词条效果的效果定义以「效果体系正式对象（走装载链与生命周期）」为验收基准——非类型白名单；效果预制体／效果快照同族数据形态为可选来源，本批不强制序列化落盘与预制体管理器全链登记（制品化＝后续演进）。


## Decisions（效果侧落盘·批 2 · 2026-10-08）

- **效果侧落盘＝静态数据管道**（批 2 grill 确认）：效果快照集合→目录（`SaveDirectory`／`SaveFile`）；不做管理器实例导出便捷面；与既有目录读取共享 `*.prefab.json` 口径、单文件隔离与失败语义。
- **落盘报告无警告面**（批 2 grill 确认）：成功／失败分列（快照 id＋目标文件＋原因）；快照＝完备数据模型，直出、无有损转换。
- **命名与冲突**（批 2 grill 确认）：`<root.id>.prefab.json`；非法 id 拒绝（双防线）；批内重复＝首见写＋重复失败；跨运行覆盖（内容覆盖）；只写不删。
- **文本契约**（批 2 grill 确认）：效果分发文件与卡侧同款硬契约（LF／2 空格／尾换行／无 BOM／键序确定；写→读→写字节幂等）。


## Language（批 4·csx 动态效果能力 增补）

**挂载凭据**：
动态效果受控挂载（Attach）返回的不透明引用；每次挂载唯一、互不相等（复装＝新凭据）；csx 侧仅持有、回传、作同一性比较；用于卸载指认。
_Avoid_: 句柄、handle

**受控挂/卸**：
csx 面向的动态效果进出受控面（EffectRuntime）：从已注册预制体／快照 JSON 挂载、按挂载凭据或效果引用卸载；语义沿用统一装载链（Add 即装载）。
_Avoid_: 动态装卸、脚本挂载

## Decisions（批 4·csx 动态效果能力 · 2026-10-08）

- **受控挂/卸（面向 csx）**：EffectRuntime 新增受控方法族（从已注册预制体挂载／从快照 JSON 挂载／按挂载凭据或效果引用卸载〔同名重载〕／DSL 编译挂载）；卸载覆盖「本门面挂载者（凭据）」与「卡上已有者（效果引用）」；失败＝结构化类别（来源未命中／数据无效／编译失败／实例化失败／装载失败／未命中／跨卡归属／服务不可用）＋零残留回滚（静默、零发射）；成功判据＝实例化＋生效路径成功＋凭据有效；重复挂载允许多实例并存；复装＝新实例新凭据。
- **运行时编译挂载**：DSL（DslJson）→EffectCompiler→快照→挂载；资产＝默认目录约定＋可显式覆盖（含内存资产注入）；进程级编译缓存（键＝DSL 文本＋资产指纹；命中与否行为无差别）。
- **形态与边界**：主动形态可挂/卸、本批不受理施放（XML 注释文档化边界）；沙箱与内核零改动；public 面只增不收窄（收口留后续）；命名（方法/类型/类别字面）＝对外契约、变更受控。
- **测试验收（本批）**：csx 视角双硬性（csx 承载效果真编译＋csx 调用门面样例）；「临时获得某能力」被动样例含「卸载后行为停止」反向断言；托管/信号五必测（effect.removed 恰一次、失败零发射、随卡销毁、复装、多实例并存）；编译面三必测（全链含资产注入、资产变更必反映、同 DSL 二次编译行为等价）。


## Decisions（效果离线编译驱动·批 5 · 2026-10-08）

- **驱动定位**（批 5 grill 确认）：离线/生产面（非运行期，不启动对局）；对外＝整体链两入口（单条〔纯返回：快照＋同款 JSON 文本＋同构报告〕／批量〔落盘＋报告＋dry-run〕）；「解析／编译／打包」三段为内部架构、不独立对外（各自可达由既有 public 面承担：EffectParser／EffectCompiler／PrefabJson／PrefabWriter）。
- **落盘单一真源**（批 5 grill 确认）：批量落盘＝内部组合 `PrefabWriter`（批 2 契约逐字沿用）；单条 JSON 文本与落盘内容逐字符同款（对拍口径）；不新增第二套落盘/文本实现。
- **产出与身份**（批 5 grill 确认）：产出粒度＝效果级（0 效果＝空成功）；身份＝基名＋声明序序号（确定性派生）；批内重复＝首见产出＋重复者失败（类别 `DuplicateIdentity`——批 5 新增稳定类别）。
- **报告契约**（批 5 grill 确认）：单一类型同体承载（成功／失败〔类别集：InvalidData／SourceMissing／CompileFailed／InvalidIdentity／DuplicateIdentity／IoFailed／可选 SerializeFailed〕／留痕三类〔Unresolved／needsCsx·csx／占位条件〕／汇总〔计数＋运行参数快照〕）；事实字段与预期字段分离（dry-run 用「预期目标文件路径」）；语义完整档位＝领域口径（无占位条件、无 needsCsx/csx 留痕；递归覆盖内嵌效果；模板固定 csx 不计）。
- **dry-run 原则**（批 5 grill 确认）：零 IO（不写盘、不创建目录、不探测目录）；「模式只控制动作、不改变判定」（除 IoFailed 不发生外，判定结果一致）。
- **确定性与资产**（批 5 grill 确认）：同输入逐字节/序/字面硬断言；资产三形态（默认目录/显式目录/内存注入）；资产变更必反映；不暴露缓存控制面。


- **输入侧契约**（批 5 grill 确认·补充）：输入级条目区（逐文件、与效果级条目分列；覆盖 0 效果/坏文件）；批内序＝全部匹配文件（`*.txt`＋`*.dsl.json`）Ordinal 文件名序统一排队（首见判定与报告序同源）；同/嵌套输出目录允许（不变量：只扫顶层＋扩展名不重叠）。


- **报告结构与范围**（批 5 grill 确认·收尾）：四区＋汇总（输入级／成功／失败／留痕三类独立清单／汇总）为最小结构；留痕条目产出文件遵循事实语义（无产出允许 null），落点由预期字段按统一规则承载；报告仅内存返回（不落盘）；本批不含 CLI／对局接线／批量并发。


- **身份与对账口径**（批 5 grill 确认·补）：身份基名推导＝`*.txt` 去 `.txt`／`*.dsl.json` 去双后缀 `.dsl.json`（两类对称）；扩展名匹配＝大小写不敏感（显式后缀判定、跨平台一致）、排序＝Ordinal；语义完整判定域＝编译成功效果（`语义完整计数 ≤ 成功数`）；单条输入级条目＝恰 1 条（汇总「输入数」＝输入级条目数：批量＝文件数、单条＝1）。


- **计数/占位/不虚构口径**（批 5 grill 确认·补）：汇总失败按六类分列＋留痕三类分列；输入级含语义完整计数（`该文件完整数 ≤ 该文件成功数`）；「零 IO」＝输出侧零写（输入读取照常、目录缺失两模式一致抛出）；首见占位＝通过身份处理即占位（身份非法不占位；首见者照常记录、可定位）；`InvalidIdentity`／`DuplicateIdentity` 不得填预期路径（不得虚构）。


- **产物内容与计数对齐**（批 5 grill 确认·补）：产物内容＝单条必携／dry-run 必携（与落盘写出内容逐字符一致）／批量落盘不要求（以磁盘为准）；输入级与汇总计数维度完全一致（六类失败＋三类留痕分列；互核等式＝逐维求和相等）。


- **声明通道与封闭清单**（批 5 grill 确认·补）：词条行声明（`ParseResult.Declarations`）＝独立信息区承载（逐条：维度/标识/参值/注册状态；非留痕、非失败、不影响档位；不计入效果/覆盖率计数）；报告承载面＝五区＋汇总（输入级/成功/失败/留痕三类/声明）为**封闭清单**——新通道须停手申报、不得静默丢弃。


## Language（批 5·效果离线编译驱动 增补）

**效果离线编译驱动**：
卡面文本／DSL →（解析 → 编译 → 快照）的**离线生产面**（工具链；可选落盘 `*.prefab.json`）；与运行期门面（EffectRuntime 受控挂载）分面、不启动对局。
_Avoid_: 运行时编译挂载、门面挂载

**编译驱动报告**：
一次调用的结构化结果＝**五区＋汇总**（输入级区／成功区／失败区／留痕三类区／声明区＋汇总）；单条与批量**同一报告类型**（单条＝0/1 输入特例），计数维度逐层一致、可逐层互核。
_Avoid_: 日志、单一警告清单

**事实字段 / 预期字段**：
报告中「**产出文件**」＝事实（未落盘＝null，不得虚构）；「**预期目标文件路径**」＝**可成立**的推导落点（预览／落盘失败时承载；身份非法或重复时不得填）。
_Avoid_: 用同一字段混装事实与预期

## Decisions（批 5·效果离线编译驱动 · 2026-10-08）

- **落盘单一真源**：驱动落盘完全同款批 2 `PrefabWriter`（命名 `<root.id>.prefab.json`、文本契约、非法 id 拒绝、批内重复＝首见写＋DuplicateIdentity、只写不删、目录准备失败抛出）；不新增第二套落盘出口。
- **输入契约**：`*.txt`＝卡面文本（一文件＝一卡可多效果）、`*.dsl.json`＝DSL（一文件＝一效果实例）；匹配大小写不敏感、排序 Ordinal、非约定文件跳过且不计；输出目录可与输入同目录（扫描仅顶层，产出 `*.prefab.json` 天然不被当输入）。
- **批量＝落盘＋报告（默认）／dry-run（输出侧零写；输入侧读取照常）**；除落盘动作自身失败（IoFailed）外，两模式判定一致——「模式只控制动作、不改变判定」。
- **资产三形态**：默认目录约定／显式目录／内存注入；无缓存控制面（缓存可选、须行为透明——资产变更必反映、命中与否行为无差别）。
- **报告承载面封闭**：输入级／成功／失败／留痕三类／声明／汇总＝封闭清单（扩展须经委托方裁定）；发现未列通道＝如实承载或停手申报，不得静默丢弃。
