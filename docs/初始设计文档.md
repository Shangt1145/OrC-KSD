\# 卡牌游戏触发器引擎架构文档



> 目标语言：C# (.NET 8+)

> 状态：设计稿 v1.0

> 范围：触发器系统（Trigger System）——被动/主动触发器、优先级、上下文、生命周期、日志、异步、中断



\---



\## 一、设计目标



1\. \*\*统一抽象\*\*：被动触发（事件驱动）与主动触发（引用调用）共用同一套包装器、优先级、日志、异步、中断机制。

2\. \*\*声明式上下文\*\*：每个触发器显式声明它读什么、写什么、可缺省什么，杜绝"整个引擎当上下文"的失控。

3\. \*\*安全引用\*\*：可被删除的实体使用生命周期令牌，下游逻辑在对象失效时自动跳过而非崩溃。

4\. \*\*可扩展优先级\*\*：双层（Band × Inner）优先级，允许新效果插入而不重排旧值。

5\. \*\*异步与超时\*\*：原生 `async/await`，支持超时与取消，异常隔离。

6\. \*\*可观测\*\*：全链路 `ChainId` + `Depth` + `Band` 日志，能一眼看出因果。



\*\*非目标\*\*：不负责游戏规则本身（伤害、费用、胜负判定在引擎之外）；不负责网络同步；不负责 UI。



\---



\## 二、术语与核心概念



| 术语 | 含义 |

|---|---|

| \*\*Event\*\* | 引擎在结算流水线上暴露的更新点，如 `BeforeDamage` |

| \*\*Trigger\*\* | 包装器，同时承载被动与主动两种触发器的执行 |

| \*\*TriggerBus\*\* | 事件槽位容器，被动触发器在此挂载 |

| \*\*Context\*\* | 一次结算的完整上下文，贯穿整条因果链 |

| \*\*ContextView\*\* | 触发器执行时看到的受限视图，按声明裁剪 |

| \*\*Ref / Lifetime\*\* | 安全引用与生命周期令牌 |

| \*\*Band\*\* | 双层优先级的外层，语义化的相位 |

| \*\*Inner\*\* | 双层优先级的内层，同 Band 内的微调 |

| \*\*ChainId\*\* | 一次因果链的全局标识 |

| \*\*Interrupt\*\* | 取消当前引擎动作 |

| \*\*Stop\*\* | 中止本事件后续触发器 |

\## 四、模块设计



\### 4.1 Lifetime 与 Ref —— 生命周期令牌



\*\*目的\*\*：让"对象已删除"可检测，下游触发器在跑之前就能跳过。



```csharp

public sealed class Lifetime

{

&#x20;   private int \_alive = 1;

&#x20;   public bool IsAlive => Volatile.Read(ref \_alive) == 1;

&#x20;   public void Kill() => Interlocked.Exchange(ref \_alive, 0);

}



public sealed class Ref<T> where T : class

{

&#x20;   private readonly T \_target;

&#x20;   private readonly Lifetime \_life;

&#x20;   public string Name { get; }



&#x20;   internal Ref(T target, Lifetime life, string name)

&#x20;   { \_target = target; \_life = life; Name = name; }



&#x20;   public bool IsAlive => \_life.IsAlive;



&#x20;   public T Value => \_life.IsAlive

&#x20;       ? \_target

&#x20;       : throw new StaleReferenceException($"Ref<{typeof(T).Name}> '{Name}' 已失效");

}



public class Entity

{

&#x20;   public string Name { get; }

&#x20;   public Lifetime Life { get; } = new();

&#x20;   public Ref<Entity> Ref { get; private set; }



&#x20;   public Entity(string name)

&#x20;   {

&#x20;       Name = name;

&#x20;       Ref = new Ref<Entity>(this, Life, name);

&#x20;   }



&#x20;   public void Destroy() => Life.Kill();   // 引擎随后通知 bus.UnmountOwner(this)

}



public sealed class StaleReferenceException : Exception { ... }

```



\*\*要点\*\*



\- `Lifetime` 用 `Interlocked` 保证多线程（若未来引入）安全。

\- `Ref<T>.Value` 访问时二次校验，兜底第一道防线（Preflight）之外的漏网。

\- `Entity` 是基类；卡牌、随从、玩家都继承。

\### 4.2 Context —— 执行上下文



\*\*目的\*\*：一次结算的完整数据载体，贯穿父子链。



```csharp

public sealed class Context

{

&#x20;   public string Event { get; }

&#x20;   public object? Source { get; }

&#x20;   public Context? Parent { get; }

&#x20;   public string ChainId { get; }

&#x20;   public int Depth { get; }



&#x20;   internal Dictionary<string, object?> Data { get; }



&#x20;   public bool Stopped { get; private set; }

&#x20;   public bool Interrupted { get; private set; }

&#x20;   public string? Reason { get; private set; }

&#x20;   public List<(string Trigger, object? Result)> Results { get; } = new();



&#x20;   public Context(

&#x20;       string @event,

&#x20;       object? source = null,

&#x20;       IDictionary<string, object?>? data = null,

&#x20;       Context? parent = null)

&#x20;   {

&#x20;       Event = @event;

&#x20;       Source = source;

&#x20;       Parent = parent;

&#x20;       ChainId = parent?.ChainId ?? Guid.NewGuid().ToString("N")\[..8];

&#x20;       Depth = (parent?.Depth ?? -1) + 1;

&#x20;       Data = data is null ? new() : new(data);

&#x20;   }



&#x20;   public void Stop(string reason = "") { Stopped = true; Reason = reason; }

&#x20;   public void Interrupt(string reason = "")

&#x20;   {

&#x20;       Stopped = true;

&#x20;       Interrupted = true;

&#x20;       Reason = reason;

&#x20;   }

}

```



\*\*要点\*\*



\- `ChainId` 用于串联整条因果链，子 Context 继承父的。

\- `Depth` 用于日志缩进。

\- `Data` 是唯一的载荷载体；触发器通过 `ContextView` 访问它。

\### 4.3 ContextView —— 声明式受限视图



\*\*目的\*\*：让每个触发器只能看到自己声明的字段，只能改声明为可变的字段。



C# 强类型，推荐 \*\*Source Generator 编译期生成\*\*。设计上分两层：



\#### 4.3.1 声明特性



```csharp

\[AttributeUsage(AttributeTargets.Class)]

public sealed class ContextViewAttribute : Attribute

{

&#x20;   public Type EventType { get; }

&#x20;   public ContextViewAttribute(Type eventType) => EventType = eventType;

}



\[AttributeUsage(AttributeTargets.Property)]

public sealed class ReadAttribute : Attribute { }



\[AttributeUsage(AttributeTargets.Property)]

public sealed class MutateAttribute : Attribute { }



\[AttributeUsage(AttributeTargets.Property)]

public sealed class OptionalAttribute : Attribute { }

```



\#### 4.3.2 声明式视图（由卡牌作者书写）



```csharp

\[ContextView(typeof(BeforeDamageEvent))]

public partial class ShieldView : IContextView

{

&#x20;   \[Read]     public Ref<Entity> Target { get; }

&#x20;   \[Mutate]   public int Amount { get; set; }
```

\#### 4.3.3 Source Generator 生成（节选示意）



```csharp

// 由 Source Generator 生成的实现

partial class ShieldView

{

&#x20;   private Dictionary<string, object?> \_data = null!;

&#x20;   private Context \_ctx = null!;



&#x20;   public void Bind(Dictionary<string, object?> data, Context ctx)

&#x20;   {

&#x20;       \_data = data; \_ctx = ctx;

&#x20;       EnsureRequired("Target"); EnsureRequired("Source"); EnsureRequired("Amount");

&#x20;   }



&#x20;   public Ref<Entity> Target

&#x20;   {

&#x20;       get

&#x20;       {

&#x20;           var v = (Ref<Entity>)\_data\["Target"]!;

&#x20;           if (!v.IsAlive) throw new StaleReferenceException("Target");

&#x20;           return v;

&#x20;       }

&#x20;   }



&#x20;   public int Amount

&#x20;       get => (int)\_data\["Amount"]!;
```

\#### 4.3.4 运行时绑定器（备用反射方案）



若首版不引入 Source Generator，可用反射在首次构造时缓存 setter/getter：



```csharp

public interface IContextView

{

&#x20;   void Bind(Dictionary<string, object?> data, Context ctx);

&#x20;   void Seal();

}



public static class ContextViewBinder

{

&#x20;   private static readonly ConcurrentDictionary<Type, ViewMeta> \_cache = new();



&#x20;   public static IContextView Create(Type viewType, Dictionary<string, object?> data, Context ctx)

&#x20;   {

&#x20;       var meta = \_cache.GetOrAdd(viewType, ViewMeta.Build);

&#x20;       var instance = (IContextView)Activator.CreateInstance(viewType)!;

&#x20;       // 反射填充：检查 required 字段、构造属性代理

&#x20;       // 首次构建慢，之后走缓存

&#x20;       meta.Bind(instance, data, ctx);

&#x20;       return instance;

&#x20;   }

}

```



\*\*推荐\*\*：MVP 阶段用反射缓存；数据量大、性能敏感时切换 Source Generator，接口不变。



\*\*语义总结\*\*



| 声明 | 读 | 写 |

|---|---|---|

| `\[Read]` | ✅ | ❌ 抛 `PermissionDeniedException` |

| `\[Mutate]` | ✅ | ✅ |

| `\[Optional]` + `\[Read/Mutate]` | ✅（缺失返回 default） | 视主特性 |

| 未声明 | ❌ 抛 `PermissionDeniedException` | ❌ |

\### 4.4 Band 与 Inner —— 双层优先级



\#### 4.4.1 常量与排序键



```csharp

public static class PriorityBands

{

&#x20;   public const int Stride = 1000;



&#x20;   // 每个事件一套独立 band 命名空间

&#x20;   public static class Damage

&#x20;   {

&#x20;       public const int Prevent  = 100;

&#x20;       public const int Replace  = 200;

&#x20;       public const int Reduce   = 300;

&#x20;       public const int Amplify  = 400;

&#x20;       public const int Finalize = 500;

&#x20;   }



&#x20;   public static class PlayCard

&#x20;   {

&#x20;       public const int Counter    = 100;

&#x20;       public const int Retarget   = 200;

&#x20;       public const int Tax        = 300;

&#x20;       public const int PreEffect  = 400;

&#x20;   }

}



public readonly record struct SortKey(int Band, int Inner) : IComparable<SortKey>

{

&#x20;   public int CompareTo(SortKey other)

&#x20;   {

&#x20;       int c = Band.CompareTo(other.Band);

&#x20;       return c != 0 ? c : Inner.CompareTo(other.Inner);

&#x20;   }



&#x20;   // 可选：序列化用

&#x20;   public long Pack() => (long)Band \* PriorityBands.Stride + Inner;

}

```



\*\*要点\*\*



\- 用 `record struct` + `IComparable` 做排序键，语义清晰且零分配。

\- `Pack()` 仅在需要持久化排序顺序时使用；\*\*Pack 要求 Inner ∈ \[0, Stride)\*\*。

\- \*\*不要用乘法\*\*——用元组比较或定点打包，两者等价但前者更安全。



\#### 4.4.2 同 Band 同 Inner 的兜底



\*\*稳定排序 + 注册序号\*\*：



```csharp

public sealed class Trigger

{

&#x20;   internal long RegistrationSeq { get; set; }   // 由 Bus 分配



&#x20;   public SortKey SortKey { get; }

&#x20;   public long TieBreaker => RegistrationSeq;

}

```



比较时：



```csharp

int c = a.SortKey.CompareTo(b.SortKey);

if (c != 0) return c;

return a.TieBreaker.CompareTo(b.TieBreaker);

```



→ 退化为"卡牌入场顺序"，本身具备语义。

\### 4.5 Trigger —— 统一包装器



```csharp

public delegate Task TriggerHandler<in TView>(TView view, CancellationToken ct)

&#x20;   where TView : IContextView;



public sealed class Trigger

{

&#x20;   public string Name { get; }

&#x20;   public SortKey SortKey { get; }

&#x20;   public object? Owner { get; }

&#x20;   public bool Once { get; }

&#x20;   public TimeSpan? Timeout { get; }



&#x20;   public IReadOnlySet<string> Reads { get; }

&#x20;   public IReadOnlySet<string> Mutates { get; }

&#x20;   public IReadOnlySet<string> Optionals { get; }



&#x20;   public long RegistrationSeq { get; internal set; }

&#x20;   public bool Fired { get; private set; }



&#x20;   private readonly Func<IContextView, Context, CancellationToken, Task> \_invoker;



&#x20;   internal Trigger(

&#x20;       string name, SortKey sortKey,

&#x20;       object? owner, bool once, TimeSpan? timeout,

&#x20;       IEnumerable<string> reads, IEnumerable<string> mutates, IEnumerable<string> optionals,

&#x20;       Func<IContextView, Context, CancellationToken, Task> invoker)

&#x20;   { ... }



&#x20;   // ------------ 唯一执行入口 ------------

&#x20;   internal async Task<object?> RunAsync(Context ctx, CancellationToken ct)

&#x20;   {

&#x20;       if (Once \&\& Fired) return null;

&#x20;       Fired = true;



&#x20;       // ① Preflight：检查所有声明的字段中 Ref 是否失效

&#x20;       if (!Preflight(ctx, out var staleField))

&#x20;       {

&#x20;           Log.Debug("\[{Chain}] 跳过 {Trigger}：{Field} 已失效",

&#x20;               ctx.ChainId, Name, staleField);

&#x20;           return null;

&#x20;       }



&#x20;       // ② 构造视图

&#x20;       var view = ContextViewBinder.Create(\_viewType, ctx.Data, ctx);

&#x20;       var indent = new string(' ', ctx.Depth \* 2);

&#x20;       var sw = ValueStopwatch.StartNew();



&#x20;       Log.Debug("{Indent}→ \[{Event}] {Trigger} band={Band}/{Inner} rw={Reads}|{Mutates}",

&#x20;           indent, ctx.Event, Name, SortKey.Band, SortKey.Inner,

&#x20;           string.Join(",", Reads), string.Join(",", Mutates));



&#x20;       try

&#x20;       {

&#x20;           // ③ 异步执行 + 超时

&#x20;           using var timeoutCts = Timeout.HasValue

&#x20;               ? CancellationTokenSource.CreateLinkedTokenSource(ct)

&#x20;               : null;

&#x20;           timeoutCts?.CancelAfter(Timeout!.Value);



&#x20;           var token = timeoutCts?.Token ?? ct;

&#x20;           await \_invoker(view, ctx, token).ConfigureAwait(false);



&#x20;           return null;

&#x20;       }

&#x20;       catch (OperationCanceledException) when (Timeout.HasValue \&\& timeoutCts!.IsCancellationRequested \&\& !ct.IsCancellationRequested)

&#x20;       {

&#x20;           Log.Error("{Indent}✗ \[{Event}] {Trigger} 超时 {Timeout}",

&#x20;               indent, ctx.Event, Name, Timeout);

&#x20;           return null;

&#x20;       }

&#x20;       catch (OperationCanceledException)

&#x20;       {

&#x20;           Log.Warning("{Indent}✗ \[{Event}] {Trigger} 被外部取消", indent, ctx.Event, Name);

&#x20;           throw;   // 外部取消要向上传播

&#x20;       }

&#x20;       catch (StaleReferenceException ex)

&#x20;       {

&#x20;           Log.Debug("{Indent}\~ \[{Event}] {Trigger} 提前退出：{Msg}",

&#x20;               indent, ctx.Event, Name, ex.Message);

&#x20;           return null;

&#x20;       }

&#x20;       catch (PermissionDeniedException ex)

&#x20;       {

&#x20;           Log.Error("{Indent}✗ \[{Event}] {Trigger} 越权访问：{Msg}",

&#x20;               indent, ctx.Event, Name, ex.Message);

&#x20;           return null;

&#x20;       }

&#x20;       catch (Exception ex)

&#x20;       {

&#x20;           // ④ 异常隔离

&#x20;           Log.Error(ex, "{Indent}✗ \[{Event}] {Trigger} 异常", indent, ctx.Event, Name);

&#x20;           return null;

&#x20;       }

&#x20;       finally

&#x20;       {

&#x20;           view.Seal();

&#x20;           Log.Debug("{Indent}← \[{Event}] {Trigger} {Ms}ms stop={Stop} intr={Intr}",

&#x20;               indent, ctx.Event, Name, sw.Elapsed.TotalMilliseconds,

&#x20;               ctx.Stopped, ctx.Interrupted);

&#x20;       }

&#x20;   }



&#x20;   private bool Preflight(Context ctx, out string? staleField)

&#x20;   {

&#x20;       staleField = null;

&#x20;       foreach (var f in Reads.Concat(Mutates))

&#x20;       {

&#x20;           if (!ctx.Data.TryGetValue(f, out var v)) continue;

&#x20;           if (v is IRef r \&\& !r.IsAlive) { staleField = f; return false; }

&#x20;       }

&#x20;       return true;

&#x20;   }



&#x20;   // ------------ 主动触发入口 ------------

&#x20;   public Task<object?> InvokeAsync(Context? ctx = null, CancellationToken ct = default)

&#x20;   {

&#x20;       ctx ??= new Context($"active:{Name}", Source: Owner);

&#x20;       return RunAsync(ctx, ct);

&#x20;   }

}

```



\*\*类型参数与 `\_viewType`\*\*：用强类型泛型构造，把 `\_viewType` 存在 Trigger 里，`RunAsync` 时按需构造视图。构造过程由 `TriggerFactory<TView>` 完成，向用户隐藏细节（见 4.6）。

\### 4.6 TriggerFactory —— 友好的构造入口



让卡牌作者不用写反射或泛型体操：



```csharp

public static class TriggerFactory

{

&#x20;   public static Trigger Create<TView>(

&#x20;       string name,

&#x20;       SortKey sortKey,

&#x20;       Func<TView, Context, CancellationToken, Task> handler,

&#x20;       TriggerOptions? options = null)

&#x20;       where TView : IContextView

&#x20;   {

&#x20;       var opts = options ?? TriggerOptions.Default;

&#x20;       // 从 TView 上静态分析（反射或 Source Generator）出 reads/mutates/optionals

&#x20;       var meta = ViewMeta.For<TView>();



&#x20;       return new Trigger(

&#x20;           name, sortKey,

&#x20;           opts.Owner, opts.Once, opts.Timeout,

&#x20;           meta.Reads, meta.Mutates, meta.Optionals,

&#x20;           async (rawView, ctx, ct) =>

&#x20;           {

&#x20;               var typed = (TView)rawView;

&#x20;               await handler(typed, ctx, ct);

&#x20;           })

&#x20;       { \_viewType = typeof(TView) };

&#x20;   }

}



public sealed record TriggerOptions

{

&#x20;   public static readonly TriggerOptions Default = new();

&#x20;   public object? Owner { get; init; }

&#x20;   public bool Once { get; init; }

&#x20;   public TimeSpan? Timeout { get; init; }

}

```



\*\*使用侧\*\*：



```csharp

var shieldTrigger = TriggerFactory.Create<ShieldView>(

&#x20;   name: "护盾",

&#x20;   sortKey: new SortKey(PriorityBands.Damage.Reduce, inner: 0),

&#x20;   {

&#x20;       if (view.Target.Value != \_shieldEntity) return;

&#x20;       int newAmount = Math.Max(0, view.Amount - 2);

&#x20;       Log.Info("  🛡 护盾减伤 {Old} → {New}", view.Amount, newAmount);

&#x20;       view.Amount = newAmount;

&#x20;       await Task.CompletedTask;

&#x20;   },

&#x20;   options: new TriggerOptions { Owner = \_shieldCard });

```

\### 4.7 TriggerBus —— 被动触发器挂载点



```csharp

public sealed class TriggerBus

{

&#x20;   private readonly Dictionary<string, List<Trigger>> \_slots = new();

&#x20;   private readonly object \_lock = new();

&#x20;   private long \_seq;



&#x20;   public Trigger Mount(string @event, Trigger trigger)

&#x20;   {

&#x20;       lock (\_lock)

&#x20;       {

&#x20;           trigger.RegistrationSeq = \_seq++;

&#x20;           if (!\_slots.TryGetValue(@event, out var list))

&#x20;               \_slots\[@event] = list = new List<Trigger>();

&#x20;           list.Add(trigger);

&#x20;           list.Sort(Compare);

&#x20;           Log.Info("mount \[{Event}] {Trigger} band={Band}/{Inner}",

&#x20;               @event, trigger.Name, trigger.SortKey.Band, trigger.SortKey.Inner);

&#x20;           return trigger;

&#x20;       }

&#x20;   }



&#x20;   public void Unmount(string @event, Trigger trigger)

&#x20;   {

&#x20;       lock (\_lock)

&#x20;       {

&#x20;           if (\_slots.TryGetValue(@event, out var list)) list.Remove(trigger);

&#x20;       }

&#x20;   }



&#x20;   public void UnmountOwner(object owner)

&#x20;   {

&#x20;       lock (\_lock)

&#x20;       {

&#x20;           foreach (var list in \_slots.Values)

&#x20;               list.RemoveAll(t => ReferenceEquals(t.Owner, owner));

&#x20;       }

&#x20;   }



&#x20;   public async Task EmitAsync(string @event, Context ctx, CancellationToken ct)

&#x20;   {

&#x20;       // 快照，防止遍历中被改

&#x20;       Trigger\[] snapshot;

&#x20;       lock (\_lock)

&#x20;       {

&#x20;           if (!\_slots.TryGetValue(@event, out var list)) return;

&#x20;           snapshot = list.ToArray();

&#x20;       }



&#x20;       foreach (var t in snapshot)

&#x20;       {

&#x20;           if (ctx.Stopped)

&#x20;           {

&#x20;               Log.Debug("\[{Chain}] 在 \[{Event}] 处停止", ctx.ChainId, @event);

&#x20;               break;

&#x20;           }

&#x20;           await t.RunAsync(ctx, ct).ConfigureAwait(false);

&#x20;       }

&#x20;   }



&#x20;   private static int Compare(Trigger a, Trigger b)

&#x20;   {

&#x20;       int c = a.SortKey.CompareTo(b.SortKey);

&#x20;       return c != 0 ? c : a.RegistrationSeq.CompareTo(b.RegistrationSeq);

&#x20;   }

}
```

\## 六、异常、取消与中断语义



| 情形 | 处理 | 是否中断链 |

|---|---|---|

| 触发器内部业务异常 | 捕获、记日志、返回 null | ❌ 继续下一个 |

| 视图越权（PermissionDenied） | 捕获、记 Error | ❌ 继续（便于暴露 bug） |

| Ref 失效（StaleReference） | Preflight 拦截或捕获、记 Debug | ❌ 继续 |

| 超时（Timeout） | 捕获 OperationCanceled、记 Error | ❌ 继续 |

| 外部取消（CancellationToken） | 捕获、记 Warning、\*\*重新抛出\*\* | ✅ 整个链终止 |

| `ctx.Stop()` | 引擎在下一个触发器前检查 | ✅ 本事件后续终止 |

| `ctx.Interrupt()` | 引擎动作边界检查 | ✅ 动作整体取消 |

| `ctx.Interrupt()` + 回滚需求 | \*\*引擎侧负责\*\*（前置校验点模式） | — |



\*\*关键约定\*\*



\- \*\*触发器\*\*只能"喊停"，不能"撤回已发生的事"。反制类效果必须落在 `Before\*` 事件。

\- \*\*引擎\*\*在动作边界（emit 之后）检查 `ctx.Interrupted`。

\- \*\*取消令牌\*\*必须从引擎一路传到触发器，用于真实资源清理。

\## 七、异步模型



\### 7.1 统一签名



所有触发器 handler 都是：



```csharp

Func<TView, Context, CancellationToken, Task>

```



同步逻辑用 `Task.CompletedTask` 或 `ValueTask`（若追求零分配）。



\### 7.2 超时



在 `Trigger.RunAsync` 内用 `CancellationTokenSource.CreateLinkedTokenSource` + `CancelAfter`。



\### 7.3 并发



\*\*首版建议：单线程调度\*\*。所有触发器通过一条 `Task` 链顺序 await。若引入并行，需要：



\- 每个触发器独立的 `ContextView`（当前实现已具备）

\- `ctx.Data` 写入需加锁或使用 `ImmutableDictionary`

\- 明确哪些 band 可并行（一般只有 `Read` 类可并行）



\*\*不建议原型阶段并行\*\*，调试成本远高于收益。

\## 十一、C# 实现注意事项



1\. \*\*`Ref<T>` 用 `sealed class`\*\*，避免虚调用开销；访问 `Value` 是热路径。

2\. \*\*`SortKey` 用 `readonly record struct`\*\*，排序零分配。

3\. \*\*`TriggerBus` 的 `\_slots` 用 `Dictionary<string, List<Trigger>>`\*\*，`List` 内部有序，配 `Sort(Compare)` 保证顺序。

4\. \*\*`Context.Data` 用 `Dictionary<string, object?>`\*\*。若需极致性能，可换 `FrozenDictionary` 做只读阶段，但写入阶段仍需可变。

5\. \*\*Source Generator 是长期方案，反射缓存是短期方案\*\*。接口 `IContextView.Bind` 不变，方便切换。

6\. \*\*`ValueTask` vs `Task`\*\*：原型用 `Task`；热点路径（如每秒上千次结算）可评估 `ValueTask`。

7\. \*\*`ConfigureAwait(false)`\*\*：引擎内部一律加，避免同步上下文死锁。

8\. \*\*多线程\*\*：v1 单线程调度，`TriggerBus` 的 `\_lock` 仅为防御；未来若并行，需升级为 `ReaderWriterLockSlim` 或每事件独立锁。

9\. \*\*日志用 `Microsoft.Extensions.Logging`\*\*，通过结构化字段支持过滤。

10\. \*\*不要在 `ContextView` 里存引用\*\*，只做 `\_data` 的转发；每次 `Bind` 复用或新建均可。

\## 十三、设计决策速查表



| 决策 | 选择 | 理由 |

|---|---|---|

| 被动/主动是否共用包装器 | ✅ 共用 | 优先级/日志/异步/中断统一 |

| 上下文传递 | `Context` + `ContextView` | 收窄范围，防越权 |

| 引用安全 | `Lifetime` + `Ref<T>` | 悬空可检测 |

| 优先级 | `(Band, Inner)` 元组 | 避免浮点、避免重排 |

| 排序键比较 | `IComparable` 元组 | 零成本、安全 |

| 同键冲突 | 注册序号兜底 | 语义即入场顺序 |

| 异步 | `async Task` + `CancellationToken` | 原生支持 |

| 超时 | `CancelAfter` | 防止卡死 |

| 异常 | 隔离，除非外部取消 | 单个触发器不拖垮链 |

| 中断 | `ctx.Stop/Interrupt` + 引擎边界检查 | 显式、可测 |

| 日志 | `ChainId` + `Depth` + 结构化 | 全链路可读 |

| 视图实现 | 反射缓存（MVP）→ Source Generator（长期） | 兼容切换 |

\*\*结语\*\*



这套架构的核心思想是把"上下文"和"引用"从\*\*万能对象\*\*降级为\*\*每个触发器自己的切片 + 生命周期令牌\*\*，把"优先级"从\*\*单值调数\*\*升级为\*\*双层语义相位\*\*。所有复杂度都收敛在 `Trigger.RunAsync` 一个方法里，卡牌作者面对的是强类型视图和命名 band。这是可长期维护、可扩展、可观测、可测试的形态。
