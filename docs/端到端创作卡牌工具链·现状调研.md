## 一、创作面：效果创作五形态总清单

### 形态A：卡面文本〔解析器〕
- 输入：中文卡面文本（官方 zh-Hans；一卡可多效果）
- API：`EffectParser.CreateDefault()`（src/Orc.Game/EffectParsing/Parsing/EffectParser.cs:29-33）→ `Parse(text)`（:36-45）→ `ParseResult{Effects: DslEffectInstance[]; Unresolved: UnresolvedRecord[]; Declarations: LineDeclaration[]}`（ParseResult.cs:15-37）
- 内部链：Tokenizer→Segmenter→AstBuilder→SemanticMapper（EffectParser.cs:32-36；SemanticMapper.Map @ SemanticMapper.cs:46-58）
- 词表：Lexicon/*.json 10 类（LexiconLoader.cs:26-39；默认目录 `<bin>/EffectParsing/Lexicon` @ :26）
- 词条行声明：KeywordLineScanner（词条行→声明+参值；异常并入未解析面，KeywordLineScanner.cs:16-70）
- 产物：DSL 实例（模板+槽位 ops）；未解析＝显式记录（不产占位效果，ParseResult.cs:19-21）
- 适用：批量把官方卡面文本转 DSL；限制：子集覆盖＋needsCsx 留痕＋占位条件（raw→if(false)）分层（EffectParseCorpusTests.cs:55-99）

### 形态B：模板效果 + DSL
- 模板资产：Templates/*.tpl.json（约 31 个）→ EffectTemplateLoader（DefaultDirectory=`<bin>/EffectParsing/Templates`，:26）；槽位定位语法 `mainTrigger.events[e1]` / `otherTriggers[<id>].events[e2]`（EffectTemplateSlots.cs:12-19）
- op 语句模板：Templates/ops/*.csx.tpl（22 个：damage/draw/buff/move/destroy/pin/silence/addToHand/shuffleIn/costMod/needsCsx/nested/gainSlot/loseSlot/gainPoint/losePoint/aura/reveal/upgrade/grant/csx）；占位符 `{{amount}}` 等（OpTemplateCatalog.cs:21-52；DefaultDirectory @ :63）
- DSL 模型/校验：DslModels.cs；DslOpRegistry 21 原语（:41-83）；JSON 读写 DslJson（Serialize/Deserialize/TryDeserialize）
- 编译：`new EffectCompiler(templates, ops).Compile(dsl, effectId, version=1)` → EffectSnapshot；`CompileToJson`（EffectCompiler.cs:35-88）；条件渲染 owner.*/raw/EventCardFilter/PayloadSelf/PayloadOwner/Compare/TurnOwner（:138-175）
- 产物：EffectSnapshot（带渲染后 csx）→ 可落 *.prefab.json 或卡内联
- 限制：src/scripts 无生产调用者（仅测试构造 new EffectCompiler，如 EffectParsingTests.cs:28-33）；模板/ops 为资产需随程序集复制（Orc.Game.csproj:20-25）

### 形态C：预制体 JSON（*.prefab.json，含 csx 内联）
- 形态：`{schemaVersion:2, root:{id, version, mainTrigger, otherTriggers[], modings[], injects[]}}`；触发器 `{id, stableKey, kind, viewType, hooks[], events[], version}`；事件 `{id, entry, csx?, assemblyKey?, downstream[], version}`（PrefabJson.cs:14-22；Prefabs.cs:10-17）
- API：PrefabJson.Serialize/Deserialize/TryDeserialize（PrefabJson.cs:36-90）；PrefabManager.LoadDirectory（PrefabManager.cs:79-108；*.prefab.json 顶层、文件名序、单文件失败隔离）；RegisterPrefab（:57-71）
- 样本：src/Orc.Game/Cards/KeywordPrefabs/keyword.blitz.deploy-set.prefab.json（+mobilize.accrual/mobilize.loss）
- 先例：PrefabEffectLoadingTests.cs:24-74

### 形态D：csx 逃生舱
- 输入：csx 源码；入口＝具名变量 `Func<TView, Context, CancellationToken, Task>`（默认 HandleAsync）
- 求值器：Orc.Script.CSharpScriptEvaluator（CSharpScriptEvaluator.cs:18-172；缓存 :42-56；失败分类 compile/runtime/entry-missing/signature/sandbox/timeout :59-131）；契约 IScriptEvaluator/ScriptRequest/ScriptEvaluationResult（Scripting.cs:19-105；ScriptHandlerAdapter 绑回泛型 :90-105）

- 限制：viewType 需程序集限定名（跨程序集程序集内视图；E1-36 修复记录见 EffectRuntimeEndToEndTests.cs:44-72）；超时无法真中断

- 适用：内置/复杂机制（伏击=判定器改写；动员=回合累积）；限制：需编译期入程序集

## 二、数据面：*.card.json schema 与官方样本
- 顶层：`{schemaVersion:1, id, name, components[]}`（CardDataJson.cs:14-17；必填；组件每类至多一份；未知组件→告警隔离 :120-160）
- 六组件（注册序＝第一段加载序 typeCategory→factionCost→battleStats→tagData→keywords→effects，BuiltInCardComponents.cs:390-471）：
  1. typeCategory〔构造期〕`{type:[...]}`：order→Command/countermeasure→Counter（独占）；infantry/tank/artillery/fighter/bomber（可多个）（:96-176）
  2. factionCost〔构造期，必填〕`{faction, kredits}`（:13-35）
  3. battleStats〔构造期，仅单位〕`{operationCost, attack, defense}`（:40-62）
  4. tagData〔加载期，必填〕`{rarity, tags?}`（:67-89）
  5. keywords〔加载期〕`{attributes:[...]}`→CardAttributeMap 映射；未命中→UnmappedAttributes 留痕（:185-310）
  6. effects〔加载期〕`{prefabs:[id...], inline:[{schemaVersion:2,...}|字符串]}`；载入期注册内联并转声明（:316-357；CardDataLoader.cs:100-148）
- keywords 映射表全景（CardAttributeMap.cs:46-84）：blitz→闪击/fury→奋战/smokescreen→烟幕/ambush→伏击/pincer→钳击/mobilize→动员/covert→隐蔽/guard→守护/shock→冲击；Orc 自有 suppressed/inhibited/forecast/immune/cannotBeSuppressed/cannotBeInhibited/deathrattle；参值型 heavyArmorN→重甲N、intelN→情报N（N>0）；老兵链 `BecomesVeteran:<id>`/`VeteranOf:<id>`（:23-27,:129-146，唯一合法条承载）；未实现（bond/alpine/salvage/OnlySpawnable 等）留痕不阻断
- 官方样本（outputs/kards-cards/*.card.json 共 1646 张；生成器 scripts/import_kards_cards.py:31-102）：dug_in（指令/无效果）、102_grenadier（BecomesVeteran:102_grenadier_vet+OnlySpawnable+shock）、char_b1_bis（heavyArmor2+shock）、matilda_mk_iv_vet（VeteranOf+guard+heavyArmor1）；官方语料不含 effects/trigger/ability 字段（OfficialCardDataSmokeTests.cs:34-40）

## 六、端到端可跑路径拆解（工具链对照）

## 七、扩展点与缺口
【可复用 API】加载：CardDataLoader/PrefabManager/PrefabJson/EffectTemplateLoader/OpTemplateCatalog/LexiconLoader/KeywordPrefabLibrary；解析编译：EffectParser/EffectCompiler/DslJson/EffectTemplateJson；注册：CardEffectRegistry/KeywordRegistry/CardComponentRegistry/JudicatorRegistry；运行时：EffectRuntime/GameUpdates/GameHooks；导出：GameEntryPointsJson/GameHooksJson（Serialize→string）
【目录/命名约定】*.card.json / *.prefab.json / *.tpl.json / *.csx.tpl / Lexicon（10 文件名→类别）/ Cards/KeywordPrefabs/*.prefab.json；复制规则 Orc.Game.csproj:20-30
【现有脚本/工具】scripts/import_kards_cards.py（官方→card.json，不含 effects）；scripts/extract_card_text.py（卡面文本抽取）；EffectParseCorpusTests 覆盖率报告（测试内产物）
【阻挡项】①编译管线无生产驱动（EffectCompiler 仅测试调用）——需自建 parse→compile→pack 驱动；②卡面→effects 内联无自动管道（import 脚本不产 effects）；③无预览/试编译生产 API（先例=测试 AssertCompiles 经 CSharpScriptEvaluator 逐事件 Evaluate）；④无卡包级 dry-run 校验器（声明↔注册对比仅在装载时 fail-fast/隔离）；⑤injects 限默认区段（非空 BandName 隔离，EffectSystem.cs:306-313）；⑥viewType 解析要求程序集限定名（DynamicEffectBuilder.ResolveViewType，DynamicEffect.cs:200-209）；⑦csx 弱沙箱（同进程；创作工具若创造+运行需评估）；⑧解析器覆盖缺口分层（Unresolved/needsCsx/占位条件；覆盖率报告口径甲/乙）；⑨诊断产物位置不稳定（corpus-coverage.md 在测试 bin）；⑩无 UI/图形表现面（引擎无头）

## 附二：词条效果 csx 行为引用（2026-10-07 验证补充）

【已验证】csx 版词条效果样本 ×3 落定 `KeywordPrefabs`（`*.csx.prefab.json`，与 assemblyKey 生产版并存）；全链＝生产库装载→授予链实例化（csx 求值器编译绑定）→对局行为等价；失败分类（compile/sandbox/entry-missing）经授予链 fail-fast＋回滚。
【csx 编写边界（实测）】①`ReferenceEquals` 裸名不可解析——用 `object.ReferenceEquals`；②沙箱屏蔽词＝文本级子串（File/Assembly/Environment/System.IO 等 20 项）——源文本须规避；③性能：3 源冷启动首编译≈2s（按 视图+入口+超时+源哈希 缓存）；装载零编译、编译仅首用；跨对局不共享求值器。
【迁移路径（可选、未执行）】绑定/注册切 csx 常量→`RegisterHandlers` 对应项退役→制品与装载面不变→效果名契约保持；性能优化（跨对局共享/持久缓存）留迁移批次。
